## 摘要
视觉-语言模型展现出卓越的零样本能力，但在分布偏移下会遭受显著的性能下降。虽然通过低秩适应的测试时自适应（TTA）提供了一种参数高效的解决方案，但我们识别出当前方法的一个根本瓶颈：对静态秩配置的依赖。由于视觉输入本质上具有不同的信息密度，固定秩迫使优化做出不可避免的妥协，导致在复杂场景下欠拟合，在简单场景下过拟合。为弥合这一差距，我们提出多秩适应（MuRA）——一种新颖的框架，基于标记级视觉复杂度动态选择并融合不同能力的适应模块。MuRA协同多秩正交分解以提供优越且保留知识的初始化，并通过连续路由更新的统一组件融合来持续学习语义到秩的映射。此外，我们提供严谨的理论论证，在数学上证明该自适应机制的必要性和梯度稳定性。关键在于，MuRA的动态设计独特地在最深的视觉层上发挥作用，利用最短的梯度反向传播路径。大量实验表明，MuRA在广泛的域泛化和跨数据集基准上取得了最先进的准确率，同时显著降低了计算和内存开销。

## Abstract
Vision-language models exhibit remarkable zero-shot capabilities but suffer significant performance degradation under distribution shifts. While test-time adaptation (TTA) via Low-Rank Adaptation offers a parameter-efficient solution, we identify a fundamental bottleneck in current methods: the reliance on static rank configurations. Because visual inputs inherently possess varying information densities, a fixed rank forces an inevitable optimization compromise, leading to underfitting on complex scenes and overfitting on simple ones. To bridge this gap, we propose Multi-Rank Adaptation (MuRA), a novel framework that dynamically selects and fuses adaptation modules of varying capacities based on token-level visual complexity. MuRA synergizes Multi-Rank Orthogonal Decomposition to provide a superior, knowledge-preserving initialization, and Unified Component Fusion with Continuous Router Updating to sustainably learn semantic-to-rank mappings. Furthermore, we provide rigorous theoretical justifications mathematically proving the necessity and gradient stability of this adaptive mechanism. Crucially, MuRA's dynamic design uniquely thrives at the deepest visual layer, capitalizing on the shortest gradient backpropagation path. Extensive experiments demonstrate that MuRA achieves state-of-the-art accuracy across extensive domain generalization and cross-dataset benchmarks while significantly reducing both computational and memory overhead.

## 2. 方法论：核心思想、关键技术细节与流程

### 核心思想

MuRA 通过在**最深层视觉层**部署动态多秩 LoRA 路由机制，按 token 级视觉复杂度（熵）动态选择/融合不同秩的适应模块，实现“复杂度-容量”匹配，同时利用最短梯度路径降低开销。

### 三大核心组件

1. **多秩正交分解（Multi-Rank Orthogonal Decomposition, MROD）**
   - 对预训练权重 W 执行经济奇异值分解：W = USVᵀ；
   - 对于每个秩 rᵢ，将前 rᵢ 个主成分作为 LoRA 初始化，残余矩阵 Rᵢ = U[:, rᵢ:]S[rᵢ:, rᵢ:]Vᵀ[:, rᵢ:]；
   - 确保 W = AᵢBᵢᵀ + Rᵢ 且 AᵢBᵢ ⊥ Rᵢ；
   - 相比标准零初始化，该初始化具有**保留预训练知识、梯度和注意力分布更稳定**的特点。

2. **统一组件融合（Unified Component Fusion, UCF）**
   - 将各秩对应的残差矩阵平均为 R̄，替换原始预训练权重并冻结；
   - 借鉴 Mixture-of-Experts（MoE）思想：零初始化路由器 W_r ∈ R^{k×d} 对 token 表征 h_l 计算 softmax 权重：
     π(h_l) = softmax(W_r h_l)；
   - 最终输出为：o = Σᵢ πᵢ(h_l)·AᵢBᵢᵀh_l + R̄h_l。

3. **连续路由更新（Continuous Router Updating, CRU）**
   - 每次测试样本适应结束后，将低秩矩阵 Aᵢ、Bᵢ **重置为 MROD 初始化值**（容量锚点固定）；
   - 路由器 W_r 的累积知识**持续保留**，在多样本流上学习普适的“复杂度-容量”映射；
   - 解决了持续更新中路由崩溃与灾难性遗忘问题。

### 优化目标与流程

- 对每个测试图像，通过增强函数 A 生成多个增强视图；
- 计算各视图的预测熵 H_Φ(x̃)，用自适应权重 β_Φ(x̃) = 1/exp(H_Φ(x̃) − ε) 平衡贡献；
- 损失函数为经过熵阈值过滤和加权的熵最小化：

  L = −(1/ρN) · Σ_{x̃∈A(X)} 1[H_Φ(x̃) ≤ τ] · β_Φ(x̃) · H_Φ(x̃)

- 使用 AdamW 优化器，单步更新（LoRA 矩阵学习率 6e-3，路由器学习率 1e-4）。

### 理论贡献

- **Lemma 4.1（路由器梯度结构）**：给出了 router 权重的梯度形式，说明路由器通过对比各专家有效性实现自动选择；
- **Lemma 4.2（动态路由必要性）**：推导出路由 logit 更新与复杂度-容量失配距离的关系，证明动态路由诱导低复杂度→低秩、高复杂度→高秩的收敛行为，静态秩无法参与该竞争；
- **Lemma 4.3（CRU 稳定性）**：通过 softmax 的 Lipschitz 连续性界定了连续更新中路由概率的稳定性；固定容量锚点保证路由器优化地形全局平稳。

## 6. 主要结论与发现

1. **静态秩是知识自适应 TTA 的根本瓶颈**，数据复杂度与最优秩强相关；
2. **MROD 初始化**在单秩设置下即带来 7.38% 平均提升（相比 vanilla CLIP），且使梯度和注意力分布更稳定；
3. **UCF + CRU** 额外带来 1.13% 平均提升，且 CRU 在 token 级粒度下增益显著（+1.13%），实例级仅 +0.03%；
4. MuRA 的**动态设计使最深视觉层成为最佳适配层**（最深 72.98% vs 单秩 67.51%），由此获得最短反向传播路径带来的效率优势；
5. **Soft Routing 优于 Hard Routing**（+1.41% 平均），渐进式多秩优于均匀秩配置；
6. **跨骨干有效**：ViT-B/16、ViT-L/14、ResNet-50 上均超越对比方法；
7. **持续分布偏移下 CRU 保持稳定**：秩利用率熵降低、路由确定性增强，且选择趋势符合复杂度预期。
