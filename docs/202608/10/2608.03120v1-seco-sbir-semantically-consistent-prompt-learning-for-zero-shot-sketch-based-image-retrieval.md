## 摘要
通过提示学习将CLIP适应于零样本草图图像检索（ZS-SBIR）面临一个基本矛盾：模型必须通过特定于任务的适应来弥合草图-照片领域差距，但增加的灵活性可能会过拟合到已见的训练类别，并侵蚀CLIP的零样本泛化能力。我们提出了SeCo-SBIR，一个语义一致的提示学习框架，从两个方面解决了这一矛盾。首先，一种文本引导的多模态提示策略将可学习的提示向量通过CLIP的文本编码器路由，并通过可学习的耦合函数将生成的中间表示投影到每一层的视觉编码器中。由于文本编码器已经从大规模语言监督中学习了稳健、抽象的类别级语义，这种机制将可迁移的语义知识直接注入视觉通路——使模型适应草图-照片领域，同时固有地有利于对未见类别的泛化。其次，一种基于扰动的一致性约束通过使用非对称InfoNCE目标将适应模型与冻结的CLIP参考分支对齐，解决了可学习耦合函数带来的残留过拟合风险——增强输入馈入冻结分支，而干净输入馈入可训练分支——将学习到的表示锚定到CLIP的泛化特征空间。结合轻量级适配器和结合三元组、NT-Xent和分类项的多目标损失，SeCo-SBIR在三个标准ZS-SBIR基准上，在分类、广义和跨数据集设置下均取得了最先进的结果。

## Abstract
Adapting CLIP for zero-shot sketch-based image retrieval (ZS-SBIR) via prompt learning faces a fundamental tension: the model must bridge the sketch-photo domain gap through task-specific adaptation, yet the added flexibility risks overfitting to seen training categories and eroding CLIP's zero-shot generalization. We present SeCo-SBIR, a semantically consistent prompt learning framework that resolves this tension from both sides. First, a text-guided multi-modal prompting strategy routes learnable prompt vectors through CLIP's text encoder and projects the resulting intermediate representations into the visual encoder at every layer via learnable coupling functions. Because the text encoder has already learned robust, abstract category-level semantics from large-scale language supervision, this mechanism injects transferable semantic knowledge directly into the visual pathway - adapting the model to the sketch-photo domain while inherently favoring generalization to unseen classes. Second, a perturbation-based consistency constraint addresses the residual overfitting risk from the learnable coupling functions by aligning the adapted model with a frozen CLIP reference branch using an asymmetric InfoNCE objective - augmented inputs feed the frozen branch while clean inputs feed the trainable branch - anchoring the learned representations to CLIP's generalizable feature space. Together with lightweight adapters and a multi-objective loss combining triplet, NT-Xent, and classification terms, SeCo-SBIR achieves state-of-the-art results on all three standard ZS-SBIR benchmarks across categorical, generalized, and across-dataset settings.

### 1. 核心问题与整体含义（研究动机和背景）

- **任务背景**：草图图像检索（SBIR）允许用户通过手绘草图查询自然图像数据库，而零样本草图图像检索（ZS-SBIR）更进一步要求模型在**从未见过的类别**上进行检索，不仅要弥合草图与照片之间的跨模态领域差距，还要具备类别级别的泛化能力。广义 ZS-SBIR（GZS-SBIR）还要求模型在同时包含已见类和未见类照片的图库中检索，面临更严重的已见类偏向问题。
- **现有方法的矛盾**：CLIP 已成为 ZS-SBIR 的主流骨干网络，主流适应策略为提示学习（prompt learning），但现有提示学习方法面临一个根本性张力——**模型必须通过任务特定适应来弥合草图-照片领域差距，但增加的灵活性又会过拟合到已见训练类别，从而侵蚀 CLIP 的零样本泛化能力**。已有方法如 CLIP-AT（浅层孤立视觉提示）、SpLIP（双向标记交换）等均未显式解决这一核心矛盾。
- **整体含义**：本文提出 SeCo-SBIR 框架，**从"适应"和"泛化"两侧同时解决上述矛盾**——一方面通过文本引导机制注入本身可迁移的语义知识进行深度适应，另一方面通过扰动一致性约束对剩余的可学习容量进行正则化，防止向已见类漂移，从而在保持 CLIP 零样本泛化能力的同时实现有效的跨域适应。

### 2. 方法论（核心思想、关键技术细节）

#### 2.1 整体架构
- 在 CLIP 双编码器（视觉 + 文本）基础上扩展为**三个并行分支**：照片分支、草图分支、文本分支，每个分支后接轻量适配器（adapter）。CLIP 两个编码器全程冻结，仅通过可学习模块进行适应。

#### 2.2 文本引导多模态提示（Text-Guided Multi-Modal Prompting）

- **核心思想**：CLIP 的文本编码器已从大规模语言监督中学到了稳健、抽象的类别级语义，这些知识天然可跨类别迁移。与其在视觉编码器中孤立地学习提示（如 VPT），不如**让可学习提示先经过文本编码器，再通过可学习耦合函数将其各层中间表示注入视觉编码器的每一层**。
- **关键技术细节**：
  - **可学习提示构建**：在固定文本模板（如"a photo of a"）中，用可学习向量替换前 \( b \) 个词嵌入位置，保留其余固定 token，并与类别名嵌入拼接后送入文本编码器。所有类别共享同一组可学习向量，仅类别名嵌入随类别变化。
  - **跨模态提示耦合**：文本编码器第 \( l \) 层产生的提示中间表示 \( P^t_l \) 经可学习耦合函数 \( F_l: \mathbb{R}^{d_t} \to \mathbb{R}^{d_v} \)（线性投影，随训练联合优化）投影到视觉嵌入空间，生成 \( P^p_l = F_l(P^{t,p}_l) \) 和 \( P^s_l = F_l(P^{t,s}_l) \)。照片和草图分支有各自独立的可学习提示。
  - **深层注入**：每一层视觉编码器将耦合后的视觉提示与当前 patch token 拼接作为输入，处理后**丢弃提示位置**，保持序列长度不变，再在下一层注入新的耦合提示，实现跨全深度的渐进式语义引导适应。
- **设计优势**：与仅从视觉训练信号学习提示（易过拟合已见类）相比，文本引导产生的提示具有语言层面的类别级语义根基，天然偏向对未见类的泛化。

#### 2.3 轻量适配器模块
- 每个分支附加一个两层网络：\( A(z) = \Theta_2 \cdot \text{ReLU}(\Theta_1 \cdot z) \)，用于将特征投影到任务适配的嵌入空间。最终特征为 \( \hat{f}_p = A_p(\hat{V}_p(p)) \)、\( \hat{f}_s = A_s(\hat{V}_s(s)) \)、\( \hat{f}_t = A_t(T(t_k)) \)。
- **可训练组件**：可学习提示向量、耦合函数集合 \( \{F_l\}_{l=0}^{L} \)、三个适配器、以及编码器内部的 LayerNorm 参数；两个 CLIP 编码器主体保持冻结。

#### 2.4 扰动一致性约束（Perturbation-Based Consistency Constraint）

- **核心思想**：对文本引导提示中的可学习耦合函数等新增容量进行正则化，防止已见类过拟合。
- **关键技术细节**：
  - **非对称双分支设计**：对输入照片 \( p \) 生成增强视图 \( \tilde{p} = T_{aug}(p) \)（随机擦除、中心裁剪、水平翻转），**增强输入**馈入**冻结**的 CLIP 参考编码器 \( V_{frz} \)，**干净输入**馈入**可训练**（提示 + 适配器）编码器。
  - **非对称设计的目的**：防止平凡解（若两分支输入相同，可训练模型只需复制冻结模型行为即可最小化损失）；通过增强输入制造软监督，促使可训练模型学习对输入变化稳健的表征，而非简单拷贝。
  - **InfoNCE 损失**：以判别式方式对齐两分支嵌入，保留 CLIP 嵌入空间的相对结构（比 MSE/L1 更适合检索任务）。照片分支的损失为：
    \[
    L^p_{InfoNCE} = -\frac{1}{B}\sum_{i=1}^{B}\log\frac{\exp(\text{sim}(f^{frz}_{p_i}, \hat{f}_{p_i})/\tau_c)}{\sum_{j=1}^{B}\exp(\text{sim}(f^{frz}_{p_i}, \hat{f}_{p_j})/\tau_c)}
    \]
    草图分支同理，总一致性损失 \( L_{consist} = L^p_{InfoNCE} + L^s_{InfoNCE} \)。

#### 2.5 跨模态对齐损失

- **三元组损失**：拉近同一类别草图-照片对，推远不同类别对，使用余弦距离和边界参数 \( \mu = 0.3 \)。
- **NT-Xent 损失**：批次级双向对比损失（草图→照片和照片→草图两个方向），将批内所有非匹配对作为负样本，补充三元组损失的监督信号。
- **分类损失**：将每个已见类的提示增强文本输入经文本编码器和适配器得到类别原型，对草图和照片特征分别做分类损失；测试时为未见类别名称构造相同提示结构的原型，实现零样本迁移。

#### 2.6 总训练目标

\[
L_{total} = L_{triplet} + L_{NT\text{-}Xent} + \lambda_1 L_{class} + \lambda_2 L_{consist}
\]

实验设置 \( \lambda_1 = \lambda_2 = 1 \)。

#### 2.7 推理过程
测试时丢弃增强管道和冻结参考分支，仅用提示 + 适配器的草图编码器提取查询特征，按余弦相似度对图库照片排序。

### 6. 主要结论与发现

- **SeCo-SBIR 在所有三个标准基准的所有评测场景下均达到最先进水平**：
  - 分类 ZS-SBIR：在 TU-Berlin-Ext 上较此前最优 SpLIP 提升 **+5.6% mAP@all / +6.5% P@100**，在 Sketchy-Ext-1 上 mAP@all 达 80.6%，在 QuickDraw-Ext 上提升 +1.8% mAP@all。
  - GZS-SBIR：在 TU-Berlin-Ext 上较 SpLIP 提升 **+4.6% mAP@all / +7.5% P@100**，在 Sketchy-Ext-2 上 mAP@200 达 77.6%；提升幅度大于标准 ZS-SBIR 设置，表明一致性约束有效缓解了已见类偏向。
  - 跨数据集：在 QuickDraw-Ext 上较 SpLIP 提升 **+6.8% mAP@all**，证明对类别和数据集双重漂移的鲁棒性。
- **消融结论**：
  - 文本引导耦合机制（+1.4%）、适配器（+1.2%）、一致性约束（+2.6%）、扰动策略（+1.5%）均带来正收益且非冗余。
  - 四个损失（三元组、NT-Xent、分类、一致性）各自贡献显著且互补。
  - InfoNCE 优于逐点损失（MSE、L1、Cosine）作为一致性约束的损失函数。
  - 1–3 个可学习 token 效果最佳，过多 token 导致性能下降。
  - 损失权重 \( (\lambda_1, \lambda_2) = (1, 1) \) 为最优平衡。
- **更广泛的启示**：将适应过程引导到语言根基的知识上，同时对可学习组件施加显式约束，是部署视觉-语言模型于需要向未见类别泛化的任务的有效原则。

- **深度的语义引导**：通过文本编码器中间表示逐层注入视觉提示，机制新颖，既实现了深层适应，又将可迁移的类别级语义直接嵌入视觉通路，与仅依赖已见类视觉统计的提示学习方法有本质区别。
- **正则化设计精巧**：非对称 InfoNCE 一致性约束（增强输入→冻结分支，干净输入→可训练分支）同时解决了"平凡解"问题和已见类漂移问题，是方法上的一个亮点。
- **消融实验全面细致**：从提示设计、损失组件、一致性设计、损失函数类型、token 数量、权重灵敏度等多个维度验证了每个设计决策，证据链完整。
- **实验覆盖完整**：标准 ZS-SBIR、广义 ZS-SBIR、跨数据集三个设置全覆盖，且补充了数据规模变化和已见类数量变化的泛化性分析，论证充分。
- **在过拟合最严重的基准上提升最大**：在类别最多的 TU-Berlin-Ext（250 类）和跨域差异最大的 QuickDraw-Ext 上增益最显著，从侧面验证了方法确实解决了所宣称的核心问题。

### 8. 不足与局限

- **消融实验的覆盖范围有限**：所有消融实验仅在 TU-Berlin-Ext 数据集上进行，未在其他数据集（如 Sketchy、QuickDraw）上验证各组件的一致有效性，结论的跨数据集稳健性证据不够完整。
- **算力与效率分析缺乏**：仅说明使用单张 H100 和 10 个 epoch，未报告训练时长、显存占用、可学习参数量等关键效率指标，也未与其他方法进行计算成本对比。
- **骨干网络单一**：仅使用 ViT-B/32 一种 CLIP 骨干，未验证在 ResNet 骨干或其他 ViT 变体（如 ViT-L/14）上的表现，方法对骨干的通用性未知。
- **与最新方法的跨数据集对比不完整**：跨数据集设置中未纳入 DCDL、SketchFusion 等最新方法，对比范围略逊于分类设置。
- **超参敏感性**：损失权重实验显示性能对 \( (\lambda_1, \lambda_2) \) 较敏感（如 \( \lambda_2=0.4 \) 时出现波动），但未给出权重选择的指导原则或自适应策略。
- **类别划分依赖 ImageNet 语义关系**：训练/测试类别划分排除了 ImageNet 中存在的类别，这意味着基准设置隐含了"CLIP 对测试类别已有知识"的前提，实际部署中完全未知类别情况下的表现可能低于实验报告值。

- **可解释性与失败分析不足**：论文未提供失败案例或误差分析，没有讨论在哪些类别/场景下仍会出现检索错误，也未分析跨数据集设置中性能下降的具体原因，这限制了对方法边界条件的理解。

### 9. 总结与总体评价

SeCo-SBIR 针对 ZS-SBIR 中"任务特定适应"与"零样本泛化"之间的根本矛盾，提出了一个双管齐下的解决方案：在适应侧，通过文本引导的多模态提示将语言知识深度注入视觉编码器，使可学习参数扎根于可迁移的类别级语义；在泛化侧，通过基于扰动的非对称一致性约束对新增容量进行正则化，抑制向已见类过拟合。这一"适应-约束"协同框架在三个标准基准、三种评测场景下均取得领先结果，特别是面对类别数更多、跨域差异更大的 TU-Berlin-Ext 和 QuickDraw-Ext 时增益尤为显著，从实证上支持了其核心论点。

作为一篇方法导向型论文，其亮点在于问题定义清晰、机制设计有针对性、消融证据链完整，对后续将视觉-语言模型（如 CLIP）应用于开放类别检索任务具有启发意义。然而，在实验覆盖面（骨干网络单一、消融仅限单数据集）和工程实用性（缺乏效率报告与开源信息）方面仍有提升空间。总体而言，本文是 ZS-SBIR 领域一篇论证扎实、思想明确的高质量工作，其"以语言知识引导适应、以一致性约束保护泛化"的设计范式值得借鉴。
