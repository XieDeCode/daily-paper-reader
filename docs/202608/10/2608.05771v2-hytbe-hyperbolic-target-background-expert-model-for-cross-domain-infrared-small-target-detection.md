## 摘要
红外小目标检测（IRSTD）在域一致评估下已取得显著进展，但当泛化到未见过的红外域时，检测器性能往往明显下降。现有方法主要通过增强目标响应和抑制背景干扰来提升检测性能。然而，当仅在有限的源域集合上训练时，它们学到的决策规则不可避免地建立在受限的源域目标-背景关系模式范围内。我们将这种跨域失效表述为目标-背景关系偏移：未见过的域可能表现出训练期间未观察到的关系模式，从而削弱从源域学到的判别能力。为解决此问题，我们提出HyTBE，一种双曲目标-背景专家模型，它扩展源域关系模式并利用显式关系线索自适应调整视觉表示。目标-背景关系干预选择性地扰动目标或背景，在保持有效监督的同时拓宽训练期间可观察的关系模式。随后，双曲关系建模将多尺度视觉线索映射到庞加莱球中，并根据每个特征标记到目标和背景锚点的相对距离来刻画其目标-背景关系。双曲引导的MoE适配器进一步利用这些双曲关系表示来校准多尺度视觉特征，并为不同关系模式聚合专家特定的特征校正。在NUAA-SIRST、NUDT-SIRST和IRSTD-1K上的留一域实验表明，HyTBE比竞争基线实现了更强的跨域泛化。

## Abstract
Infrared small target detection (IRSTD) has achieved substantial progress under domain-consistent evaluation, yet detector performance often degrades markedly when generalizing to unseen infrared domains. Existing methods primarily improve detection by enhancing target responses and suppressing background interference. However, when trained on only a limited set of source domains, their learned decision rules are inevitably established from a restricted range of source-domain target-background relation patterns. We formulate this cross-domain failure as target-background relation shift: unseen domains may exhibit relation patterns that are not observed during training, thereby weakening the discriminative capability learned from the source domains. To address this problem, we propose HyTBE, a Hyperbolic Target-Background Expert model that expands source-domain relation patterns and adaptively adjusts visual representations using explicit relation cues. The Target-Background Relation Intervention selectively perturbs either targets or backgrounds, broadening the observable relation patterns during training while maintaining valid supervision. Subsequently, the Hyperbolic Relation Modeling maps multi-scale visual cues into a Poincaré ball and characterizes the target-background relation of each feature token according to its relative distances to the target and background anchors. The Hyperbolic-guided MoE Adapter further uses these hyperbolic relation representations to calibrate multi-scale visual features and aggregate expert-specific feature corrections for different relation patterns. Leave-one-domain-out experiments on NUAA-SIRST, NUDT-SIRST, and IRSTD-1K demonstrate that HyTBE achieves stronger cross-domain generalization than competitive baselines.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究领域**：红外小目标检测（IRSTD），旨在从复杂红外背景中定位仅占几个像素、缺乏纹理和语义结构的弱小目标。
- **核心问题**：现有深度学习方法在**域一致（domain-consistent）** 评估下表现良好，但跨域部署时性能显著下降——在源域学到的决策规则在未见过的红外域中变得不可靠，出现漏检和虚警。
- **关键洞察——目标-背景关系偏移（Target-Background Relation Shift）**：由于红外小目标可判别性高度依赖其与周围背景的相对对比度、显著性、形态和上下文差异，跨域时目标外观与背景统计的联合变化导致决策边界失效。作者将这种源域关系分布 \(P_s(r, y)\) 与目标域关系分布 \(P_t(r, y)\) 的不一致形式化为关系偏移。
- **解决思路**：从**关系多样化**（扩大训练中观测到的关系模式）和**关系自适应**（显式刻画并校准特征的目标/背景关联）两条路径出发，提升跨域泛化能力。

## 2. 方法论：核心思想、关键技术细节

**整体框架**：HyTBE = 视觉编码器（ResBlocks）+ 三个核心模块（TBRI、HRM、HMA）+ RPCABlock 解码器，构建了"多样化关系 → 表征关系 → 按关系适配特征"的递进式流水线。

### 2.1 目标-背景关系干预（TBRI）

- **目的**：在不访问目标域的前提下，通过选择性扰动目标或背景来扩展源域可观测的关系模式，同时保持有效的监督信号。
- **机制**：每个训练样本以概率 \(p=0.5\) 激活，仅从目标干预和背景干预两类操作中采样并执行一种：
  - **背景干预**（2种算子）：全局成像风格扰动（亮度/对比度/伽马）和背景复杂度扰动（局部对比度、高频分量、噪声），保留目标区域和标注不变。
  - **目标干预**（5种算子）：显著性衰减（将目标向局部背景回归）、形态变换（拉伸/断裂/块状）、亮度增强、收缩（保留高对比度且靠近中心的像素）以及从源域随机采样目标插入到合法背景位置。
- **特点**：仅外观变化的干预保持标注不变，而改变目标支撑的干预会同步更新标注，确保监督有效性。

### 2.2 双曲关系建模（HRM）

- **目的**：在庞加莱球中显式刻画每个特征 token 的目标-背景关系。
- **流程**：
  1. 多尺度特征经 Patch Embedding（含最大池化和平均池化响应）投影为统一分辨率的关系 token \(u_i\)；
  2. 通过指数映射 \(z_i = \mathrm{Exp}_0^c(u_i)\) 将 token 映射到庞加莱球（曲率 \(c=1\)）；
  3. 构造两个相反锚点：目标锚点 \(a_t = \mathrm{Exp}_0^c(\rho)\) 和背景锚点 \(a_b = \mathrm{Exp}_0^c(-\rho)\)（\(\rho=0.05\)）；
  4. 关系得分定义为 \(s_i = d_c(z_i, a_b) - d_c(z_i, a_t)\)，正值为目标关系，负值为背景关系；
- **双曲关系损失**：\(L_{\mathrm{hyp}} = L_t + L_b\)，分别约束目标 token 满足 \(s_i \geq m\)、背景 token 满足 \(s_i \leq -m\)，同时保留单侧关系的多样性。

### 2.3 双曲引导的 MoE 适配器（HMA）

- **目的**：利用 HRM 产生的双曲关系表示校准多尺度视觉特征，并为不同关系模式聚合专家特定的特征校正。
- **Guide-Attention**：以视觉特征的平均池化作为 query、HRM 关系表示作为 key、原始特征作为 value，通过 Sigmoid 门控对通道响应进行校准。
- **MoE 适配器**：每个尺度的引导特征送入多个专家（残差块+线性门控），路由器通过 Softmax 预测输入相关的专家权重，加权融合专家校正并残差加回。
- **辅助损失**：负载均衡损失 \(L_{\mathrm{lb}}\) 和专家非一致性损失 \(L_{\mathrm{nc}}\) 分别鼓励专家使用均衡与校正多样化。

## 3. 实验设计

### 3.1 数据集与跨域协议

- **数据集**：NUAA-SIRST（427张）、NUDT-SIRST（1327张）、IRSTD-1K（1000张），三者来自不同红外成像场景，在目标尺度、形态、背景内容和成像风格上均有差异。
- **Benchmark 协议**：采用**留一域（leave-one-domain-out）** 评估，即每次用两个数据集作为源域训练，剩下的一个作为不可见目标域测试，形成三组设置：
  - NUAA-SIRST + NUDT-SIRST → IRSTD-1K
  - NUDT-SIRST + IRSTD-1K → NUAA-SIRST
  - NUAA-SIRST + IRSTD-1K → NUDT-SIRST
- **指标**：mIoU（均值交并比）、F-measure、检测概率 Pd、虚警率 Fa。
- **对比方法**：共10种代表性方法，包括 ALCNet、DNANet、UIUNet、MSHNet、SCTransNet、DRPCANet、PConv、MLPNet、PQGNet、NS_FPN。

### 3.2 实验结果概览

- **主实验**：在全部三个跨域设置中，HyTBE 在 mIoU 和 F-measure 上均取得最优；相比各设置第二名分别提升 0.48/0.42、4.92/3.17、5.45/4.15 个百分点；在 NUAA-SIRST 和 NUDT-SIRST 上 Pd 也为最高。Fa 并非所有设置最低，但整体平衡性最好。

## 6. 主要结论与发现

1. **关系偏移是可实证的跨域失效机制**：源域训练模型在未见域中的漏检率与目标相对源域关系模式的偏差程度正相关（Spearman ρ=0.25）。
2. **关系干预有效**：同时进行目标侧和背景侧扰动比单侧干预带来更显著的增益（mIoU 从 71.03% 提升至 78.58%），两者提供互补的关系模式。
3. **双曲几何优于欧氏**：双曲关系建模在预测一致性和虚警抑制上均优于欧氏距离版本。
4. **关系引导的专家适配是有效的组合**：Guide-Attention 和 MoE 各自独立提升性能，组合后达到最佳整体效果。
5. **轻量高效**：HyTBE 以仅 1.13M 参数在三个跨域设置中均超越了参数量大得多的方法，展示了良好的效率-性能权衡。
