## 摘要
提示调优以少量可训练参数适应视觉-语言模型，但现有方法在效率与适应性之间权衡：静态文本提示可能过拟合源类别，图像条件提示增加每实例计算量，多模态调优则修改视觉分支。我们提出VDA（视觉分布锚定），一种无需训练的目标适应框架，通过从无标签目标池离线估计的类级视觉原型增强冻结的语义分类器。我们首先探究原型能否从类名合成。文本到质心映射器能重建保留的源原型，但在数据集偏移下失败，因为类名指定语义身份而非目标域外观。一项内省分析确认真实目标原型具有高度判别性。因此，VDA利用冻结的语义和域模板分类器将无标签目标图像划分为类相关分组。置信度排序的图像特征形成归一化原型，并通过一个全局权重与语义分类器融合。适应过程不需要目标标签、目标端优化、统一类先验假设、迭代细化或测试查询访问，并产生一个固定、可缓存的分类器。控制实验表明，类特定分组驱动性能提升，且视觉上局部的伪标签错误即使类别不正确仍可能有用。在十个ImageNet到目标的迁移中，相同的冻结设计分别将零样本CLIP、TCP和MaPLe提升3.22、3.39和3.35个百分点，在每种设置下均改善十个目标中的九个。其视觉校正进一步将无泄漏的PromptKD提升2.79个百分点，与零样本、源提示、多模态提示和目标蒸馏分类器互补。

## Abstract
Prompt tuning adapts vision--language models with few trainable parameters, but existing approaches trade off efficiency and adaptation: static textual prompts can overfit source classes, image-conditioned prompts add per-instance computation, and multimodal tuning modifies the visual branch. We propose VDA (Visual Distribution Anchoring), a training-free target adaptation framework that augments a frozen semantic classifier with class-level visual prototypes estimated offline from an unlabeled target pool. We first ask whether prototypes can be synthesized from class names. A text-to-centroid mapper reconstructs held-out source prototypes but fails under dataset shift because class names specify semantic identity, not target-domain appearance. An oracle analysis confirms that true target prototypes are highly discriminative. VDA therefore uses frozen semantic and domain-template classifiers to partition unlabeled target images into class-correlated groups. Confidence-ranked image features form normalized prototypes, fused with the semantic classifier using one global weight. Adaptation requires no target labels, target-side optimization, uniform class-prior assumption, iterative refinement, or test-query access, and yields a fixed, cacheable classifier. Controlled experiments show that class-specific partitioning drives gains and that visually local pseudo-label errors can remain useful despite being class-incorrect. Across ten ImageNet-to-target transfers, the same frozen design improves zero-shot CLIP, TCP, and MaPLe by 3.22, 3.39, and 3.35 points, respectively, improving nine of ten targets in every setting. Its visual correction further improves leakage-free PromptKD by 2.79 points, complementing zero-shot, source-prompted, multimodal-prompted, and target-distilled classifiers.

## 1. 核心问题与整体含义

- **背景**：视觉-语言模型（如 CLIP）通过比较图像表示与类名构造的文本分类器实现零样本识别。提示调优（Prompt Tuning）用少量可训练参数提升分类器性能，但现有方法面临效率与适应性的权衡：静态文本提示（如 CoOp）可能过拟合源类；图像条件提示（如 CoCoOp）逐查询计算成本高；多模态方法（如 MaPLe）修改视觉分支，复杂度进一步增加。
- **核心问题**：源域训练的分类器可能保留目标类的“语义身份”，却未能捕捉该类别在目标域中的“视觉呈现方式”。类名（如“forest”）只约束语义身份，不指定其在目标域（如卫星俯瞰图）中如何视觉呈现。作者追问：能否直接从类名合成目标域视觉原型？答案是否定的——文本到质心的映射器能准确重建源域质心，但在跨域迁移时失败。
- **整体含义**：VDA 提供一个完全免训练的适配框架，利用无标签目标图像的类级视觉原型，在不改动源提示训练、不生成逐查询提示、不引入目标标签或训练的前提下，弥补语义分类器对目标域视觉外观的缺失，实现了高效、可缓存、可部署的目标域适配。

## 2. 方法论

VDA（Visual Distribution Anchoring）是一个**无需训练的目标适应框架**，其核心流程如下：

- **问题设定**：给定目标类词汇表 `C` 和无标签目标域训练池 `U`（与测试集不相交），适配一个冻结的语义分类器 `s_sem`。
- **图像编码**：用冻结的 CLIP 图像编码器 `f_V` 将每张目标图像编码为单位归一化向量 `v_i = norm(f_V(x_i))`。
- **域感知硬划分**：
  - 构造一个冻结的域模板分类器 `s_D`，将类名与已知的域描述（如“a true-color overhead satellite image of {class}”）结合，通过文本编码器得到域模板文本向量。
  - 对每张无标签图像，计算语义分类器与域模板分类器得分的平均值 `a_ic = 1/2(s_sem(x_i,c) + s_D(x_i,c))`，取 argmax 得到唯一伪标签 `c_hat_i`。
  - 按预测类别将目标池划分为不相交的分组 `I_c`。
- **上限伪支持选择**：分组内按分配置信度 `q_i = softmax(a_i)_{c_hat_i}` 排序，保留每类至多 K=32 张图像（不足 K 则全部保留）。支持预算 K 是上限而非平衡约束。
- **目标视觉原型**：每类中保留图像的归一化特征取平均后再次归一化，得到目标视觉原型 `mu_c`。
- **语义-视觉融合**：以单一全局权重 `λ=0.2` 将视觉原型得分 `s_vis` 与语义分类器得分 `s_sem` 融合：`s_VDA = (1−λ_c)·s_sem + λ_c·s_vis`，其中无支持分配的类保留纯语义分类器（λ_c=0）。
- **共享特征空间下的缓存**：当语义分类器与视觉原型共享 CLIP 特征空间时，融合退化为对类向量 `w_c` 的线性插值，得到一个固定、可缓存的分类器，推理时仅需一次图像编码和一次矩阵乘法。
- **关键设计决策**：硬划分（非软分配）、置信度排序上限、单次过、不做迭代细化、不假设均匀类先验。设计选用的 K 和 λ 在开发集上选定后固定不变，域模板、归一化、聚合规则跨数据集一致。

## 6. 主要结论与发现

1. **名称到原型的映射存在根本局限**：线性映射器能准确重建源域质心（held-out 余弦 0.922–0.933，五折外推 0.930），但在目标域上表现不佳（平均 49.49% vs 语义基线 49.91%）。目标域几何分析显示：原始余弦 0.814 但平均居中后仅 0.387，检索 top-1 仅 17.8%，Spearman 相关 0.488——原始相似度夸大了类特定结构恢复程度。
2. **真实目标原型高度可判别**：内省分析（oracle）显示 16-shot 真实目标原型直接分类将均值从 49.91% 提升到 66.16%，保守融合也达 60.52%，说明“类级目标视觉证据”的信息量大，但无法由类名替代。
3. **硬划分驱动收益，而不是通用目标统计**：公共目标质心、打乱的伪原型、随机目标分配均不能复制 VDA 增益；硬类对应的原型选择贡献了主要提升（随机类内采样 53.23% vs 置信度排序 54.92%）。
4. **置信度排序提供较小但真实的收益**（整体 +1.69 点），且呈域依赖特征（EuroSAT +5.80；Aircraft 无增益）。
5. **视觉上局部的伪标签错误仍有用**：FGVC-Aircraft 上伪标签精度仅 32.9%，但错误支持与真实类原型相似度显著高于随机错误对，且强烈富集正确飞机家族（17.1% vs 1.25%）和制造商（38.4% vs 7.98%）。
6. **类级视觉证据跨语义分类器互补**：同一固定 VDA 流程提升零样本 CLIP、TCP、MaPLe、无泄漏 PromptKD 分别 +3.22、+3.39、+3.35、+2.79，每种设置均提升九/十个目标。
7. **软分配失败**：均衡 Sinkhorn 分配产生高熵（0.949–0.994）近似混合的原型，迭代细化反而退化（直接原型从 36.52% 降至 27.91%）。

## 7. 优点

- **训练免费、协议高度透明**：无目标标签、无目标端优化、无验证集停止、无均匀类先验、无迭代细化、无测试查询访问，适配后输出固定可缓存分类器，推理成本与普通 CLIP 一致。
- **机制剖析深入**：不仅报告性能提升，还从原型几何（raw vs mean-centered cosine、检索 top-1、成对 Spearman）、错误伪标签的结构性（家族/制造商富集）等角度定位了改善来源，对“为什么有效”给出有力解释。
- **协议分层严谨**：将发布版 InMaP（不同目标图像协议）与匹配复现明确区分，将 PromptKD 的发布版结果（包含测试集验证选择）仅作协议不同的上下文，不混排名。这种透明性显著增强了结果可信度。
- **跨架构泛化验证扎实**：对四类语义分类器的测试覆盖了从零样本→源提示→多模态提示→目标蒸馏的递进难度，且使用相同的固定 VDA 配置，证明了方法的通用性。
- **消融体系完整**：对 K、λ、置信度排序、域模板、类特定性、池大小做系统评估，且含统计变异性标注（随机条件多重复、多种子 ± 值）。
- **现实部署取向清晰**：文章明确区分“类拥有支持”与“类无支持”两种情形，并指出 VDA 主要精炼被语义初始化识别出的类，诚实承认无法可靠恢复零支持类。

## 8. 不足与局限

- **依赖无标签目标池**：VDA 不是纯粹的源域/名称-only 方法，需要能代表评估域的无标签目标训练池。池小、有偏差、时间不匹配或缺类时性能可能下降。部分池（50%）能改善全五数据集，但完整池在所有数据集上最佳。
- **依赖人工域描述**：域模板是手动指定的额外先验知识。当部署域未知、异构或难以描述时，模板选择可能需要人工努力；域模板对结果有影响（semantic-only 排名 54.23% vs 域模板 54.92%）。
- **限制在原始 CLIP 特征空间**：所有原型用 OpenAI CLIP ViT-B/16 估计，未验证在其他骨干网上的可迁移性；MaPLe 和 PromptKD 是 logit 级挂接，推理时需要额外的 raw-CLIP 分数流，并非完全单流。
- **困难类别覆盖不足**：K=32 是上限而非实际达到的计数；EuroSAT 各类均达 32 支持，而 Aircraft 约 45% 的类、Cars 约 53% 的类未达到；即使保留零支持类的语义分类器，由于竞争类别的修正也可能改变多分类决策边界，无法保证正确性。
- **单一全局融合权重**：固定 λ=0.2 稳定但无法利用异常准确的原型；类级可靠性权重在实验中出现跨类尺度不一致和 argmax 校准问题，被放弃，且未找到无标签的可靠权重估计方案。
- **评估协议不完全资源等价**：构建的匹配 InMaP 为无细化版本，发布版 InMaP 的数字（平均 70.46%）被单独报告；PromptKD 使用更大的 ViT-L/14 教师和更多优化预算，与 VDA 的对比并非严格同资源。
