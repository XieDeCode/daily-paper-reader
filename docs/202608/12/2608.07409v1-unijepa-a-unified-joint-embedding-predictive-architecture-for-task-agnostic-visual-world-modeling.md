## 摘要
联合嵌入预测架构（JEPA）已成为在紧凑潜在空间中进行自监督世界模型学习的原则性框架，然而现有方法彼此割裂：有些在潜在空间预测单幅图像的掩蔽部分（I-JEPA），有些学习预测全局光度变换（Image World Models），而视频级JEPA则预测未来时间状态，并针对动作条件规划进行后训练（V-JEPA~2、DINO-World、DINO-WM）。这些目标被视为不同的配方，各自配备独立的编码器、预测器和防坍缩正则化器，阻碍了单一模型统一图像级和视频级世界建模。我们提出UniJEPA，一种统一JEPA，在共享潜在空间中联合学习光度预测（图像级变换）和时间预测（视频级下一状态动力学）。由一个下一嵌入预测损失和高斯正则化器组成的单一端到端目标，可产生可证明防坍缩的编码器-预测器对，且无需EMA、停止梯度或预训练编码器即可从原始像素进行训练。我们表明，同一潜在空间支持可控抽象：光度预测学习不变结构，而时间预测学习等变动动力学。在离线轨迹上进行动作条件后训练后，UniJEPA通过将目标特征视为预测目标来实现零样本规划。在图像、视频和控制基准上，UniJEPA在仅需单一损失超参数的情况下匹配或超越任务特定JEPA，并且在可比精度下，其规划速度比生成式世界模型快数十倍。

## Abstract
Joint-Embedding Predictive Architectures (JEPAs) have emerged as a principled framework for self-supervised learning of world models in compact latent spaces, yet existing methods are fragmented: some predict masked parts of a single image in latent space (I-JEPA), others learn to predict global photometric transformations (Image World Models), while video-scale JEPAs predict future temporal states and are post-trained for action-conditioned planning (V-JEPA~2, DINO-World, DINO-WM). These objectives are treated as distinct recipes with separate encoders, predictors, and anti-collapse regularizers, hindering a single model from unifying image-level and video-level world modeling. We present UniJEPA, a unified JEPA that jointly learns photometric prediction (image-level transformations) and temporal prediction (video-level next-state dynamics) in one shared latent space. A single end-to-end objective, composed of a next-embedding prediction loss and a Gaussian regularizer, yields a provably anti-collapse encoder-predictor pair trainable from raw pixels without EMA, stop-gradient, or pre-trained encoders. We show that the same latent space supports controllable abstraction: photometric prediction learns invariant structure while temporal prediction learns equivariant dynamics. After action-conditioned post-training on offline trajectories, UniJEPA enables zero-shot planning by treating goal features as prediction targets. On image, video, and control benchmarks, UniJEPA matches or surpasses task-specific JEPAs while requiring a single loss hyperparameter, and plans up to tens of times faster than generative world models at comparable accuracy.

### 2. 论文提出的方法论

**核心思想：**
- **统一目标**：将光度预测（图像级变换）与时间预测（视频级下一状态动力学）归结为同一潜在预测任务的两种实例，在一个共享潜在空间中联合优化。
- **单一防坍缩正则化器**：采用一个高斯正则化器（Gaussian regularizer）防止表征坍缩，无需 EMA、stop-gradient 或预训练编码器，且具有可证明的理论保证。
- **可控抽象**：光度预测学习**不变结构**，时间预测学习**等变动动力学**；调整两项损失的相对权重，可在不变性—等变性谱系上连续调节表征的抽象层级。

**技术细节：**

1. **编码器与预测器设计**：
   - 编码器 fθ 将观测 x 映射为潜在嵌入 z = fθ(x)；
   - 预测器 gψ 以条件潜在（及可选动作）为输入，预测目标潜在表示；
   - 光度预测与时间预测共享同一编码器与同一预测器，仅条件输入和目标不同。

2. **统一损失函数**：
   - 光度预测损失：Lphoto = E[‖gψ(fθ(x), τ) − fθ(τ(x))‖²]；
   - 时间预测损失：Ltemp = E[‖gψ(fθ(xt), at) − fθ(xt+1)‖²]；
   - 正则化项：R(θ) 迫使潜在分布接近球形高斯；
   - 总目标：L = Lphoto + Ltemp + α·R，仅需一个超参数 α。

3. **防坍缩理论（定理 3.1）**：
   - 若编码器坍缩为常数，则任意投影方向上方差为零，导致 χ² 正则化项无界；
   - 因此最小化 R ≤ ε 可保证编码器非退化，潜在分布协方差正定且最小特征值 λmin ≥ 1 − O(ε)；
   - 由此无需 EMA 或 stop-gradient 即可端到端稳定训练。

4. **动作条件规划**：
   - 预训练后冻结编码器，在离线轨迹上对预测器进行动作条件后训练；
   - 规划采用模型预测控制（MPC），将目标特征作为预测目标，在潜在空间中进行采样式优化；
   - 因预测在紧凑潜在空间完成，每次 rollout 仅为预测器的一次前向传播，规划速度显著快于像素级生成式世界模型。

**训练流程（Algorithm 1）：**
```
1. 预训练：采样光度变换样本和视频时间样本，按统一目标更新 θ, ψ；
2. 后训练：冻结 θ，在离线轨迹上以时间预测损失微调 ψ；
3. 规划：给定当前潜状态 z0 和目标 zg，通过 MPC 求解最优动作序列。
```

### 6. 论文的主要结论与发现

### 7. 优点

- **概念创新**：首次将图像级和视频级 JEPA 世界建模统一到单一潜在空间，消解了以往 JEPA 家族的碎片化问题；
- **端到端简化**：无需 EMA、stop-gradient、预训练编码器或像素重建，仅需单一损失超参数，大幅简化训练流程；

### 8. 不足与局限

- **共享预测器可能受限**：光度预测与时间预测共享同一个预测器，在长时序、多模态或复杂任务中，简单的共享机制可能不足以表达两种预测所需的全部条件关系；
- **正则化的容量限制**：高斯正则化虽然防坍缩，但在极大模型规模下可能约束潜在表示的容量与灵活性；
- **无语言指令支持**：与视觉-语言-动作模型（如 RT-2、OpenVLA 等）不同，UniJEPA 目前无法消费语言指令，限制了其作为通用智能体基座的能力；
- **算力报告不充分**：对 GPU 型号、数量、训练总时长的报告不够细致，消融实验的硬件成本未提供，可复现性受损；
- **规划公平性存疑**：与 DINO-WM 的对比中，后者使用冻结的 DINOv2 预训练编码器，而 UniJEPA 端到端训练编码器，二者在数据需求、计算预算和归纳偏置上存在根本差异，需要更细化的公平性讨论；
- **实验覆盖有限**：部分消融结果缺失（如 temporal loss 消融的 SSv2 指标），规划任务类型有限，缺少大规模真实机器人平台验证；
- **潜在的风险**：作为世界模型，预测的动力学可能不完美，在安全关键或自主场景部署前需要额外验证，论文未能给出足够的可靠性边界分析。
