## 摘要
无监督域适应是一类广泛使用的方法，它利用有标签源领域的知识来训练模型，使其在相关的无标签目标领域上表现良好。这类方法通常引入一个辅助的适应相关任务，该任务可以整合到多任务范式中，旨在将多个单任务模型合并为一个统一的架构。在本文中，我们提出在极端类别不平衡的现实场景下，将域适应与多任务平衡相结合。为此，我们提出了一个组合框架来涵盖并验证这些方法，并在切伦科夫望远镜阵列天文台（CTAO）的物理背景下评估其性能。结合对若干相关适应技术的比较研究，我们强调了极端标签偏移的影响，并扩展了关于重要性加权以修正该影响的研究。完整的代码和结果已发布并作为开源资源在Zenodo上提供。

## Abstract
Unsupervised domain adaptation is a widespread set of methods that leverages the knowledge of a labeled source domain to train a model to perform well on a related unlabeled target domain. They generally introduce an auxiliary adaptation-related task that can be integrated into the multitask paradigm, which aims to merge multiple single-task models into a unified architecture. In this paper, we propose to associate domain adaptation and multitask balancing in the realistic context of an extreme class imbalance. Therefore, we propose a combined framework to cover and validate these approaches, and evaluate its performance in the physics-based context of the Cherenkov Telescope Array Observatory (CTAO). Along with a comparative study of some relevant adaptation techniques, we highlight the impact of extreme label shift and extend the investigations on importance weighting to rectify it. The complete code and results are published and available as open-source resources on Zenodo.

## 二、方法论

### 2.1 核心思想
- 将UDA作为一种额外的辅助任务纳入多任务学习框架，并使用自动多任务平衡算法（GradNorm、不确定性加权UW）替代手动权重（MW）。
- 针对极端标签偏移，引入**条件域适应**：仅使用源域中与目标域共有的类别（如质子）进行域对齐，从而避免目标域中极少量的伽马样本对域判别造成误导。
- 引入**梯度层（Gradient Layer, GL）**，对域适应任务的梯度进行调度，缓解早期训练中域适应任务与物理重建任务之间的梯度冲突。

### 2.2 关键技术细节
- 基础网络为 **γ-PhysNet**，包含ResNet特征提取器、注意力机制和多任务分支（类别分类、能量回归、方向回归、冲击点回归）。
- 三种UDA方法：
  - **DANN**：对抗域判别，使用梯度反转层（GRL）。
  - **DeepJDOT**：基于最优传输的Wasserstein距离对齐深层特征。
  - **DeepCORAL**：最小化源/目标特征二阶统计量（协方差）差异。
- 多任务平衡策略：
  - **MW**：网格搜索手动设置权重（作为基线）。
  - **UW**：基于同方差不确定性自动加权损失。
  - **GN**：基于梯度范数和训练速率自动调整任务权重。
- 条件UDA的核心修改：
  - **CDANN**：域分类器损失仅使用源域质子与目标域所有样本计算（公式16）。
  - **CDeepJDOT**：最优传输成本矩阵仅在源域质子与目标样本之间计算（公式17）。
  - **CDeepCORAL**：源域协方差矩阵仅用源域质子计算（公式18）。
- 重要性权重定义（公式14）：
  \[
  \omega(\gamma) = \frac{P_T(\gamma)}{P_S(\gamma)} \approx 0, \quad
  \omega(p) = \frac{P_T(p)}{P_S(p)} > 1

  用于估计目标域中伽马与质子比例，并将域适应任务聚焦于质子主导的实际分布。

## 六、主要结论与发现

1. **UDA + MTB可以双赢**：在多任务框架下引入UDA，使用UW或GN自动平衡，不仅省去手动调参，还**达到或超过手动权重（MW）的性能**，尤其在数字分类中。
2. **梯度层（GL）对DeepJDOT特别有效**：DeepJDOT的域任务梯度在训练初期范数极大且与分类任务负冲突，GL能显著稳定训练；但对DANN和DeepCORAL反而有损。
3. **条件UDA可缓解极端标签偏移**：CDANN（条件DANN）结合UW在目标域上取得最佳能量偏差和分辨率，恢复至接近无标签偏移时的性能；CDeepCORAL结合GN也改善了低能段指标。
4. **标签偏移会恶化回归指标，但对AUC影响较小**：当目标域伽马比例降至 \(10^{-2}\) 以下后，模型性能变化趋于平缓，说明条件化主要对“存在强烈标签偏移”而非精确比例敏感，对真实比例估计误差具鲁棒性。
5. **NSB是协变量偏移的主要来源**：当测试NSB水平增加时，γ-PhysNet的AUC从0.87降至0.50（随机水平），能量分辨率恶化严重，凸显UDA必要性。
6. **方法选择建议**：DeepJDOT虽理论优美，但计算量大且训练不稳定，不适宜大规模真实数据；**CDANN + UW**被选为后续真实数据应用的最有潜力方法。
7. **开源贡献**：完整代码和结果发布在Zenodo，便于复现和后续研究。
