## 摘要
遥感基础模型提供跨传感器、分辨率和地理区域的可迁移地球观测表示，但大多数模型与自然语言的对齐仍较弱，限制了自然语言档案检索、图像-文本检索和基于问题的分析。我们提出AlignJEPA，一种受JEPA启发的预测性视觉-语言对齐框架，用于遥感基础模型。AlignJEPA使用预训练的AnySat视觉编码器和RemoteCLIP文本编码器，仅训练轻量级预测对齐网络。该框架不依赖全局图像-文本对比对齐，而是从掩蔽的视觉基础模型标记中预测遥感文本嵌入。其掩蔽感知的多尺度预测对齐器在细粒度、区域和全局尺度上聚合可见标记，通过跨尺度Transformer联合建模，并使用学习查询池化将所得表示投影到文本空间。训练结合语义预测和双向对比检索。我们在BigEarthNet.txt上训练和评估AlignJEPA以进行自然语言Sentinel检索，在RSICD上评估跨数据集适应性，并仅将RSVQA用作闭集表示探针。AlignJEPA为将地球观测基础模型与语言对齐提供了一条参数高效的途径。

## Abstract
Remote sensing (RS) foundation models provide transferable Earth observation representations across sensors, resolutions, and geographies, yet most remain weakly aligned with natural language, limiting natural-language archive search, image-text retrieval, and question-conditioned analysis. We propose AlignJEPA, a JEPA-inspired predictive vision-language alignment framework for remote sensing foundation models. AlignJEPA uses a pretrained AnySat visual encoder and a RemoteCLIP text encoder while training only a lightweight predictive alignment network. Instead of relying on global image--text contrastive alignment alone, the framework predicts remote-sensing text embeddings from masked visual foundation-model tokens. Its mask-aware multi-scale predictive aligner aggregates visible tokens at fine, regional, and global scales, jointly models them with a cross-scale Transformer, and projects the resulting representation into the text space using learned query pooling. Training combines semantic prediction with bidirectional contrastive retrieval. We train and evaluate AlignJEPA on BigEarthNet.txt for natural-language Sentinel retrieval, evaluate cross-dataset adaptation on RSICD, and use RSVQA only as a closed-set representation probe. AlignJEPA provides a parameter-efficient route for aligning Earth observation foundation models with language.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：遥感（RS）基础模型已在跨传感器、分辨率和地理区域的表示学习上取得了显著进展（如 SatMAE、Scale-MAE、CROMA、DOFA、AnySat、Prithvi-EO-2.0 等）。然而，绝大多数遥感基础模型**仅停留在纯视觉层面**，与自然语言的语义空间缺乏直接对齐，这严重限制了以下实际应用：
  - 自然语言档案库搜索（如“有森林斑块和附近水体的农田”）
  - 图像–文本跨模态检索
  - 基于语言条件的地理空间分析/问答
- **现有方案的不足**：
  - 已有的遥感视觉-语言模型（如 RemoteCLIP、GeoRSCLIP）主要依赖全局图像–文本对比对齐，没有充分利用预训练遥感基础模型（如 AnySat）产生的**空间 token 表示**。
  - 指令微调类模型（如 GeoChat、SkyEyeGPT）需要大量生成式指令数据，训练成本高。
  - 从头训练一个遥感视觉-语言模型代价高昂，且在传感器、分辨率、地理区域多变的情况下难以泛化。
- **核心问题**：如何在不更新底层视觉/文本编码器的前提下，以参数高效的方式将预训练遥感基础模型的视觉表征映射到遥感文本嵌入空间，从而实现自然语言检索与语言条件化分析？

## 2. 论文提出的方法论

### 2.1 核心思想（JEPA 理念的迁移）

AlignJEPA 借鉴 JEPA（Joint-Embedding Predictive Architecture）的**预测式表征学习**思想，但做了关键改变：
- 传统的 JEPA（如 I-JEPA、V-JEPA）从可见上下文预测**缺失的视觉潜在表示**。
- AlignJEPA 则从部分可见的遥感视觉 token 中预测**冻结的遥感文本嵌入**（RemoteCLIP 文本空间），从而将预测原则迁移到视觉-语言对齐任务。

### 2.2 整体架构

系统由三个部分组成（见图 1）：
1. **冻结的视觉编码器**：使用 AnySat（预训练遥感基础模型），提取空间视觉 token：
   \[
   Z_v = E_v(x) \in \mathbb{R}^{B \times N \times D_v}
   \]
2. **冻结的文本编码器**：使用 RemoteCLIP 文本编码器，产生 L2 归一化的文本嵌入：
   \[
   z_t = E_t(t), \quad z_t = z_t / \|z_t\|_2
   \]
3. **可训练的对齐网络**：预测式对齐网络 \( P_\theta \)，实现：
   \[
   \hat{z}_{v \to t} = P_\theta(Z_v, \Omega_c)
   \]
   其中 \( \Omega_c \) 为可见 token 索引集合。

### 2.3 预测对齐网络的关键技术细节

网络由以下组件级联而成：

1. **Token 投影**：线性层 + LayerNorm + 非线性激活，将视觉 token 投影到统一隐藏维度 D。
2. **视觉上下文掩码**：默认采用随机掩码，掩码率 0.5，不重建被掩码 token，而是以可见 token 为条件预测文本嵌入。
3. **掩码感知的多尺度上下文构建**（Mask-Aware Multi-Scale Context）：
   - **细粒度尺度**：所有可见的投影 token。
   - **区域尺度**：对每个非重叠 2×2 空间区域做掩码感知池化：
     \[
     h_R^r = \frac{\sum_{i \in r} m_i h_i}{\sum_{i \in r} m_i + \epsilon}
     \]
   - **全局尺度**：全局可见 token 的池化：
     \[
     h_G = \frac{\sum_{i=1}^{N} m_i h_i}{\sum_{i=1}^{N} m_i + \epsilon}
     \]
   - 被掩码 token 不参与区域/全局池化，防止信息泄漏。
   - 各尺度添加可学习的尺度嵌入（\( e_F, e_R, e_G \)）后拼接成多尺度序列。
4. **跨尺度 Transformer**：共享轻量级 Transformer（6 层、8 头、维度 512）对三个尺度联合建模，捕获细粒度局部证据、区域结构与场景级上下文的交互。
5. **学习查询池化**：使用一个可学习的查询 token 通过注意力机制聚合得到单一语义表示。
6. **文本空间投影**：将池化表示投影到 RemoteCLIP 文本嵌入维度并 L2 归一化。

### 2.4 训练目标

总损失函数为：
\[
\mathcal{L} = \mathcal{L}_{pred} + \lambda \mathcal{L}_{con}
\]
其中 \(\lambda = 1.0\)，\(\tau = 0.07\)。

- **语义预测损失（\( \mathcal{L}_{pred} \)）**：最小化预测文本嵌入与目标文本嵌入的余弦距离：
  \[
  \mathcal{L}_{pred} = \frac{1}{B} \sum_{i=1}^{B} \left( 1 - \hat{z}_{v \to t,i}^\top z_{t,i} \right)
  \]
- **双向对比检索损失（\( \mathcal{L}_{con} \)）**：采用多正例（multi-positive）InfoNCE 形式，同一图像的多条 caption 均视为正样本，包含图像到文本（\( \mathcal{L}_{v2t} \)）和文本到图像（\( \mathcal{L}_{t2v} \)）两个方向的损失：
  \[
  \mathcal{L}_{con} = \frac{1}{2}(\mathcal{L}_{v2t} + \mathcal{L}_{t2v})
  \]

### 2.5 核心设计原则

- 视觉和文本编码器全程**冻结**；
- 仅训练约 2000 万参数的对齐网络；
- 检索/推理时关闭掩码，使用全部视觉 token。

## 6. 论文的主要结论与发现

1. **参数高效对齐可行**：冻结 AnySat + RemoteCLIP，仅训练 2000 万参数的对齐网络，即可实现有效的视觉-语言对齐。
2. **预测式语义对齐优于纯对比对齐**：在 BigEarthNet.txt 上，AlignJEPA（T2I R@1=20.72）显著优于 AnySat+对比对齐（16.90）和线性投影（10.79）。
3. **掩码预测带来增益**：0.5 的随机掩码率优于无掩码设置（R@1 从 18.75 提升到 21.31），说明部分可见上下文的预测任务能够促进语义表征学习；过高的掩码率（0.75）则损害性能。
4. **多尺度 + 查询池化优于替代方案**：跨尺度 Transformer + 学习查询池化的组合优于线性投影、MLP 和均值池化。
5. **跨数据集适应能力**：在 RSICD 上，AlignJEPA 在受控协议下取得最优结果（T2I R@1=16.49，I2T R@1=23.41），验证了从 Sentinel 到 RGB 航空影像的跨域迁移潜力。
6. **表示质量提升**：RSVQA 上 AlignJEPA 探针（LR Avg=91.84，HR Avg=89.15）优于 AnySat（88.07/81.73）和对比对齐（86.57/85.36）探针，说明语言对齐有助于下游问题条件预测。

## 7. 优点

- **参数高效性**：视觉/文本编码器完全冻结，仅训练约 2000 万参数的轻量网络，训练成本大幅降低。
- **方法论新颖**：将 JEPA 的预测哲学从"预测视觉潜在"拓展到"预测文本嵌入"，为 RS 视觉-语言对齐提供了新范式。
- **掩码感知多尺度设计巧妙**：区域池化和全局池化都考虑了掩码位置，防止信息泄漏；细-区域-全局三级语义粒度兼顾局部证据与整体上下文。
- **受控对比实验设计规范**：以相同的 AnySat 冻结编码器为基础，构建了线性投影和对比对齐两个强基线，公平地隔离出各组件贡献。
- **下游任务覆盖合理**：从检索（主任务）到跨数据集迁移再到表示探针，评价层次清晰。
- **消融实验全面**：覆盖掩码策略、损失函数、网络架构三个关键维度，证据链完整。

## 8. 不足与局限

- **依赖冻结目标空间的表达能力**：RemoteCLIP 文本空间是固定的，AlignJEPA 本质上做的是**跨模态表示映射**，不具备组合式语言推理能力，语义表达上限受限于远程CLIP 嵌入空间的质量。
- **域偏移问题**：BigEarthNet.txt（Sentinel 多光谱）到 RSICD（RGB 航空）之间存在显著的传感器、分辨率、风格和标注分布差异，虽然取得了较好结果，但性能仍受域偏移限制。
- **监督范围有限**：仅使用图像-caption 对，未利用 BigEarthNet.txt 中的 VQA 对和指代表达式标注；这对检索任务是有意为之，但也说明当前框架尚未探索更丰富的语言监督形式。
- **RSVQA 评估方式受限**：仅作为闭集表示探针，不能反映生成式 VQA 或复杂推理能力，需谨慎解读。
- **参考对比的公平性瑕疵**：外部参考模型（RSVQA 专家模型、RSICD 已发表方法）的训练协议不同，不能做严格横向对比。
- **几何先验假设**：2×2 固定区域池化假设图像具有规整的空间结构，对于不规则地理对象或极端宽高比的遥感影像可能不够自适应。
- **未探索的方向**：更长文本目标、短语级监督、指代表达式、空间定位/grounding、更多传感器模态（如 SAR 多模态对齐）。
- **可复现性细节有限**：未报告具体训练时长、内存占用等资源指标，也未提及代码/模型发布计划。
