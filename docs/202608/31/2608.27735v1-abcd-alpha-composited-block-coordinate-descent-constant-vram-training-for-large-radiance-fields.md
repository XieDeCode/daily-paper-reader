## 摘要
我们提出了ABCD（Alpha合成块坐标下降），一种用于alpha合成辐射场的核外训练框架，此处针对3D高斯泼溅进行实例化。我们的方法将训练重新表述为对空间划分的块坐标下降：每次仅激活一个参数块，而所有其他块被冻结。利用alpha混合的结合性，这些非活动区域可以被预渲染并折叠为前景和背景RGBA图像。因此，对于固定的划分大小和图像分辨率，峰值显存相对于整个场景范围变为O(1)，而不是随完整场景大小增长。这使得显存有限的GPU能够训练原本无法装入核心内存的场景。在实验中，我们的方法紧密保持了3DGS的重建质量，PSNR下降小于5%，而消融组合的ABCD则遭受约40%的退化。我们的代码可在https://github.com/shiukaheng/abcd找到。

## Abstract
We present ABCD (Alpha-Composited Block Coordinate Descent), an out-of-core training framework for alpha-composited radiance fields, instantiated here for 3D Gaussian Splatting. Our method reformulates training as block coordinate descent over spatial partitions: only one block of parameters is active at a time, while all others are frozen. By exploiting the associativity of alpha blending, these inactive regions can be pre-rendered and collapsed into foreground and background RGBA images.   As a result, for fixed partition size and image resolution, peak VRAM becomes O(1) with respect to total scene extent, rather than growing with full scene size. This enables GPUs with limited memory to train scenes that would otherwise not fit in core. In experiments, our method closely preserves the reconstruction quality of 3DGS, with less than 5% PSNR degradation, while ABCD with compositing ablated suffers roughly 40% degradation.   Our code can be found at https://github.com/shiukaheng/abcd

## 1. 核心问题与整体含义（研究动机与背景）

- 辐射场（Radiance Fields）技术正被广泛采用，但训练大规模场景时，完整场景参数需要同时驻留 GPU 显存，导致显存需求随场景规模线性增长，单卡 GPU 难以胜任。
- 现有解决方案如多 GPU 分布式训练成本高昂；分块训练再合并的方法（partition-train-merge）会因不同分块共享相机视角而产生严重伪影，且依赖分解质量。
- 本文提出 **ABCD（Alpha-Composited Block Coordinate Descent）**，一种针对 alpha 合成辐射场的核外（out-of-core）训练框架，实例化为 3D Gaussian Splatting（3DGS）。
- 核心意义：通过将训练重构为空间分块上的块坐标下降，并利用 alpha 混合的结合性预渲染非活动区域，使**峰值显存与场景总规模无关**（固定分块大小和图像分辨率下为 O(1)），从而在有限显存 GPU 上训练原本无法装入核心内存的大场景。

## 2. 提出的方法论

### 核心思想
- 将完整场景参数按空间划分为参数块：Θ = {θᵢ}，每个 θᵢ 对应一个空间分区 Pᵢ。
- 采用块坐标下降（Block Coordinate Descent）：**每次只激活一个参数块**（θ_active），其余参数全部冻结。
- 利用 alpha 混合的结合性和分区造成的固定深度顺序，将冻结参数预渲染并折叠为**前景图像 F 和背景图像 B**（RGBA 格式），避免显式渲染所有冻结参数。

### 关键技术细节
- 对于给定活动凸分区和相机视角，冻结参数按几何位置分为完全位于活动区域前方（Θ_fg）和完全位于后方（Θ_bg）的两部分。
- 对每个可见的“相机–分区”对，渲染并压缩 RGBA 图像存入磁盘；系统内存可缓存压缩图像以加速复用。
- 优化活动块时：
  1. 收集观察到该分区的相机；
  2. 对每个相机，将冻结分区的缓存渲染按深度顺序合成为 F 和 B；
  3. 执行 T 步梯度更新：采样训练相机，仅渲染活动分区，与 F、B 合成，计算重建损失，并仅对 θ_active 反向传播；
  4. 完成后刷新该分区的缓存渲染，继续优化下一个块。
- 内存层次：
  - 磁盘：存储可见相机–分区渲染；
  - 系统内存：缓存压缩图像；
  - GPU 显存：仅包含 θ_active 及所需的前/背景图像对（可进一步流式加载单对图像）。

### 算法流程（文字说明）
1. 初始化场景图元并划分为凸空间分区（实验中使用规则 3D 网格）。
2. 渲染并存储所有可见相机–分区对的 RGBA 图像到磁盘。
3. 对每个活动块：
   - 收集观察该分区的相机；
   - 合成冻结分区的前景 F 和背景 B；
   - 执行 T 次梯度更新；
   - 刷新该分区的缓存渲染。
4. 依次推进各分区，直到全部块优化完成。

## 6. 主要结论与发现

- **质量保持**：平均 PSNR 从 3DGS 的 25.52 降到 ABCD 的 24.73（仅降低 3.1%）；而 ablated 版本降至 16.10（降低 36.9%）。SSIM 从 0.728 到 0.707（降低 3.0%），ablated 为 0.430（降低 41.0%）。
- **显存优势**：平均峰值 VRAM：3DGS 0.925GB，abcd ablated 0.720GB，ABCD 0.785GB。相对 ablated 仅增加 9.0%，相对 3DGS 降低 15.1%。从图 3 可见 ABCD 保持了与 ablated 相同的“活跃高斯驻留量”，说明其保留分区训练的低显存特性。
- **资源转移**：系统 RAM 从 5.81GB（3DGS）/7.29GB（ablated）增至 21.38GB，主要用于缓存渲染图像；训练时间从 83.5s/422.0s 增至 1061.2s。
- **总体结论**：ABCD 将大规模训练的限制性资源从稀缺的 GPU 显存转移到更便宜的存储层，同时几乎保持标准 3DGS 的重建质量；显存渐近独立于场景规模，为有限显存 GPU 上的大场景训练提供了可行方案。

## 7. 优点

- **方法创新**：巧妙利用 alpha 混合的结合性将冻结区域压缩为前后景 RGBA 图像，理论上使显存需求变为常数，避免了显式渲染所有冻结参数。
- **通用性**：适用于任意 alpha 合成辐射场（不局限于 3DGS），具有扩展到其他公式的潜力。
- **清晰的内存分层设计**：磁盘/系统内存/GPU 显存分工明确，且可通过流式加载进一步减少显存。
- **实验设计有针对性**：对 compositing 进行消融，有效验证了合成策略的核心贡献；同时报告了显存、RAM、时间等多维资源指标。
- **优化行为良好**：训练轨迹接近 3DGS，说明块坐标下降加合成并未显著破坏优化过程。

## 8. 不足与局限

- **实验规模有限**：仅两个小场景，高斯数量少，渐近显存收益被掩盖，无法充分验证“常数显存”在大场景中的实际优势。
- **超参数未调优**：densification 和训练超参数未充分优化，可能影响最终质量的公平性。
- **近似分区赋值**：高斯按均值分配到分区，忽略协方差可能跨越边界，严格的分区成员关系是前后景分解正确性的前提，需更细致的分配规则或重叠边界区域。
- **内存/时间开销大**：缓存渲染图像导致系统 RAM 和训练时间显著增加，虽然可通过磁盘流式缓解，但仍有实际成本。
- **收敛理论待研究**：块坐标下降在 3DGS 上尤其是空间分组下的理论收敛性没有分析。
- **可见性处理粗糙**：仅用视锥剔除，缓存量仍可能随场景增长，需引入可见性阈值和遮挡剔除。
- **缺乏大规模与分布式验证**：作者建议未来在更大真实场景和分布式设置中评估，当前结论尚未覆盖这些重要场景。
