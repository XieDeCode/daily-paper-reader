## 摘要
使用3D高斯泼溅（3DGS）进行场景重建已变得普遍，然而，由于未压缩的文件大小可能非常庞大，部署仍然困难。当前的3DGS压缩系统结合多种策略来减小文件大小，这可能会掩盖收益的来源，并限制组件在不同训练流程中的复用。为了使收益更加透明，我们提出了KISS-GS，一种模块化压缩流程，其名称源于“保持简单”的原则，旨在将压缩与训练完全解耦。给定使用vanilla 3DGS重建的3DGS场景，我们通过结合最先进的剪枝方案，能够将其压缩15.7倍。然后，我们将其编码为一种基于图像的格式，该格式专为简单、普适的解码而设计。在SOG-XT格式中，我们提出了一种对自组织高斯的新扩展，包含两个主要贡献：（i）自组织2D码本和（ii）并行代表分配平滑（PRAS），后者利用四元数和尺度参数化的对称性，生成更有利于编码的2D属性网格。这种编码将场景大小减少了6.6倍。我们表明，可选的编码感知微调可进一步减少2.2倍。在标准3DGS基准测试中，我们简单且模块化的方法因此实现了场景大小相对于未压缩vanilla 3DGS的85倍至319倍缩减，为真实世界场景树立了新基准，并在率失真方面超越了紧密集成的方法。解码仅依赖于Web原生图像格式，模块化设计使每个阶段易于与未来重建和压缩方面的进展相结合。代码和项目页面：https://fraunhoferhhi.github.io/KISS-GS/

## Abstract
Scene reconstruction with 3D Gaussian Splatting (3DGS) has become common, however deployment remains painful as the uncompressed file sizes can be massive. Current 3DGS compression systems combine multiple strategies for file size reduction, which can obscure where gains come from and limit component reuse across training pipelines. To make the gains more transparent, we propose KISS-GS, a modular compression pipeline named after the principle of keeping things simple, designed to decouple compression entirely from training.   Given a 3DGS scene reconstructed with vanilla 3DGS, we are able to reduce it through compaction by 15.7x using a combination of state-of-the-art pruning schemes. Then we encode it into an image-based format designed for simple, ubiquitous decoding. With the SOG-XT format, we propose a novel extension to Self-Organizing Gaussians with two main contributions: (i) Self-organizing 2D Codebooks and (ii) Parallel Representative Assignment Smoothing (PRAS), which leverages the symmetry of quaternion and scale parameterizations to produce 2D attribute grids more amenable to encoding.   This encoding reduces scene size by 6.6x. We show that optional encoding-aware fine-tuning yields a further 2.2x. Across standard 3DGS benchmarks, our simple and modular approach thus achieves a total of 85x to 319x reductions in the size of the scene over uncompressed vanilla 3DGS, setting new benchmarks for real-world scenes and surpassing tightly integrated methods in rate-distortion. Decoding relies solely on web-native image formats, and the modular design makes each stage easy to combine with future advances in reconstruction and compaction. ## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：3D 高斯泼溅（3DGS）已成为场景重建的主流方法，但原始 `.ply` 导出文件体积巨大（单个场景可达数百 MB 至 GB 级），给存储、流式传输和部署带来严重障碍，尤其在硬件受限的 Web 浏览器、移动端渲染器和 AR/VR 应用中。
- **核心问题**：现有 3DGS 压缩系统往往将多种压缩策略（如剪枝、量化、熵编码、锚点结构等）紧耦合在一起，导致**归因缺口（attribution gap）**——即最终压缩收益的来源不透明，难以公平比较各方法，也限制了组件在不同训练流程中的复用。
- **现有方法的局限**：许多方法（如 anchor-based 方法）将压缩与特定的重建训练管线深度耦合，当新的重建方法或参数化方式出现时，压缩方案本身也必须随之重写，形成"训练-格式耦合"（training-format coupling）问题。
- **论文目标**：提出一个**保持简单（KISS 原则）** 的模块化压缩流水线，将压缩与训练完全解耦，使得每一阶段的压缩收益可独立测量，同时保持解码端极简（仅依赖 Web 原生图像格式）。
- **三个研究问题（RQ）**：
  - **RQ1**：能否通过模块化压缩流水线并逐一测量各阶段贡献来弥合归因缺口？
  - **RQ2**：简单的基于图像的编码格式能否在真实场景基准上匹敌更复杂的集成方法（如 HAC++）？
  - **RQ3**：在受限于简单、Web 友好编解码器的条件下，编码感知微调是否仍能带来收益？

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 整体架构：四阶段模块化流水线

KISS-GS 将压缩显式划分为四个独立阶段，每个阶段可单独替换、消融和分析：

| 阶段 | 名称 | 作用 | 计算量 |
|------|------|------|--------|
| Stage 1 | 3D 重建（Reconstruction） | 接受任意标准 3DGS `.ply` 文件 | 30k 迭代 |
| Stage 2 | POPSpa 压实（Compaction） | 减少基元数量 | 10k 迭代 |
| Stage 3 | SOG-XT 编码（Encoding） | 将基元编码为图像格式 | 无需训练 |
| Stage 4（可选） | 编码感知微调（Adaptation） | 以编解码器在环方式微调参数 | 4k 迭代 |

### 2.2 Stage 1：3D 重建

- 接受任何标准 3DGS `.ply` 文件（INRIA、gsplat、Lichtfeld Studio 等），不依赖特定实现，确保训练-格式解耦。
- 保持标准 3DGS 参数化：均值、四元数协方差、尺度、3 阶球谐颜色、标量不透明度。**不依赖 MLP、哈希网格或锚点结构**，保证解码器简单。
- 主实验使用 gsplat-MCMC 实现（30k 迭代）。

### 2.3 Stage 2：POPSpa 压实

POPSpa 是一个**与重建无关**的压实方案，结合了多种现有剪枝技术：

- **有效秩正则化（Effective Rank Regularization）**：利用协方差矩阵特征值谱的熵来量化高斯形状，抑制极端针状高斯（erank≈1）的形成，鼓励盘状高斯（erank≈2），公式为：
  $$L_{erank} = \sum_k \lambda_{erank} \max(-\log(erank(\Sigma_k) - 1 + \epsilon), 0) + s_3$$
- **第一轮剪枝**：使用 GaussianPOP [20] 的逐基元误差准则 ΔSE_k = ‖C_render − C′_render‖²，计算移除每个高斯后渲染图像的变化量，剪除得分最低的固定比例基元。
- **优化-稀疏化精炼（Optimize-Sparsify Refinement）**：借鉴 GaussianSpa [47] 的交替优化方案，将基元选择形式化为 ℓ0 稀疏约束优化问题（min L(a,Θ) s.t. ‖a‖₀ ≤ κ），在 5k 迭代内逐步降低冗余基元的不透明度。
- **第二轮剪枝 + 微调**：重新计算剪枝得分，再经过 5k 迭代微调恢复质量，总计 10k 后处理迭代。

### 2.4 Stage 3：SOG-XT 编码

SOG-XT 是基于图像的编码格式，扩展了 Self-Organizing Gaussians (SOG) [27] 方法，核心机制包括：

- **PLAS 排序**：使用并行赋值算法将 N 个基元排列到 ⌈√N⌉×⌈√N⌉ 的 2D 网格中，使属性图局部平滑，适合标准图像编解码器。
- **球谐（SH）降维**：(i) **自组织 2D 码本（Self-organizing 2D Codebooks）**——用 k-means 聚类将 45 维 SH 系数（15 个非 DC 系数 × RGB）压缩为码本，聚类中心再用 PLAS 排序形成 2D 码本网格（上限 256×256=65,536 个条目），分配索引存为两个 8-bit UV 图像通道；(ii) 码本中心以 100 级量化后以 3×5 平铺 RGB 图像存储。
- **PRAS（Parallel Representative Assignment Smoothing，并行代表分配平滑）**：利用协方差分解的对称性——尺度排列（3!=6 种）、特征向量方向（4 种有效）和四元数双覆盖（2 种）共产生 **48 个等价参数组合**——通过粗到细的优化，在 2D 网格上对每个基元在等价类内选择使压缩误差最小的代表参数，从而在**不改变 3D 协方差**的前提下减小四元数和尺度网格的人工方差，提升可压缩性。PRAS 使四元数量化从 q=255 降到 q=99 而不损失质量。
- **各属性存储方式**：
  - 均值（位置）：signed-log 重映射 + 16-bit 量化，分为高低两个 8-bit 字节平面，PLAS 排序时对高字节加权更强；
  - 尺度：log 映射 + 8-bit 量化；
  - 不透明度：inverse sigmoid 映射 + 8-bit 量化；
  - SH DC 项：直接 8-bit 图像；SH AC 项：k-means 码本 + UV 索引；
  - 填充基元通过 active mask 标记，解码时丢弃。
- **图像压缩**：全部使用 8-bit WebP 图像格式（浏览器原生支持），而非 SOG 原版的 JPEG-XL。
- **元数据**：每通道 min-max 量化范围存为 float32 的 YAML 文件，仅占总大小约 0.2%。

### 2.5 Stage 4：编码感知微调（可选）

- 在微调过程中，每个训练步将当前高斯属性映射到 SOG-XT 的量化图像张量，经编解码往返后渲染并反向传播（使用直通估计器处理取整）。
- 编解码器的离散结构（active mask、PLAS 顺序、SH 分配、码本布局）在开始时固定；SH 分配保持固定，但码本中心根据当前 f_rest 系数重新计算。
- 在量化图像上添加轻量平滑损失（total variation），并在微调期间重跑 PRAS 以保持协方差对称性解决的收益。
- 输出格式与无微调 SOG-XT 完全一致，**解码器无需任何改动**。

## 6. 论文的主要结论与发现

1. **模块化可以有效弥合归因缺口**：KISS-GS 将压缩显式分解为重建、压实、编码、微调四阶段，每阶段的压缩收益可独立测量。在 Mip-NeRF 360 上，POPSpa 压实贡献 15.7× 缩减，SOG-XT 编码贡献 6.6×，编码感知微调再贡献 2.2×。
2. **简单图像编码可超越复杂集成方法**：在 Tanks and Temples 和 Mip-NeRF 360 两个真实世界基准上，KISS-GS 在匹配 INRIA-Q 质量时达到 **319×（PSNR）** 和 **228×（PSNR）** 的文件缩减，全面超越 HAC++，且解码仅需标准 WebP 图像解码 + 轻量反量化操作。
3. **编码感知微调在约束编解码器下仍然有效**：在保持输出格式和解码器不变的前提下，微调额外带来约 2.2× 的缩减，且参数敏感性分析显示默认设置并非脆弱最优。
4. **自组织 2D 码本和 PRAS 是有效的创新组件**：2D 码本排序和 UV 标签打包带来"免费"的文件大小收益（无质量损失）；PRAS 以极小的文件大小代价换取显著的质量提升。
5. **Deep Blending 仍是边界**：锚点学习的表示方法（HAC++）在此数据集上优于标准 splat 重建输入，说明限制因素在于输入重建的质量而非图像编码器本身。
6. **编码开销远低于重建和压实**：SOG-XT 后处理编码（34 秒）与重建（1215 秒）相比极为廉价，但可选微调（441 秒）成本较高。

## 7. 优点

1. **清晰的方法论定位**：明确提出"归因缺口"概念，将压缩收益透明化，为领域内公平比较提供了新范式。
2. **训练-格式完全解耦**：输入可以是任意标准 3DGS `.ply`，未来重建方法的改进可直接受益于 KISS-GS 而无需修改压缩方案，具有极佳的组件可复用性和前瞻性。
3. **解码端极简**：解码仅依赖 Web 原生 8-bit 图像格式（WebP）+ 轻量确定性操作，可在 CPU 上亚秒级解码百万级高斯，便于跨语言/跨平台移植，适合 Web 和移动端部署。
4. **创新性技术贡献**：自组织 2D 码本（利用 PLAS 排序码本中心）和 PRAS（利用协方差分解的 48 重对称性）均为新颖且有效的设计。
5. **实验设计严谨**：使用率失真曲线而非单点对比；对 HAC++ 进行统一协议的重新计算；计算预算匹配（30k/40k/44k 迭代对齐）。
6. **充分披露消融**：逐组件量化每个设计选择对文件大小和质量的贡献，透明度和可复现性强。
7. **实际性能卓越**：在真实世界数据集上达到个位数 MB 文件大小、228–319× 总压缩比，超越此前最优方法。

### 8. 不足与局限（续）

1. **Deep Blending 数据集的局限**（接上文）：KISS-GS 在此数据集上未能在任一操作点达到 INRIA-Q 的 LPIPS 指标，虽然论文将其归因于标准 splat 重建的局限性，但这限制了方法在类似"近距离、高细节、少视点"场景下的泛用性。若输入重建质量本身不佳，后续压缩环节无论多高效都无法挽回信息损失，这暴露了"压缩与重建解耦"策略的固有边界——解耦虽有利于模块复用，也意味着压缩方法无法像 anchor-based 方法那样通过联合优化反向提升重建质量。

2. **解码器并非完全"零依赖"**：论文强调解码仅依赖 Web 原生图像格式，但解码过程仍需要实现 PLAS 逆排序、码本查找、signed-log/inverse-sigmoid 反量化、48 重等价类参数解析等操作。虽然这些操作是确定性的轻量运算，但对于不熟悉 3DGS 内部结构的 Web 开发者而言，仍需要维护一份非平凡的解码逻辑，并非真正意义上的"开箱即用"。

3. **对 HAC++ 的对比公平性仍有争议空间**：论文将 HAC++ 重跑于 44k 迭代并宣称计算预算匹配（30k+10k+4k），但 HAC++ 的架构（anchor + 神经编码）本身的设计目标并非与 30k 步重建 + 14k 步后处理的调度对齐；论文也承认 HAC++ 在 40k 和 44k 之间的性能存在波动。这种"计算量对齐但优化调度不对齐"的折中方案虽比直接引用自报数据更严谨，但仍非完美对照。

4. **量化粒度与多级缩放策略的缺失**：SOG-XT 将各类属性统一量化为 8-bit 图像，缺乏对高精度需求的属性（如位置）提供自适应位深或多尺度表示的能力；相比之下，部分压缩方案支持按重要性动态分配比特率。对于顶级质量需求（如影视级渲染），8-bit 量化天花板可能成为瓶颈。

5. **码本机制的容量上限与扩展性**：SH 码本被限制在 256×256=65,536 条目以内，对于高斯数量极大（>1M）且外观变化复杂的场景，固定采样密度可能不足；同时 k-means 聚类仅针对非 DC 项且未在微调阶段更新分配（仅更新中心），存在局部最优风险。

6. **率失真曲线的多基元档位主要依赖剪枝实现**：论文在生成不同基元预算的 RD 曲线时，主要通过对已训练模型进行剪枝来获得不同档位，而非为每个档位单独运行完整的重建-压实流程。这意味着低预算端的表现可能受限于初始重建的基元分布，而非真正探索了该预算下的最优表示。

7. **未涉及时间维度与动态场景**：KISS-GS 仅处理静态场景的压缩，对动态 3DGS（如 4D Gaussian Splatting）没有扩展探讨；视频流式传输场景（如体积视频）通常需要帧间编码与时间一致性压缩，这不是当前格式能够覆盖的。

8. **论文对部分基线的细节披露不充分**：如 "gsplat-1M"、".spz 格式" 等对照方法的实现细节、训练配置、超参数来自自报（† 标记），读者难以精确复现这些对比的数据点；附录中虽有补充，但某些方法的具体版本（commit/release）未指明。

9. **SH 码本与图像编解码器之间存在隐式耦合**：SH 系数经过 k-means 聚类、UV 索引映射和 WebP 压缩三层处理，任何一层的失真都会在解码端叠加。论文通过消融量化了整体影响，但没有单独评估"码本量化误差"与"WebP 有损压缩误差"各自的贡献与相互作用，这使得归因分析在编码阶段内部仍不完全透明。

10. **评估指标集中在图像质量，缺乏下游任务验证**：论文的评估仅涉及 PSNR/SSIM/LPIPS 等图像质量指标，未讨论压缩表示在分割、编辑、语义理解等下游任务中的可用性；对于 3DGS 压缩领域的实际部署场景（如交互式编辑、光照重打），这种评估缺口是常见但重要的局限。

## 9. 对未来工作的启示与展望

1. **模块化压缩可能成为新的基准范式**：KISS-GS 证明了"压缩无关训练"的可行性与竞争力。未来的 3DGS 重建方法可以在不考虑压缩的情况下自由演进，随时通过 KISS-GS 这类后处理管线获得可观的压缩收益。这种解耦思路有望推动领域内形成"重建贡献"与"压缩贡献"分离评价的共识协议。

2. **图像编解码器的进步可直接转化为压缩收益**：由于 SOG-XT 完全建立在标准图像格式之上，任何针对 8-bit 图像的新一代编解码器（如 AVIF、JPEG-XL、学习型编码器）的改进，都可以在不改动管线其他部分的条件下直接提升 3DGS 压缩性能。这是一个极具吸引力的"搭便车"机制。

3. **PRAS 所代表的数学对称性利用值得推广**：协方差参数化中的 48 重等价性是一个被其他方法忽视的结构性质。类似的对称性可能存在于其他表示中（如 Rodrigues 旋转向量、各向异性尺度排列），未来工作可以在更广泛的 3D 表示压缩中利用这种"零成本"的规范化手段。

4. **编码感知微调的解耦边界值得进一步探索**：论文在微调时固定了离散结构（active mask、PLAS 顺序、SH 分配），仅优化参数。一个自然的扩展是：允许微调过程渐进式地更新码本分配或 PRAS 排序，以探索"结构级"与"参数级"微调的更大空间，同时保持最终格式不变。

5. **应对复杂场景表示（如锚点、哈希网格）的解耦**：本工作的一个未竟目标是将压缩解耦推广到 anchor-based 或 MLP-based 重建方法。若能在不注入训练格式的前提下，将这类表示转换为统一的可压缩张量，将极大扩展该范式的适用范围。

## 10. 总体评价

KISS-GS 是一篇**方法论定位精准、工程细节扎实、实验设计严谨**的高质量压缩工作。其核心贡献不在于某一项颠覆性技术，而在于**提出了一种将压缩收益"解耦、量化、归因"的系统性框架**，并通过极其简单的基于图像的编码格式，在真实世界基准上击败了此前结构复杂得多的集成方法。论文写作清晰，消融深入，对 HAC++ 的重新评估体现了难得的学术公平性。

在"压缩与训练强耦合"日渐成为主流的领域氛围中，KISS-GS 以"少即是多"的姿态提供了有力的反例：**简单的模块化设计配合精心调优的每个组件，可以在可解释性和最终性能上同时超越复杂的整体式方法。** 其主要局限在于对输入重建质量的依赖、动态场景缺失以及某些对比协议的一致性瑕疵，但这些问题并不削弱其作为未来 3DGS 压缩研究**新基准范式**的价值。

对于同时追求**可复现性、可解释性、部署友好性**的应用场景（Web AR/VR、移动端渲染、云端流式传输），KISS-GS 是一个极具实际工程落地方案候选。
