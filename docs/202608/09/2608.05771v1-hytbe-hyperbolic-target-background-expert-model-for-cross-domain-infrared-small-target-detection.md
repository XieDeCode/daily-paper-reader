## 摘要
红外小目标检测（IRSTD）在域一致评估下取得了显著进展，但在泛化到未见红外域时，检测器性能往往会明显下降。现有方法主要通过增强目标响应和抑制背景干扰来改进检测。然而，当仅在有限的源域集合上训练时，其学习到的决策规则不可避免地建立在源域目标-背景关系模式的有限范围内。我们将这种跨域失败定义为目标-背景关系偏移：未见域可能表现出训练期间未观察到的关系模式，从而削弱从源域学到的判别能力。为解决这一问题，我们提出HyTBE，一种双曲目标-背景专家模型，它扩展源域关系模式并利用显式关系线索自适应调整视觉表示。目标-背景关系干预选择性地扰动目标或背景，在保持有效监督的同时拓宽训练期间可观察的关系模式。随后，双曲关系建模将多尺度视觉线索映射到庞加莱球中，并根据每个特征令牌到目标和背景锚点的相对距离来表征其目标-背景关系。双曲引导的MoE适配器进一步利用这些双曲关系表示来校准多尺度视觉特征，并为不同关系模式聚合专家特定的特征修正。在NUAA-SIRST、NUDT-SIRST和IRSTD-1K上的留一域实验表明，HyTBE比竞争基线实现了更强的跨域泛化。

## Abstract
Infrared small target detection (IRSTD) has achieved substantial progress under domain-consistent evaluation, yet detector performance often degrades markedly when generalizing to unseen infrared domains. Existing methods primarily improve detection by enhancing target responses and suppressing background interference. However, when trained on only a limited set of source domains, their learned decision rules are inevitably established from a restricted range of source-domain target-background relation patterns. We formulate this cross-domain failure as target-background relation shift: unseen domains may exhibit relation patterns that are not observed during training, thereby weakening the discriminative capability learned from the source domains. To address this problem, we propose HyTBE, a Hyperbolic Target-Background Expert model that expands source-domain relation patterns and adaptively adjusts visual representations using explicit relation cues. The Target-Background Relation Intervention selectively perturbs either targets or backgrounds, broadening the observable relation patterns during training while maintaining valid supervision. Subsequently, the Hyperbolic Relation Modeling maps multi-scale visual cues into a Poincaré ball and characterizes the target-background relation of each feature token according to its relative distances to the target and background anchors. The Hyperbolic-guided MoE Adapter further uses these hyperbolic relation representations to calibrate multi-scale visual features and aggregate expert-specific feature corrections for different relation patterns. Leave-one-domain-out experiments on NUAA-SIRST, NUDT-SIRST, and IRSTD-1K demonstrate that HyTBE achieves stronger cross-domain generalization than competitive baselines.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：红外小目标检测（IRSTD）旨在从复杂红外背景中定位微小且暗淡的目标，广泛应用于遥感、海上监视和预警系统。与普通物体不同，红外小目标通常仅占几个像素，缺乏稳定的纹理、轮廓和语义结构，其可检测性高度依赖于与周围背景的相对对比度、显著性、形态及上下文差异。
- **核心问题**：现有深度学习方法在“域一致”评估（训练与测试分布相似）下表现良好，但在跨域部署时性能显著下降。论文将这种失败归纳为**目标-背景关系偏移（Target-Background Relation Shift）**：训练时模型只能从有限源域中学习有限的目标-背景关系模式，而未见域可能呈现训练中未出现的关系模式，导致源域学到的决策规则失效，出现漏检和虚警。
- **关键洞察**：跨域 IRSTD 的难点不仅在于目标或背景各自外观的变化，更在于两者判别关系的改变。因此，需要同时做到两点：① 在训练阶段**扩展**源域可观察到的关系模式；② 在推理阶段**显式建模**并**自适应调整**特征以匹配不同关系模式。
- **论文总体方案**：据此提出 HyTBE（Hyperbolic Target-Background Expert Model），通过“关系干预 → 双曲关系建模 → MoE 引导适配”的渐进式流程，提高模型跨域泛化能力。

## 2. 论文提出的方法论

### 2.1 整体架构

- 输入图像经 ResBlock 编码器提取多尺度视觉特征 \(\{F_i\}_{i=1}^I\)。
- 每个尺度的特征依次经过：
  1. **超关系建模（HRM）**：将视觉特征映射到庞加莱球，生成关系表示 \(z_i\)；
  2. **双曲引导 MoE 适配器（HMA）**：利用 \(z_i\) 对视觉特征进行校准并聚合专家特征修正，得到适配特征 \(A_i\)；
  3. 最后由 RPCABlock 解码器逐步融合多尺度特征，输出目标响应图。

### 2.2 目标-背景关系干预（Target-Background Relation Intervention, TBRI）

- **目的**：在训练时人为扩大目标-背景关系的多样性，避免模型过度依赖源域中的有限模式。
- **机制**：对每个训练样本，以概率 \(p=0.5\) 激活干预；激活后从两类操作中均匀随机选择一个：
  - **背景干预**：保留目标区域和标注，替换/扰动背景，包括全局成像风格变换（亮度、对比度、gamma）、背景复杂度变化（局部对比度、高频增强、噪声添加）等。
  - **目标干预**：保留背景，变换目标外观甚至目标支撑区域，包括显著度衰减、形态变化、亮度增强、收缩、从源域随机采样其他目标插入等。
- **关键设计**：每个样本只执行一种干预，且保持监督信号（二值掩码）与干预后的目标支撑一致，避免引入无效标签。

### 2.3 双曲关系建模（Hyperbolic Relation Modeling, HRM）

- 将多尺度视觉特征通过 Patch Embedding 投影为关系令牌 \(u_i\)，再利用指数映射将 \(u_i\) 从原点切空间映射到庞加莱球（曲率 \(c=1\)）得到 \(z_i\)。
- 定义两个相对锚点：目标锚点 \(a_t = \mathrm{Exp}_0^c(\rho)\)，背景锚点 \(a_b = \mathrm{Exp}_0^c(-\rho)\)，\(\rho\) 控制锚点尺度。
- 计算每个令牌到目标和背景锚点的测地距离之差作为关系分数：
  \[
  s_i = d_c(z_i, a_b) - d_c(z_i, a_t)
  \]
  \(s_i > 0\) 表示目标关系，\(s_i < 0\) 表示背景关系。
- 利用真值掩码划分目标/背景令牌集合，施加带边距的关系损失 \(L_{hyp} = L_t + L_b\)，鼓励目标令牌 \(s_i \ge m\)、背景令牌 \(s_i \le -m\)，同时保留各侧内部关系模式的多样性。

### 2.4 双曲引导 MoE 适配器（Hyperbolic-guided MoE Adapter, HMA）

- **Guide-Attention（引导注意力）**：以视觉特征的平均池化作为 Query，HRM 产生的双曲关系表示作为 Key，原视觉特征作为 Value，通过 Sigmoid 门控重新校准通道响应。
- **MoE 适配器**：每个尺度配有若干专家（默认 \(E=4\)），每个专家由一个残差块和轻量通道门组成；路由器根据全局池化特征预测专家软权重，将各专家修正加权求和后加回引导特征：\(A_i = G_i + \alpha_i \sum_{e=1}^E g_{i,e} E_{i,e}(G_i)\)。
- 辅助损失：负载均衡损失 \(L_{lb}\) 促进专家使用均衡，非一致性损失 \(L_{nc}\) 促进专家修正的多样性。
- 总训练损失：\(L = L_{IoU} + L_{hyp} + L_{lb} + L_{nc}\)。

## 6. 论文的主要结论与发现

- 跨域 IRSTD 性能下降的根本原因可归结为**目标-背景关系偏移**，而非单纯的目标或背景外观变化。
- 通过 **TBRI** 在训练阶段人为扩展源域关系模式，能够显著提升模型对未见域的适应性（mIoU 提升约 2.93 个百分点）。
- 在**庞加莱球**中显式建模目标/背景相对关系，比欧氏距离度量更有效，尤其在降低虚警率方面（\(F_a\) 从 17.77 降至 13.10）。
- **双曲关系引导的 MoE 适配器**能将关系线索转化为特征级适应，实现多尺度、多关系模式下的动态修正；目标干预和背景干预互为补充，共同使用时效果最佳。
- 完整 HyTBE 模型在 3 个跨域设置中均取得最佳 mIoU 和 F-measure，同时保持极低的参数量（1.13M），验证了“关系多样化 → 关系表示 → 关系引导适应”这一设计原则的有效性。

- **方法设计自洽且互补**：三个组件（干预、双曲建模、MoE 适配）分别对应“扩展关系模式”、“表征关系模式”、“适应关系模式”，逻辑链条完整，消融实验证明各组件均有独立贡献且能协同增强。

- **干预策略细致**：既包含背景侧（成像风格、杂波）也包含目标侧（显著性、形态、尺度、采样），且保持监督一致性，是一种轻量而有效的域随机化变体。

- **实验覆盖不均衡**：消融与超参数分析均只在单一跨域设置下进行，无法判断方法在其他目标域上的鲁棒性和最佳超参数是否一致。
- **统计可靠性未知**：未报告多次随机种子实验的标准差或置信区间，性能增益可能受到训练随机性影响；补充材料中的相关性分析虽有 bootstrap 置信区间，但主结果缺少类似处理。
- **对比公平性风险**：各对比方法的超参数和训练设置可能未逐一重新调优，尤其某些对比方法在特定域上表现异常（如 DRPCANet 在 IRSTD-1K 上 mIoU 仅 25.82），可能影响“全面优于”结论的置信度。
- **虚警率控制不全面**：HyTBE 在 \(F_a\) 上并非所有设置最优（如 IRSTD-1K 上比 SCTransNet 高），表明在目标召回与背景抑制之间仍存在进一步优化空间。
- **场景局限性**：三个数据集虽来自不同成像环境，但仍属于公开的、相对标准的红外小目标场景，未覆盖更极端的条件（如强杂波、雨雾、飞行平台抖动、多目标密集场景）。传感器型号、分辨率变化等实际部署因素也未系统测试。
- **方法复杂度与代码可复现性**：文中部分模块（如形态学变换、目标采样的具体实现）细节较多，补充材料虽提供了公式，但实际调参（如各操作符的采样范围）未充分说明；RTX 4070 Ti SUPER 训练 200 epoch 的时间未报告，影响复现评估。
- **理论深度有限**：为何双曲空间比欧氏空间更适合该任务，论文只给实验验证，缺少更高层次的理论分析（如双曲曲率对关系表示容量的影响）；MoE 路由的“关系感知”与普通输入依赖路由的差异也缺乏深入探讨。
