## Abstract
Existing Multimodal Large Language Models (MLLMs) predominantly rely on image-text pairs for modality alignment pretraining, mapping global image representations to long textual descriptions. However, this image-level alignment suffers from referential ambiguity: models struggle to infer the correspondences between multiple visual objects and textual entities from the global representation, leading to data inefficiency and suboptimal semantic grounding. To address this, we propose MultiModal Code-Switching (MMCS), a novel pretraining paradigm that provides explicit object-level supervision. Inspired by the linguistic phenomenon of code-switching, MMCS interleaves vision and language by replacing textual entities with their corresponding visual objects, enforcing local vision-language grounding. We further develop a scalable data synthesis pipeline to generate a pretraining dataset of 773K samples with accurate object-entity correspondences. Experiments show that MMCS is highly data-efficient: with only 50K samples, it matches or surpasses models trained on 600K image-text pairs. Furthermore, MMCS consistently improves visual grounding and perception capabilities across varying model scales.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **研究背景**：现有多模态大语言模型（MLLMs）普遍采用两阶段训练范式——先通过图像-文本对进行模态对齐预训练，再进行多模态指令微调（SFT）。其中模态对齐预训练是整个能力的基石，对齐质量决定了模型多模态能力的上限。
- **核心问题**：主流对齐方法依赖密集图像标题（dense captions），将整幅图像编码为全局表征后预测长文本序列，属于**图像级对齐（image-level alignment）**。然而自然图像通常包含多个对象（密集标题数据集中每样本平均含 6.8~11.0 个实体），这种"多对多"映射导致**指代歧义（referential ambiguity）**——模型无法从全局表征中准确推断文本实体与特定视觉区域的对应关系，只能依赖统计共现而非真正的语义接地（semantic grounding）。
- **后果**：隐式对齐范式数据效率极低，需要海量数据才能学到鲁棒的对象-实体关联；模型关注力弥散、表征一致性差，细粒度视觉感知和接地能力受限。
- **论文立意**：提出 **MultiModal Code-Switching (MMCS)**，一种全新的预训练范式，将视觉对象直接插入语言序列中替换对应文本实体，把对齐从隐式的图像级关联转变为**显式的对象级对应（explicit object-level correspondence）**，从根本上消除指代歧义。

## 2. 论文提出的方法论

### 2.1 核心思想：代码切换（Code-Switching）

- 灵感来源于语言学中的"语码转换"现象（如英语句子中插入德语单词 *Klavier*），其本质含义是"被切换的词汇必须与上下文语义兼容"。
- MMCS 将视觉对象视为一种特殊的"代码"，用视觉对象的嵌入替换文本中的实体嵌入，构造**交错式图像-文本序列**，迫使模型直接从局部视觉特征满足句子的语义期望，实现显式对象级接地。

### 2.2 方法形式化定义

- 设原始文本序列为 X，文本实体段 e = [xᵢ, ..., xᵢ₊ₘ]，v_object 为对应对象的视觉表征（与对象边界框空间相交的图像 token 集合），则构造的交错序列为：

  **X_MMCS = Concat(X<ᵢ, v_object, X>ᵢ₊ₘ)**

- 训练采用语言建模目标，损失仅在文本 token 上计算（视觉 token 作为条件上下文）：

  **L_LM = −Σ log pθ(xₜ | X<ₜ)** （仅对文本 token 求和）

- 额外增加实体重建损失，强制显式的对象-实体监督：

  **L_entity = −log pθ(e | X<ᵢ_MMCS, v_object)**

- 总目标：**L_MMCS = L_LM + L_entity**，两个损失互不重叠、互补：L_entity 作为语义锚点保证实体重建的语义精度，L_LM 负责上下文整合。

### 2.3 数据合成流水线（4 步）

1. **详细图像描述**：使用 Qwen3-VL-32B-Instruct 生成穷尽性细节的密集标题。
2. **文本实体提取**：使用 Qwen2.5-72B-Instruct 提取名词短语清单（附带简短属性描述以消歧同类对象）。
3. **视觉对象接地**：使用 Grounding DINO 将文本实体定位到对应视觉区域，输出边界框+标签+置信度。
4. **多阶段过滤**：① Grounding DINO 预测经 box 阈值 0.4 与 text 阈值 0.3 过滤；② 剔除面积小于单个视觉 patch 或超过图像总面积 50% 的框；③ 使用 SAM-2.1 生成分割掩码，丢弃掩码面积小于边界框面积 20% 的框（去除严重遮挡对象）。

- 图像来源涵盖 MS COCO、Flickr30k、GQA、Objects365、OpenImages、SA-1B，最终生成 **773K 预训练样本**，平均每样本约 6.65 个视觉对象，平均标题长度 961.65 字符。VLM 裁判（Gemini-3-Pro）与人工评估的接地准确率分别达 94.9% 与 94.2%。

## 6. 论文的主要结论与发现

1. **数据效率极大提升**：仅用 50K MMCS 样本即可超过 600K 图像级预训练样本的下游性能。
2. **视觉接地能力显著增强**：在 RefCOCO/+/g 上平均提升 7.9%（如 Qwen2.5-3B 上 AVG 从 59.12→70.29）。
3. **感知能力提升**：CVBench 平均 +4.0%，OCRBench +2.8%，V-Star +2.0%，整体感知类任务平均 +2.1%。
4. **通用 VQA 有小幅但统计显著的提升**（+1.67%，p=0.028），增益较小是因为该类任务还依赖世界知识与推理先验。
5. **表征对齐质量更高**：CKA、CKNNA、Mutual k-NN 三种指标均显示 MMCS 的视觉-语言表征在大多数层上对齐更好。
6. **注意力更精准**：注意力图可视化表明 MMCS 预训练模型能准确关注到文本实体对应的视觉区域，而图像级基线关注弥散或错位。
7. **隐式学习动作与关系**：虽然只替换了名词实体，但动词和介词的预测 NLL 也显著下降，说明显式对象接地信号会传播到动作与关系的学习。
8. **涌现 OCR 能力**：自然图像中 10.0%~30.8% 的对象含可读文本，MMCS 的显式裁剪对齐形成了隐式 OCR 监督。
9. **token 效率**：MMCS 平均减少约 41.4% 的图像 token 数量，训练更高效。

## 7. 优点（方法或实验设计亮点）

- **新颖且优雅的核心思路**：将语言学中的代码切换现象跨域迁移到多模态对齐，概念简洁、动机明确，直击图像级对齐的指代歧义痛点。
- **显式对象级监督**：不依赖全局表征的隐式推断，通过"替换实体为视觉对象"在表征层面强制建立对象-实体绑定，比 patch 级对齐（语义碎片化）和坐标文本化（符号中介延迟）更直接有效。
- **数据管线自动化可扩展**：基于现成的 VLM、LLM、接地与分割模型构建，无需人工标注即可扩展到 773K 乃至 1M 规模，且经过 VLM+人工双重质量验证。
- **实验控制严谨**：与图像级基线使用完全相同的图像-标题对，确保增益来自方法本身而非数据质量；多种模型规模、视觉编码器、数据规模的交叉验证增强了结论普适性。
- **机理分析深入**：不止于下游性能比较，还通过表征对齐度量（CKA/CKNNA/Mutual k-NN）、注意力可视化和词性级 NLL 分析揭示内部工作机制。
- **鲁棒性考量全面**：考察了标题质量差异、对象定位噪声、分辨率变化、数据规模扩展等多种实际部署中可能遇到的情形。

## 8. 不足与局限

- **应用范围有限**：当前实现聚焦于自然图像中的视觉对象，未覆盖图表理解、场景文本识别等更广泛场景（作者在 Limitations 中承认）。
- **对象类别覆盖不均**：合成数据可能继承源数据集和自动标注模型的偏差，稀有类别、文化特定对象或代表性不足对象的接地准确率可能不均衡。
- **复杂关系与动作建模不足**：虽实验证明动词/介词学习有所改善，但显式替换仅针对名词短语，复杂关系（如空间关系、交互动作）缺乏直接监督。
- **依赖自动接地模型的准确性**：Grounding DINO 定位错误会引入噪声（虽然 10% 扰动下依然鲁棒，但 30% 噪声下感知与通用性能显著下降）。
- **SFT 数据单一**：仅使用 LLaVA-NeXT 一种 SFT 数据集，未验证与其他指令微调数据分布的兼容性。
- **隐私与伦理风险**：源图像可能包含人脸、车牌、位置信息，生成的标注可能继承这些隐私线索；更强的对象定位能力可能被滥用为监控或追踪系统（作者也明确警示了这一点）。
