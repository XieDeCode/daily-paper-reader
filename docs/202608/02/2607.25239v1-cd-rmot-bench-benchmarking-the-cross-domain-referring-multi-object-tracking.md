## 摘要
指代多目标跟踪（RMOT）通过将目标轨迹与自然语言表达对齐，将跟踪从类别驱动的感知扩展到语言引导的理解。尽管近期取得了进展，现有的RMOT研究大多在域内设置下进行，语言条件跟踪在不可避免的视觉域偏移下的鲁棒性尚未得到探索。在本文中，我们研究了跨域指代多目标跟踪（CD-RMOT），这是一个新颖且具有挑战性的问题，评估在标记源域上训练的RMOT模型是否能够在具有不同视觉条件的未标记目标域中可靠地遵循自然语言表达。为了支持系统性研究，我们构建了CD-RMOT-Bench，一个统一基准，结合了真实清晰域指代跟踪数据、对齐的数字孪生变体和真实恶劣域视频。CD-RMOT-Bench在共享RMOT协议下支持受控的天气/视角偏移分析和逼真的合成到真实迁移评估。此外，我们提出了查询中心自适应（QCA）框架，旨在稳定连接视觉轨迹和指代表达的查询空间。大量实验表明，域偏移严重降低了RMOT性能，其失败不仅由目标检测错误引起，更关键地由不稳定的表达条件时间关联和目标选择引起。QCA建立了一个强基线，而CD-RMOT-Bench为跨视觉域的鲁棒语言引导跟踪开辟了新方向。

## Abstract
Referring multi-object tracking (RMOT) extends tracking from category-driven perception to language-guided understanding by grounding object trajectories in natural-language expressions. Despite recent progress, existing RMOT studies are largely conducted under in-domain settings, leaving the robustness of language-conditioned tracking under inevitable visual domain shifts unexplored. In this paper, we study Cross-Domain Referring Multi-Object Tracking (CD-RMOT), a new and challenging problem that evaluates whether an RMOT model trained on a labeled source domain can reliably follow natural-language expressions in an unlabeled target domain with different visual conditions. To support systematic study, we construct CD-RMOT-Bench, a unified benchmark that combines real clear-domain referring tracking data, aligned digital-twin variants, and real adverse-domain videos. CD-RMOT-Bench enables both controlled weather/viewpoint shift analysis and realistic synthetic-real transfer evaluation under a shared RMOT protocol. Further, we provide a Query-Centric Adaptation (QCA) framework, designed to stabilize the query space that bridges visual trajectories and referring expressions. Extensive experiments reveal that domain shifts severely degrade RMOT performance, where the failure is not merely caused by object detection errors but more critically by unstable expression-conditioned temporal association and target selection. QCA establishes a strong baseline, while CD-RMOT-Bench opens a new direction for robust language-guided tracking across visual domains.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：指代多目标跟踪（Referring Multi-Object Tracking, RMOT）将多目标跟踪从基于类别的感知拓展到语言引导的理解，即根据自然语言表达同时定位并跟踪视频中的指定目标。现有RMOT研究（如 TransRMOT、TempRMOT）及相应基准（如 Refer-KITTI-V2）主要在同域（in-domain）设置下评估，即训练与测试视频来自同一视觉分布。
- **核心问题**：当模型部署到真实场景时，必然遭遇视觉域偏移（domain shift），包括极端天气变化、传感器视角改变、合成到真实的保真度差距等。论文提出一个关键问题：**当视觉域改变时，语言条件跟踪器能否保持可靠？** 现有RMOT评价体系基本未回答这一问题。
- **研究意义**：论文首次系统研究跨域指代多目标跟踪（Cross-Domain Referring Multi-Object Tracking, CD-RMOT），即在有标注源域训练、在无标注目标域（视觉条件不同）上评估RMOT模型的泛化能力，对人机交互、具身智能、自动驾驶等实际应用具有重要意义。

## 2. 方法论

### 2.1 核心思想

论文将 CD-RMOT 定义为**语言条件下的无监督域自适应（UDA）问题**：源域提供视频、表达和跟踪标注用于监督训练；目标域仅提供视频和表达作为任务输入，目标域的框、身份、掩码和表达-目标关联仅用于评测。作者的核心观察是：域偏移下 RMOT 性能下降并非主要由检测错误引起，而是**语言条件的时间查询（temporal query）不稳定、跨域失配、语义漂移**所致。为此提出 QCA（Query-Centric Adaptation）框架，从三个互补维度稳定查询空间。

### 2.2 关键技术细节

QCA 在共享 RMOT 骨干输出的语言条件时间查询 Q = {q₁,…,q_N} 上叠加三个自适应机制：

- **CDT-MT（Cross-Domain Temporal Mean Teacher，跨域时间均值教师）**：针对目标域查询不稳定性。维护学生模型 f_θ 和 EMA 教师模型 f_θ̄（更新规则 θ̄⁽ᵏ⁺¹⁾ = αθ̄⁽ᵏ⁾ + (1−α)θ⁽ᵏ⁾），对可靠目标查询施加选择性一致性损失，包含特征 L2 距离、框的 smooth-L1 损失和指代 logit 的 L2 损失；通过教师置信度与学生-教师一致性（特征、框、指代置信度三空间）挑选可靠子集。
- **ACDA（Adaptive Curricular Domain Adversarial，自适应课程域对抗）**：针对源-目标任务相关查询失配。在查询级做对抗对齐，任务相关分数 c_i = σ(o_i)·σ(r_i)；域分类器通过梯度反转层（GRL）训练，并引入基于域不确定性、源原型距离和任务难度的课程权重，避免早期强行对齐严重退化的目标查询。
- **LGCA（Language-Guided Continuous Adaptation，语言引导连续自适应）**：针对语言条件语义漂移。以指代表达的文本锚作为语义锚点，计算语言引导置信度 κ_i = (1 + cos(q_i, ℓ))/2 · ν_i，维护原型估计（动量更新），并通过残差融合对查询进行修正。

总损失为：**L_total = L_rmot^s + λ_mt·L_mt + λ_acda·L_acda + λ_lgca·L_lgca**。

### 2.3 基准构建方法

CD-RMOT-Bench 的核心构建流程分五个阶段：

1. **源标注与对齐数字孪生**：从 Refer-KITTI-V2 获取真实域表达与轨迹，使用 Virtual KITTI 2 的对齐数字孪生场景提供受控天气/视角变体。
2. **映射式标注转移**：逐场景建立 KITTI 到 vKITTI 的身份对应（基于帧级 IoU 证据、轨道级几何一致性、面积相似性、时间重叠的加权评分与一对一分配），保留自然语言表达、重写目标身份和视频名；每个映射对扩展到 10 个领域（clear、rain、fog、morning、overcast、sunset、15°L/R、30°L/R）。
3. **残差质量控制**：人工检查弱对应证据、身份歧义、表达-目标不一致等情况，移除映射目标缺失的帧级标注。
4. **Real adverse-domain anchor**：Refer-BDD 作为真实恶劣域锚点，不参与数字孪生转移管线，用于合成-真实/清晰-恶劣迁移评估。

## 6. 主要结论与发现

- **域偏移严重损害 RMOT 性能**：仅改变视觉域（场景语义和表达不变），TempRMOT 的 HOTA 即从域内参考的 28.69 降至 fog 下的 16.00，降幅超过 44%。
- **失败主因不是检测错误**：DetA 虽下降，但 AssA（关联精度）下降更为显著，说明表达式条件的时间关联和目标选择不稳定才是核心瓶颈。
- **fog 是最困难的目标域**，且合成-真实、真实-合成迁移依然困难，说明问题的挑战性不限于受控合成变体。
- **QCA 在所有迁移设置下取得最强 HOTA 和 AssA**，且不使用任何目标域监督标签，验证了查询中心自适应的有效性；但结果仍低于域内参考，说明 CD-RMOT-Bench 留有大量提升空间，并非饱和基准。

## 7. 优点

- **问题定义新颖且有实际价值**：首次将 RMOT 与跨域鲁棒性结合，切中实际部署的核心痛点，并给出清晰的形式化定义。
- **基准设计精巧**：通过 KITTI/vKITTI 对齐数字孪生实现"场景语义不变、仅视觉域变化"的受控偏移，有效解耦了域偏移与语义内容变化；将受控分析和真实迁移在统一协议下整合，兼顾可控性与现实性。
- **诊断驱动的方法设计**：QCA 的三个模块分别对应实验揭示的三种故障模式（查询不稳定、跨域失配、语义漂移），方法论有充分实证依据。
- **严谨的基准构建流程**：身份映射通过多证据评分和一对一约束保证可审计性，残差质量控制处理歧义，并报告了详细的构建统计（95.40% 保留率等）。
- **实验分析客观**：明确指出 RVOS 方法不适配轨迹协议、QCA 仍低于域内参考、任务尚有大量空间，没有夸大方法的绝对优势。

## 8. 不足与局限

- **应用场景局限**：基准局限于驾驶场景（KITTI、BDD100K 风格），未覆盖室内、空中（UAV）、监控等 RMOT 潜在应用领域，跨域结论的普适性需更多场景验证。
- **域内上界本身偏低**：vKITTI clear→clear 的 HOTA 仅 28.69，说明源域监督训练本身的性能就不高，跨域评估可能在放大/混淆方法的基础缺陷而非纯粹的域偏移效应。
- **消融覆盖有限**：消融实验仅在两种迁移方向上进行，且未详细分析各模块对检测/关联/定位细分子指标的具体影响。
- **合成-真实迁移中检测性能仍较弱**：QCA 在 Refer-KITTI-V2 和 Refer-BDD 上的 DetA 均低于 9，检测侧的自适应仍有不足。
- **RVOS 基线适配公平性存疑**：掩码转框的接口方式可能系统性低估 RVOS 类方法，论文虽将其定位为"参考"，但直接对比时需谨慎解读。
- **算法细节与复现信息不完整**：训练时长、推理开销、超参敏感性分析未报告；CDT-MT 的可靠查询选择阈值、LGCA 的融合门控细节等依赖附录补充说明。
- **未报告逐表达类别的性能分解**：无法判断不同语言线索类型（空间、运动、关系等）对域偏移的鲁棒性差异，这对理解 CD-RMOT 的语义维度十分重要。
- **未与更广泛的 UDA 方法对比**：实验对比以 RMOT/RVOS 方法为主，未纳入通用目标检测 UDA 方法（如 Adaptive Teacher、Probabilistic Teacher 等）作为参考，方法的相对优势缺乏更全面的参照。
