## 摘要
开放词汇目标检测测试时自适应（OVOD-TTA）旨在解决预训练基础模型在遇到图像域偏移时出现的性能下降问题。现有无源OVOD-TTA方法要么依赖精炼的测试时信息进行重新评分，要么依赖伪标签进行自训练，导致当初始预测较差时精度显著下降。同时，大多数传统源域估计方法恢复适用于分类任务的抽象、稀疏表示，但无法捕获检测所需的密集、具体特征。为了解决这些问题，我们提出了PISA，一种新颖的无源OVOD-TTA方法，可以无缝集成到开放词汇视觉骨干网络中。我们方法的核心组件是抗损坏不变特征提取器（CIFE）、特征对齐模块（FAM）和多尺度对齐框架（BAA）。为了捕获适合检测的特征，我们开发了CIFE，利用CLIP视觉特征在损坏图像上的不变性，确保对各种损坏的鲁棒性。我们进一步开发了FAM和BAA用于预训练和自适应，将损坏不变特征转换为接近原始源域特征的伪个体源域特征。通过这种方式，使用密集且具体的伪个体源域特征进行监督，而不是不可靠的伪标签信号。在损坏的VOC-C、COCO-C和LVIS-C基准上，使用三种基础模型进行的实验表明，PISA显著提高了原始模型的定位精度和类别识别准确率。值得注意的是，PISA在无需访问源域数据的情况下实现了最先进的性能，在COCO-C上超过现有方法3.92%的AP@50%。

## Abstract
Open-vocabulary object detection test-time adaptation (OVOD-TTA) aims to address the performance degradation that pre-trained base models suffer when encountering image-domain shifts. Existing source-free OVOD-TTA methods rely either on refined test-time information for re-scoring or on pseudo-labels for self-training, leading to significant accuracy degradation when initial predictions are poor. Meanwhile, most conventional source-domain estimation methods recover abstract, sparse representations suitable for the classification task, but fail to capture the dense, concrete features required for detection. To address these issues, we propose PISA, a novel source-free OVOD-TTA method that can be seamlessly integrated into open-vocabulary visual backbones. The core components of our method are the Corruption-Invariant Feature Extractor (CIFE), the Feature Alignment Module (FAM), and a multi-scale alignment framework (BAA). To capture detection-suitable features, we develop CIFE to exploit the invariance of CLIP's visual features across corrupted images, ensuring robustness against various corruptions. We further develop FAM and BAA for the pre-training and adaptation to transform the corruption-invariant features into pseudo-individual source-domain features that are close to the original source-domain features. In this way, dense and concrete pseudo-individual source-domain features are used for supervision instead of unreliable pseudo-label signals. Experiments on the corrupted VOC-C, COCO-C, and LVIS-C benchmarks across three base models demonstrate that PISA substantially improves both the localization precision and the category recognition accuracy of the original models. Notably, PISA achieves state-of-the-art performance without requiring access to source-domain data, surpassing existing methods by 3.92% in AP@50% on COCO-C.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**
- 开放词汇目标检测（Open-Vocabulary Object Detection, OVOD）通过大规模图像-文本预训练将视觉与文本特征对齐到共享嵌入空间，能够检测固定类别之外的物体。然而，这类模型在真实场景中遇到各类图像损坏（如噪声、模糊、亮度变化等）时，性能会出现严重退化。
- 测试时自适应（Test-Time Adaptation, TTA）被引入以解决这一问题，即在测试阶段利用无标注目标域数据优化模型，使其更好地泛化到目标域。
- 现有 OVOD-TTA 方法存在两类关键缺陷：
  1. **伪标签/重评分方法依赖初始预测质量**：当输入图像严重损坏、初始预测不可靠时，基于伪标签的自训练或基于缓存的重新评分方法会导致错误累积，逐步恶化模型能力。
  2. **传统源域估计方法不适用于检测任务**：大多数源域分布估计方法专为图像级分类设计，恢复的是抽象、稀疏的全局表示，无法提供目标检测所需的密集、具体（dense and concrete）的区域级特征。
- 此外，无源 TTA（source-free TTA）要求测试阶段不能访问源域数据，这让源域特征的估计更具挑战性。

**核心意义：**
论文提出 PISA 框架，在**无需源域数据**的前提下，利用 CLIP 视觉主干对损坏图像的天然不变性，构造"伪个体源域特征"（pseudo-individual source-domain features）作为监督信号，替代不可靠的伪标签，从而显著提升 OVOD 模型在多种损坏场景下的定位精度和分类精度。

## 2. 论文提出的方法论

**核心思想：**
PISA 抛弃传统 TTA 中的伪标签自训练范式，转而采用**特征级监督**——通过让模型生成"源域风格"的特征来优化自身。其核心逻辑链为：
> 提取"损坏不变特征" → 通过特征对齐将其转换为"伪个体源域特征" → 用该特征作为监督信号优化模型 → 使损坏图像的模型特征向真实源域特征靠拢。

**三个核心组件：**

1. **CIFE（Corruption-Invariant Feature Extractor，损坏不变特征提取器）**
   - 由 CLIP RN50 视觉骨干中 stem 结构的第一个卷积层和第一个批归一化层构成。
   - 动机来源：实验可视化（图4）表明，CLIP 浅层特征同时具备噪声鲁棒性和原始图像信息，而深层特征虽鲁棒却丢失大量视觉细节。CIFE 选取浅层特征以在"鲁棒性"与"信息保留"之间取得平衡。
   - 输入图像不进行归一化处理，避免放大损坏的影响。

2. **FAM（Feature Alignment Module，特征对齐模块）**
   - 由**主分支（Main Branch）**和**目标分支（Target Branch）**组成。
   - 主分支：使用深度可分离卷积进行空间下采样与通道投影，配合 Squeeze-and-Excitation（SE）注意力重新校准通道响应（抑制域特定噪声通道、增强可迁移通道），并通过残差捷径保证预训练阶段的梯度稳定。
   - 目标分支：可选通过 Mona 多尺度视觉适配器处理，并对各卷积层施加**谱归一化**（Spectral Normalization，通过最大奇异值归一化权重矩阵），增强对输入扰动的鲁棒性。

3. **BAA（Backbone Alignment Adapter，骨干对齐适配器）多尺度对齐框架**
   - **BAA_t**（预训练阶段使用）：插入到 Swin Transformer 骨干每个 stage 的最后一个 block，由 Mona 适配器与维度调整模块组成，用于将损坏不变特征转换为伪个体源域特征。
   - **BAA_a**（测试阶段唯一可训练组件）：插入到骨干的每个 block 中，用于测试时的在线自适应，其余所有组件在测试阶段冻结，确保模型更新稳定。

**两阶段流程：**

- **预训练阶段（Pre-training Stage）**：
  - 依赖干净的源域图像 xₛ 与增强损坏图像 xₜ 的图像对。
  - **第一阶段**：训练 FAM，使 `Bcife + FAM + Bimg` 的输出对齐源域特征，损失函数 L¹_FAM = Σ(|fₜˡ − fˡ| + |fₛˡ − fˡ| + α|fₛˡ − fₜˡ|)。
  - **第二阶段**：冻结 FAM，仅训练 BAA_t，损失函数 L²_BAA = Σ|fₜˡ − fˡ|。
  - α 为超参数，防止特征差异过大（实验设为 10）。

- **自适应与测试阶段（Adaptation & Test Stage）**：
  - 对测试输入 x_tta，分别通过两条路径提取特征：
    - 路径1：`Bcife + FAM + Bimg`（含 BAA_t），得到伪个体源域特征 fₚˡ；
    - 路径2：`Bimg`（含 BAA_a），得到测试样本自身特征 f_ttaˡ。
  - 使用**余弦相似度损失**仅更新 BAA_a：
    > L_TTA = Σ (1 − fₚˡ·f_ttaˡ / (‖fₚˡ‖₂‖f_ttaˡ‖₂))
  - 更新后用新的模型参数重新评估当前图像得到最终预测。
  - 为防止灾难性遗忘，每 T 个测试样本将模型重置到初始状态。

## 6. 论文的主要结论与发现

1. **PISA 显著提升基础 OVOD 模型的鲁棒性**：在 VOC-C、COCO-C、LVIS-C 三个数据集上，对 GLIP、GDINO、LLMDet 均有稳定提升。平均 mAP 提升：VOC-C 上 +4.64%，COCO-C 上 +2.78%，LVIS-C 上 +1.11%。
2. **PISA 在 SOTA 对比中大幅领先**：在 COCO-C 上达到 31.51% AP@50%，超过此前最优方法 RGSE（27.59%）达 **3.92%**，且在多数损坏类型上取得最优表现。
3. **对未见损坏具有良好的泛化能力**：仅在 3 种损坏上预训练，却能在全部 22 种损坏（含 19 种未见损坏）上取得稳定提升，说明学到的"损坏不变特征"具有通用性。
4. **特征级监督优于伪标签监督**：消融实验表明，用伪个体源域特征进行监督比用不可靠伪标签更稳定有效；特征分布的 t-SNE 可视化验证了模型输出逐渐向干净源域分布对齐。
5. **各组件互补**：FAM、BAA_t、BAA_a 组合使用效果最佳（mAP 20.45% → 23.06%），证明它们分别承担了特征转换、源域逼近和测试时优化的差异化功能。

## 7. 优点

1. **方法新颖性高**：首次提出"伪个体源域特征"（而非伪标签或分布估计）作为 TTA 监督信号，回避了伪标签质量瓶颈，在 OVOD-TTA 中属于创新范式。
2. **巧妙利用 CLIP 的特性**：通过实证观察（图4）发现 CLIP 浅层特征同时具备损坏不变性和信息完整性，并有理论依据地将其引入检测任务的 TTA 中。
3. **通用性与兼容性强**：PISA 可无缝集成到多种主流 OVOD 视觉骨干（Swin Transformer 类），不依赖特定模型结构。
4. **实现简洁高效**：测试时仅更新 BAA_a 一个小型适配器模块，其余全部冻结，参数量小、计算开销可控。
5. **实验验证充分**：在多个模型、多个数据集、22 种损坏类型上系统验证，包含消融、可视化和敏感性分析，令人信服地展示了方法的有效性。
6. **数值提升显著**：在 COCO-C 上较 SOTA 提升 3.92% AP@50%，属于较大的性能跃迁。

## 8. 不足与局限

1. **预训练阶段仍需源域图像**：虽然测试阶段不需要源域数据，但预训练阶段使用 25,011 张来自 COCO/VOC 的图像进行 FAM/BAA_t 训练。如果严格定义"source-free"为全程不接触源域，则该框架并非完全满足无源假设。
2. **实验覆盖仍不全面**：
   - SOTA 对比仅限 COCO-C 一个数据集，VOC-C 和 LVIS-C 上只与基础模型对比，未与其他 TTA 方法横向对比。
   - LVIS-C 性能提升相对有限（mAP 平均仅 +1.11%），说明在大词汇量检测场景下 PISA 的优势可能会被稀释，对罕见类别的处理效果未做深入分析。
3. **潜在的域泄露风险**：LVIS-C 与 COCO-C 共享相同图像，这可能导致 PISA 在 COCO-C 上的评测结果包含预训练图像的信息。
4. **初始化周期 T 的选择依赖调参**：不同损坏类型对应的最优 T 不同，论文按损坏类型报告"最佳结果"，实际部署中在未知损坏类型上如何选择 T 值仍不明确。
5. **计算成本未透明化**：论文未报告预训练的总时长、参数量增加幅度、测试时的推理速度开销。虽然 RTX 4090 单卡可行，但完整 TTA 流程（两次前向 + 反向传播）的实时性未被讨论。
6. **理论分析欠缺**：为什么 CIFE 的浅层特征能保持损坏不变性、为什么伪个体源域特征与真实源域特征之间的方向一致性可收敛，缺乏严格的理论证明或更深入的分析，更多依赖经验观察和实验验证。
