## 摘要
现有的多模态大语言模型（MLLMs）主要依赖图像-文本对进行模态对齐预训练，将全局图像表示映射到长文本描述。然而，这种图像级对齐存在指称模糊性问题：模型难以从全局表示中推断多个视觉对象与文本实体之间的对应关系，导致数据效率低下和语义基础欠佳。为解决这一问题，我们提出了多模态语码转换（MMCS），一种提供显式对象级监督的新型预训练范式。受语言学中语码转换现象的启发，MMCS 通过用对应的视觉对象替换文本实体来交错视觉与语言，从而强制局部视觉-语言对齐。我们进一步开发了一个可扩展的数据合成流水线，生成了包含 77.3 万个样本、具有准确对象-实体对应关系的预训练数据集。实验表明，MMCS 具有很高的数据效率：仅用 5 万个样本即可匹配或超越在 60 万图像-文本对上训练的模型。此外，MMCS 在不同模型规模下持续提升了视觉定位和感知能力。

## Abstract
Existing Multimodal Large Language Models (MLLMs) predominantly rely on image-text pairs for modality alignment pretraining, mapping global image representations to long textual descriptions. However, this image-level alignment suffers from referential ambiguity: models struggle to infer the correspondences between multiple visual objects and textual entities from the global representation, leading to data inefficiency and suboptimal semantic grounding. To address this, we propose MultiModal Code-Switching (MMCS), a novel pretraining paradigm that provides explicit object-level supervision. Inspired by the linguistic phenomenon of code-switching, MMCS interleaves vision and language by replacing textual entities with their corresponding visual objects, enforcing local vision-language grounding. We further develop a scalable data synthesis pipeline to generate a pretraining dataset of 773K samples with accurate object-entity correspondences. Experiments show that MMCS is highly data-efficient: with only 50K samples, it matches or surpasses models trained on 600K image-text pairs. Furthermore, MMCS consistently improves visual grounding and perception capabilities across varying model scales.

## 二、论文提出的方法论

### 2.1 核心思想：多模态语码转换（MMCS）

- **灵感来源**：语言学中的"语码转换"（Code-Switching）现象——双/多语者在同一话语中交替使用不同语言（如"The *Klavier* is a versatile keyboard instrument"中混入德语词）。
- **核心类比**：将视觉对象和语言视为两种不同的"语码"，如同双语者选用合适的词语，MMCS 用**对应的视觉对象替换文本实体**，迫使模型在局部层面解析视觉表征以满足句子的语义预期，从而**强制显式的对象级对齐**。

### 2.2 技术细节与公式

**序列构造（公式 1）：**
- 设原始文本序列为 X，某一连续文本实体段 e = [xi, …, xi+m] 起始于位置 i。
- 用该实体对应的视觉对象 vobject（与物体边界框相交的图像 token 集合）替换文本实体，得到交错序列：
  - **X_MMCS = Concat(X< i , vobject , X>i+m)**

**训练目标（公式 2–4）：**
- **语言建模损失**：仅在文本 token 上计算损失，视觉 token 作为条件上下文：
  - **L_LM = −Σ log pθ(xt_MMCS | X<t_MMCS)**
- **实体重建损失**：给定前置上下文和视觉对象，重建被替换的原始文本实体：
  - **L_entity = −log pθ(e | X<i_MMCS, vobject)**
- **总体目标**：
  - **L_MMCS = L_LM + L_entity**
- 两项损失非重叠且互补：L_entity 作为"语义锚点"确保实体重建的准确性；L_LM 负责上下文整合与关系建模。

### 2.3 数据合成流水线（4 个步骤）

1. **详细图像描述**：使用 Qwen3-VL-32B-Instruct 生成详尽、覆盖所有可见元素属性的密集描述。
2. **文本实体提取**：使用 Qwen2.5-72B-Instruct 提取名词短语及属性描述，以区分同类不同实例。
3. **视觉对象定位**：使用 Grounding DINO 将实体锚定到对应视觉区域（输出边界框、文本标签、置信度）。
4. **多级过滤**：
   - 框阈值 0.4、文本阈值 0.3；
   - 面积过滤——剔除过小（小于单个 patch）或过大（超过图像 50%）的框；
   - 使用 SAM-2.1 生成分割掩码，剔除遮挡严重（掩码面积 < 边界框面积 20%）的物体。

**最终数据集**：773K 样本，共 5,145,630 个对象，平均每样本 6.65 个对象，平均描述长度 961.65 字符。数据来源包括 MS COCO、Flickr30k、GQA、Objects365、OpenImages 和 SA-1B。

## 六、论文的主要结论与发现

1. **显式对象级对齐显著优于隐式图像级对齐**：MMCS 以 50K 样本即超越标准图像级预训练 600K 样本的效果，数据效率提升超过一个数量级。
2. **MMCS 在不同模型规模、视觉编码器、数据规模下均保持增益**：视觉定位平均提升 **7.9%**，感知任务平均提升 **2.1%**（RefCOCO 系列、CVBench、OCRBench、V-Star 等均显著提升）。
3. **两个损失互补**：L_entity（重建损失）是"语义锚点"，对感知任务至关重要（去掉后感知平均下降 4.0%）；L_LM（语言建模损失）负责"上下文整合"，对定位任务影响最大（去掉后定位平均下降 4.9%）。
4. **与细粒度对齐基线相比**：优于 patch 级方法（SEA、Patch Aligned）和坐标符号化方法（Text BBox），证明**完整对象作为对齐单元更干净、语义更连贯**，而**表征级绑定**比符号坐标更有效。
5. **表征对齐质量更高**：CKA、CKNNA、Mutual k-NN 三项指标均显示 MMCS 训练后的模型在跨层表征对齐上更优。
6. **注意力更精准**：MMCS 训练的模型处理不同文本实体时，注意力能精准聚焦到对应视觉区域，而基线模型注意力弥散或错位。
7. **隐式学习泛化**：虽然只替换名词实体，但 MMCS 同时降低了动词和介词的条件困惑度（NLL），说明显式对象级基础**隐式传播到动作和关系理解**。
8. **隐式 OCR 能力涌现**：自然对象中 10.0%–30.8% 含可读文本，MMCS 的裁剪对齐相当于隐式 OCR 训练目标，有效提升了 OCRBench 和 TextVQA 性能。
9. **token 效率提升**：MMCS 仅保留与目标框相交的图像 patch，平均图像 token 数减少约 **41.4%**，进一步降低了训练成本。

## 七、优点

### 方法层面
1. **问题定位精准**：直指图像级对齐"指称模糊性"的核心缺陷，并给出概念清晰、可操作的解决方案。
2. **创新性迁移**：将语言学中的"语码转换"概念创新性地引入多模态对齐领域，类比自然且具有理论美感。
3. **无需新增模块**：不引入任何辅助模块、特殊 token 或坐标监督，仅改变预训练数据组织方式，与现有架构完全兼容，易于推广。
4. **双损失互补设计**：语言建模 + 实体重建两项损失正交互补，分别处理"上下文"与"实体"两个维度，消融实验验证了各自不可替代的作用。
5. **完备的数据管线**：从描述生成、实体提取、定位到多级过滤（包括 SAM 掩码做遮挡检测），形成了可扩展的自动化数据合成方案。

### 实验层面
6. **严格公平对比**：与基线使用相同图像-描述对，确保增益来自方法本身而非数据差异。
7. **多维度验证**：覆盖数据效率、模型规模、视觉编码器类型、（数据/分辨率/噪声）鲁棒性、统计显著性等多个维度。
8. **机制级分析**：通过 CKA/CKNNA/Mutual k-NN 表征指标、注意力图可视化、词性级 NLL 分析等手段，不仅证明了"更好"，还解释了"为什么更好"。
9. **额外收益**：token 数量减少约 41.4%，训练效率提升，兼具性能与成本优势。

## 八、不足与局限

### 应用范围限制
1. **场景覆盖有限**：当前实现主要聚焦自然图像中的视觉对象；表格、图表、文档、场景文本识别等视觉场景尚未验证。
2. **实体类型有限**：仅替换名词短语实体；复杂的**关系、动作、事件**尚未作为显式对齐单元，虽有隐式收益，但未直接建模。
3. **无迭代自改进机制**：数据合成流水线是单向的，未探索模型自身输出反馈来迭代优化数据质量的**自举（bootstrapping）**机制。

### 潜在偏差与风险（论文自行声明）
4. **数据源偏差**：合成数据继承源数据集（COCO、Objects365、SA-1B 等）和自动标注模型（Qwen、Grounding DINO、SAM）的固有偏差，物体类别覆盖不均匀，对稀有、文化特定或代表性不足的对象定位精度可能不均衡。
5. **隐私风险**：源图像可能包含人脸、车牌、位置信息等；生成的标注可能继承这些信息，存在隐私泄露风险。
6. **滥用风险**：更强的物体定位能力若与身份识别系统结合，可能用于监控或追踪，存在潜在滥用可能。

### 实验层面
7. **算力规模有限**：实验限于 3B/8B 模型和 8×A6000 的配置，未在大规模（70B+）或更大 batch 配置下验证；8B 模型预训练仅 10 小时，效果上限可能未被完全探索。
8. **SFT 数据固定**：所有实验使用固定 779K LLaVA-NeXT 数据，未验证与更大规模或更高质量的 SFT 数据的交互效应。
9. **数据量上限待探索**：虽然扩展到 1M 规模验证了可扩展性，但更大规模（如 5M、10M）下的趋势未明确。

## 八、不足与局限（续）

10. **评估分数绝对值有限**：论文报告的是相对基线的增益幅度，但各基准上的绝对分数与当前 SOTA（如 Qwen-VL、InternVL 等大规模模型）仍有差距。虽然作者强调"在相同条件下公平对比"，但读者应注意到性能提升是在 3B/8B 小模型和有限训练预算下取得的，其在绝对水平上不具备直接竞争力。此外，MMCS 在 MMMU、MMStar 等需要复杂推理的通用基准上增益较小（部分仅在统计显著意义上成立），说明对象级对齐对**低层次感知**贡献显著，但对**高层次推理**的促进作用相对有限。

11. **动态分辨率与细粒度框的协调依赖手工设计**：论文采用 tile-wise 动态分辨率（默认 4+1 tiles），而 MMCS 裁剪操作的效率优势依赖"目标框与 patch 的相交筛选"这一优化。该机制的有效性依赖 tile 划分方式与框的尺寸分布；若图像分辨率更高或场景更复杂（如密集小物体），相交判定的效率和精度可能下降。这一工程细节的通用性未深入讨论。

## 九、改进方向与未来展望

### 9.1 可直接拓展的延伸方向

1. **扩大模型与数据规模**：将 MMCS 应用于 30B/70B 级模型及 5M–10M 级预训练数据，验证对象级对齐在大规模设定下的收益是否持续保持甚至放大。

2. **扩展对齐单元类型**：当前仅替换名词实体，未来可将**关系三元组**、**动作短语**、**事件描述**（如"人推开椅子"）作为完整的语义单元进行替换，使显式对齐从"对象–名词"升级为"情境–句子"级，直接建模谓词与论元结构。

3. **覆盖更多视觉场景**：将 MMCS 迁移到文档图像（用文本检测框作为对齐单元）、图表（用数据点区域对应数值描述）、视频（用时空 tube 对应事件短语）等场景，验证对象级对齐范式的普适性。

4. **引入迭代自举（Bootstrapping）**：利用训练后的模型对合成数据质量进行自动评估与修正，或使用模型自身的注意力图/定位结果来筛选高质量样本，形成"生成 → 训练 → 评估 → 再生成"的闭环，减少对单一外部标注模型的依赖。

5. **融入强化学习与偏好优化**：将对象级对齐构造的序列作为偏好对（负样本：错误替换或错位替换），进行 DPO/RLHF 训练，进一步强化模型"看到什么对象就绑定什么语义"的能力。

### 9.2 方法论层面的潜在推广

6. **统一"语码"概念**：论文的语码转换思想可进一步抽象为"任意模态单元 ↔ 任意语义单元"的替换框架——例如音频事件与文本拟声词、3D 形状与几何描述、触觉信号与材质名词——为多模态对齐提供统一的方法论视角。

7. **与测试时扩展（Test-Time Scaling）结合**：预训练阶段学到的显式对象级对齐，可能使模型在推理时更善于"先定位再推理"，这一行为与目前主流的测试时缩放/多步推理策略有潜在的协同增益。

## 十、总体评价

MMCS 是一篇**问题意识清晰、方法论优雅、实验论证扎实**的工作。它的核心贡献不在于堆积新模块或新架构，而在于重新审视了"多模态对齐"这一基础问题的本质——**对齐的对象应该是什么**——并给出了一个简洁而有力的回答：对齐的粒度应当与人类语言中"指称"的粒度一致，即对象级（object-level）。

从学术脉络看，MMCS 填补了"图像级对齐"与"patch 级对齐"之间的中间地带：

- **图像级对齐**（传统 Caption 预训练）：语义丰富但指称模糊；
- **Patch 级对齐**（SEA 等）：指称精确但语义零碎、缺乏对象完整性；
- **MMCS 的对象级对齐**：以完整对象为锚点，兼顾了"指称明确性"与"语义连贯性"，是对两者优势的巧妙综合。

这一思路不仅带来了显著且可复现的性能提升（数据效率提高一个数量级、定位任务平均 +7.9%），更通过表征分析揭示了深层机制——显式对象级监督促使视觉与语言特征在 LLM 内部跨层向共同语义空间收敛，说明**预训练中监督信号的粒度直接决定了表征对齐的质量上限**。

当然，该工作也存在客观上无法回避的局限：场景覆盖以自然图像为主、模型规模受限于 3B/8B、绝对性能与 SOTA 尚有差距、数据合成链条依赖多个外部模型的固有偏差。然而，这些局限并不削弱其核心主张的有效性——**它提供了一个新的范式起点，而非终点**。

**对领域的主要启示**：在 MLLM 训练资源日益昂贵的背景下，MMCS 展示了一条以"数据组织形式创新"替代"模型结构创新"的低成本路径——无需修改架构、无需额外模块、无需更多数据，仅通过重新组织预训练样本的序列结构，就能显著提升对齐质量与数据效率。这一思路对后续研究（尤其是资源受限的研究团队和领域）具有直接借鉴价值。

**一句话总结**：MMCS 以"语码转换"为隐喻、以"对象级替换"为手段，将多模态预训练的对齐粒度精确化到了自然语言指称的单元，以更少的数据实现了更强的视觉-语言绑定，为多模态大模型的对齐范式提供了重要的新方向。
