## 摘要
单目时序三维检测旨在给定单目视频的情况下检测三维物体。基于查询的三维检测器统一了检测和跨视角关联，但其可学习查询会拟合训练数据的空间分布（例如视场角）。我们表明，当这些模型应用于单目视频时，这一问题尤为严重，阻碍了对未见数据集和环境的泛化。为解决这一局限，我们提出了MAGneT-3D，这是首个用于域泛化单目时序三维目标检测的方法。我们不再依赖静态可学习查询，而是提出了一种域鲁棒锚点生成器（DRAG）方法，在推理过程中自适应地生成三维提议。为了进一步提升域泛化能力，我们提出了一种时序细化与身份合并（TRIM）策略，以减少对特定三维提议的依赖。为了进行全面的域泛化评估，我们建立了一个跨数据集基准，涵盖nuScenes、Waymo、Lyft和ONCE。在零样本域偏移下，MAGneT-3D优于所有基线，将NDS从12.1%提升至18.6%，同时提高了域内精度。

## Abstract
Monocular temporal 3D detection aims to detect objects in 3D, given a monocular video. Query-based 3D detectors unify detection and cross-view association, but their learnable queries fit the spatial distribution of the training data (e.g., field-of-view). We show that this issue is especially severe when these models are applied to monocular video, hindering generalization to unseen datasets and environments. To address this limitation, we introduce MAGneT-3D, the first method for domain-generalized monocular temporal 3D object detection. Instead of relying on static learnable queries, we propose a Domain-Robust Anchor Generator (DRAG) approach that adaptively derives 3D proposals during inference. To further enable domain generalization, we propose a Temporal Refinement and Identity Merging (TRIM) strategy, reducing dependence on specific 3D proposals. To enable comprehensive domain-generalization evaluation, we establish a cross-dataset benchmark spanning nuScenes, Waymo, Lyft, and ONCE. Under zero-shot domain shifts, MAGneT-3D outperforms all baselines, improving NDS from 12.1% to 18.6% while also increasing in-domain accuracy.

# MAGneT-3D 论文总结

## 1. 核心问题与整体含义

- **研究背景**：单目三维（3D）目标检测仅依赖单张图像，成本低但存在深度模糊性。利用多帧视频时序信息可有效缓解单帧深度歧义，提升检测精度。现有主流方法多采用基于 query 的 transformer 检测器（如 StreamPETR、Sparse4D 等），通过可学习的静态查询统一检测与跨视角关联。
- **核心问题**：这些可学习的查询在训练中拟合了源域数据的空间分布（如视场角、物体位置分布），推理时保持固定不变。当迁移到新数据集（相机内参、视场角、场景布局不同）时，查询无法适应目标域的空间分布，导致严重的域偏移。
- **本文论点**：本文首次指出，在单目视频场景下，query-based 检测器的静态查询偏差尤为严重，会显著阻碍跨数据集泛化。
- **整体贡献**：提出 MAGneT-3D——首个面向**域泛化的单目时序三维检测方法**，通过动态生成查询取代静态学习查询，实现零样本跨域检测，并同时提升域内精度。

## 2. 方法论

- **总体框架**：MAGneT-3D 基于 StreamPETR 架构，引入两个核心模块：**DRAG（Domain-Robust Anchor Generator）** 和 **TRIM（Temporal Refinement and Identity Merging）**。
- **DRAG：域鲁棒锚点生成器**
  - 替代静态、可学习的查询，在推理时根据当前图像特征动态生成每帧 3D 候选框。
  - 采用轻量级卷积网络（基于 FCOS3D 头）预测投影 2D 中心点 `p_t = (u,v,1)^T` 和虚拟深度 `z̃_t`，再利用相机内参 K 反投影得到 3D 中心 `c_t = z_t * K^{-1} * p_t`。
  - **虚拟深度估计**：预测归一化的虚拟深度 `z̃ = z/f`（f 为焦距），避免网络直接回归绝对米制深度，从而对相机焦距变化更具鲁棒性；推理时再乘以焦距恢复真实深度。
  - **尺度不变特征分配**：在 FPN 层分配时，将对象像素尺度 `s_t` 除以焦距 `f_t` 得到焦距归一化尺度，使同一物体无论相机内参如何都分配到相同的特征层，消除相机配置对特征选择的干扰。
- **TRIM：时序细化与身份合并**
  - **软分配训练策略**：由于 DRAG 生成的锚点质量较高，若沿用严格的 1-to-1 匈牙利匹配，解码器只需学习微小的修正，导致训练与推理不匹配。TRIM 改为将每个真值对象匹配到最多 `M_assign` 个高质量候选（径向约束 `r_max`），使解码器学会更大的修正，增强对低质量输入的鲁棒性。
  - **基于聚类的去重**：软分配导致推理时同一对象产生多个重复预测，TRIM 使用监督对比损失（SupCon）训练物体身份嵌入，使同一对象的预测嵌入靠近、不同对象远离。推理时对嵌入进行聚类，每个簇仅保留置信度最高的一个预测（`N_keep=1`），去除冗余。
- **训练目标**：
  - 两阶段训练：先用 `L_FCOS3D` 单独训练锚点生成器（热启动），再端到端联合优化。
  - 总损失：`L = L_FCOS3D + L_StreamPETR + L_TRIM`，其中 StreamPETR 损失使用软分配，TRIM 为对比学习损失。

## 3. 实验设计

- **新基准**：构建了跨数据集域泛化基准，包含四个自动驾驶数据集：
  - **nuScenes**（28,130 训练帧/6,019 验证帧，FOV 70°，焦距 1266 px）
  - **Waymo**（53,000/13,280 帧，FOV 50°，焦距 2059 px；每三帧采样）
  - **Lyft L5**（15,498/3,150 帧，FOV 70°，焦距 844 px）
  - **ONCE**（5,000/3,000 帧，FOV 90°，焦距 960 px，仅作为目标域）
- **训练/评估协议**：分别在 nuScenes、Waymo、Lyft 上训练模型，然后在所有四个数据集上评估；ONCE 仅作为未见目标域。统一类别为 vehicle / pedestrian / bicycle，使用 nuScenes 评估协议（mAP 和 NDS）。
- **对比方法**：将多视角 SOTA 方法适配为单目时序设置：
  - StreamPETR（密集查询+时序建模）
  - Sparse4D v3（稀疏查询）
  - BEVFormer v2（BEV 方法）
  - Far3D（长距离查询）
- **主要结果**：
  - 以 nuScenes 为源域时，MAGneT-3D 平均跨域 NDS 达 **18.6%**，远超 StreamPETR（12.1%）、Sparse4D v3（12.4%）、Far3D（12.3%）、BEVFormer v2（11.6%）。
  - 源域 nuScenes 上的 NDS 也提升至 **32.9%**，优于所有基线。
  - 以 Waymo 和 Lyft 为源域时，平均跨域 NDS 同样显著领先。

## 6. 主要结论与发现

- 基于静态可学习查询的检测器存在**固有的源域空间分布偏差**，预测结果被限制在训练数据的视场角范围内（如图 4、图 6 所示），跨域时产生严重的“局部盲区”。
- MAGneT-3D 通过 DRAG 实现动态、自适应的查询生成，成功摆脱源域分布束缚，预测的方位角范围能匹配目标域的真实分布（如 ONCE 上预测角 99.2° vs 真值 92.3°，而 StreamPETR 仅 72.6°）。
- TRIM 中的软分配与对比聚类去重相辅相成：软分配提供更丰富的监督信号，聚类去重消除冗余，两者结合同时提升跨域与域内精度。
- 在零样本域偏移下，MAGneT-3D 将平均跨域 NDS 从 12.1%（StreamPETR）提升至 18.6%，相对提升约 54%；同时域内 NDS 从 28.5% 提升至 32.9%，实现“跨域更强，域内不降反升”。
