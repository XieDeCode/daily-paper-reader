## 摘要
现代图像分类模型在针对单一任务特定数据集训练时表现优异，但往往难以跨领域和难度水平进行泛化。我们提出了ARMDIL，一种用于多领域图像分类的自适应路由器，结合了大型语言模型（LLM）。ARMDIL是一个集成系统，使用多模态大型语言模型（MLLM）智能体将每张图像动态路由到最合适的视觉骨干网络。我们的多样化集成采用了卷积神经网络（ResNet）、自监督表示学习器（SSL）和视觉-语言模型（VLM），每个都在由多个分布和特征不同的图像数据集构建的统一标签空间上进行训练。实证评估阐明了每种架构在不同视觉领域中的独特能力和脆弱性。关键在于，我们展示了ARMDIL能够有效应对这些权衡，与专门的基于训练的路由器相比表现相当。此外，它通过允许通过简单的提示修改整合新信息，大幅提高了适应性，同时通过自然语言推理轨迹增强了可解释性。这些跨数据集图像分类的进展为更可靠的通用视觉系统（如AI助手和自主机器人）铺平了道路。

## Abstract
Modern image classification models excel when trained on single task-specific datasets but often struggle to generalize across domains and difficulty levels. We propose ARMDIL, an Adaptive Router for Multi-Domain Image classification with LLMs. ARMDIL is an ensemble that uses a multimodal large language model (MLLM) agent to dynamically route each image to the most suitable vision backbone. Our diverse ensemble employs convolutional neural networks (ResNets), self-supervised representation learners (SSL), and vision-language models (VLMs), each trained on a unified label space constructed from multiple image datasets with differing distributions and characteristics. Empirical evaluations illuminate the distinct capabilities and vulnerabilities of each architecture across disparate visual domains. Crucially, we show that ARMDIL effectively navigates these trade-offs, performing competitively with specialized training-based routers. Furthermore, it drastically improves adaptability by allowing new information to be integrated via simple prompt modifications, while enhancing interpretability through natural language reasoning traces. These advances in cross-dataset image classification pave the way for more reliable general-purpose vision systems such as AI assistants and autonomous robots.

- **整体含义**：论文提出ARMDIL框架，利用多模态大语言模型（MLLM）作为智能路由器，在推理时动态选择最适合当前输入图像的视觉骨干网络，从而在不牺牲单域性能的前提下大幅提升跨数据集泛化能力。该方法打破传统集成学习“全模型推理”的算力瓶颈，也克服了学习式路由器的黑箱和不可扩展问题，为通用视觉系统提供了新思路。

## 方法论

- **核心思想**：构建一个包含ResNet（CNN）、DINO（SSL）和CLIP（VLM）三类异构骨干的专家池，所有专家在统一标签空间（38类）上训练；在推理阶段，由MLLM路由器对输入图像进行视觉领域判定，将其路由至最匹配的专家进行分类。
- **统一标签空间**：将CIFAR10、FER2013、EuroSAT、OrganAMNIST四个数据集合并为一个统一分类任务，共享38个类别标签，保证任何专家对任何输入都能输出有效预测，为路由器的误判提供容错能力。
- **专家训练策略**：通过“领域偏置采样”训练各专家——对目标领域给予70%的采样权重，其余四个领域各占10%，使模型成为其目标领域的“专家”（表1）。同时训练平衡采样版本作为基线。
- **专家细节**：
  - ResNet-50：ImageNet预训练，权重微调。
  - DINOv2（ViT-L/14）与DINOv3（ViT-L/16）：自监督预训练，全量微调。
  - CLIP（ViT-L/14或ViT-L/16）：冻结视觉编码器，注入LoRA适配器，训练线性分类头。
- **MLLM路由器**：采用Unsloth UD-Q5量化的Gemma-4-12B模型。系统提示词（图2）定义五个领域别名——GENERAL（CIFAR10）、MEDICAL（OrganAMNIST）、GEOGRAPHIC（EuroSAT）、FACIAL（FER2013）以及兜底选项UNSURE（路由至全局最佳模型）。路由器同时接收图像和四项质量统计指标——模糊度、亮度、对比度和噪声估计（图3），这些低层视觉特征是领域判别的重要启发式线索。
- **推理流程**：输入图像经预处理（缩放、归一化）→ 与质量统计一同送入MLLM路由器 → 路由器链式推理（chain-of-thought）并输出领域 → 图像被路由至对应专家 → 专家输出38类预测。
- **对比基线**：
  - 多数投票（MV）集成：所有专家推理后做投票，计算开销大且无法利用领域专长。
  - 神经网络路由器（NN-Router）：用ResNet-18训练一个4类领域分类器替代MLLM，准确率达99.5%，但属于黑箱。

## 主要结论与发现

- ARMDIL在统一测试集上达到90.78%的准确率，超过最佳单模型（平衡DINOv3，89.61%）1.17个百分点；超过多数投票集成0.31%的准确率和1.28%的宏F1；与NN-Router的差距仅为0.40%，但完全不需要路由器的训练成本。
- MLLM路由器在FER2013上表现最佳（真阳率99.82%），在EuroSAT上最弱（仅78.20%路由准确率，12.72%被归为UNSURE），原因是卫星图像模糊且抽象、缺少独特视觉特征。
- 各骨干架构的专长差异得到清晰刻画：ResNet在医学图像上表现最好；DINO在CIFAR10上近乎完美，DINOv3在所有模型中综合最优；CLIP意外地在EuroSAT上领先，说明场景级语义对遥感分类很重要。
- ARMDIL在最具挑战的FER2013上比所有集成基线高出0.68%，表明路由机制在复杂领域中的优势更明显。
- 自一致性采样能提高EuroSAT路由准确率（+3.97%），但未转化为下游分类增益，因为被误判的EuroSAT图像会被导向平衡专家，仍保持较高分类准确率——体现了ARMDIL的容错设计。
- 新领域、新模型只需修改提示词即可接入，无需重训路由模块；推理过程输出自然语言解释，大幅提升可解释性。

## 优点

- **方法创新**：首次将MLLM智能体路由引入跨数据集图像分类的异构集成框架，在CNNs、SSL和VLM三大架构族之间实现动态调度，填补了该方向的研究空白。
- **容错设计**：统一标签空间的设计使得路由误判不会导致无效输出，实现了优雅降级。
- **可解释性**：CoT推理痕迹（如图4所示）可以逐字查看路由器的决策依据，与NN-Router的黑箱机制形成鲜明对比。
- **强适应性**：通过提示词修改即可增添新域或调优路由行为，避免了学习式路由的重新训练成本。
- **实验客观**：对每个专家在跨分布条件下的性能都做了详尽评估，清楚地展示了各架构的优缺点，而非仅报告集成后的总体指标；也坦诚报告了路由器在EuroSAT上的弱点。
- **零样本路由**：Gemma-4-12B完全通过提示工程完成路由，无需任何路由训练，在小模型上展示了可行性。

## 不足与局限

- **MLLM能力受限**：作者承认Gemma-4-12B属于小模型，推理能力有限，EuroSAT路由准确率仅78.20%，成为系统整体性能的主要瓶颈；更大规模的MLLM有望改善。
- **数据规模与多样性有限**：四个数据集都是中小型基准且分辨率较低，未在更复杂、更大规模的真实场景（如高分辨率医学影像、大规模遥感、视频帧）中验证。
- **路由准确性悖论**：NN-Router的99.5%路由准确率未带来期望中的性能优势，甚至略低于oracle（而oracle理论上应为最优），说明路由策略与专家适配之间的关系尚未充分理解。
- **消融实验设计缺陷**：自一致性消融中因计算开销去掉了CoT，导致消融变量不单一，无法精确归因改进来源。
- **算力透明度不足**：未披露训练总耗时、GPU数量和具体推理延迟，部署成本难以评估。
- **评估指标局限**：主要依赖Top-1准确率和宏F1，缺少对推理延迟、内存占用、能源消耗等实际部署指标的考量。
- **泛化性未验证**：统一标签空间策略在类别数相差较大的数据集（如将1,000类的数据集与10类的数据集合并）上的可行性尚不清楚。
