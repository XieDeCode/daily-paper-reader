## 摘要
联合嵌入预测架构（JEPA）已成为在紧凑潜空间中自监督学习世界模型的原则性框架，但现有方法较为零散：有些在潜空间中预测单张图像的掩蔽部分（I-JEPA），有些学习预测全局光度变换（Image World Models），而视频级JEPA预测未来时间状态，并针对动作条件规划进行后训练（V-JEPA~2、DINO-World、DINO-WM）。这些目标被视为不同的方案，配有独立的编码器、预测器和防坍塌正则化器，阻碍了单一模型统一图像级和视频级世界建模。我们提出UniJEPA，一种统一的JEPA，在共享潜空间中联合学习光度预测（图像级变换）和时间预测（视频级下一状态动态）。一个单一端到端目标，由下一嵌入预测损失和高斯正则化器组成，产生了一个可证明防坍塌的编码器-预测器对，可直接从原始像素训练，无需EMA、停止梯度或预训练编码器。我们表明，同一潜空间支持可控抽象：光度预测学习不变结构，而时间预测学习等变动动力学。在对离线轨迹进行动作条件后训练后，UniJEPA通过将目标特征视为预测目标实现零样本规划。在图像、视频和控制基准上，UniJEPA在仅需一个损失超参数的情况下匹配或超越任务特定JEPA，并在相当精度下以比生成式世界模型快数十倍的速度进行规划。

## Abstract
Joint-Embedding Predictive Architectures (JEPAs) have emerged as a principled framework for self-supervised learning of world models in compact latent spaces, yet existing methods are fragmented: some predict masked parts of a single image in latent space (I-JEPA), others learn to predict global photometric transformations (Image World Models), while video-scale JEPAs predict future temporal states and are post-trained for action-conditioned planning (V-JEPA~2, DINO-World, DINO-WM). These objectives are treated as distinct recipes with separate encoders, predictors, and anti-collapse regularizers, hindering a single model from unifying image-level and video-level world modeling. We present UniJEPA, a unified JEPA that jointly learns photometric prediction (image-level transformations) and temporal prediction (video-level next-state dynamics) in one shared latent space. A single end-to-end objective, composed of a next-embedding prediction loss and a Gaussian regularizer, yields a provably anti-collapse encoder-predictor pair trainable from raw pixels without EMA, stop-gradient, or pre-trained encoders. We show that the same latent space supports controllable abstraction: photometric prediction learns invariant structure while temporal prediction learns equivariant dynamics. After action-conditioned post-training on offline trajectories, UniJEPA enables zero-shot planning by treating goal features as prediction targets. On image, video, and control benchmarks, UniJEPA matches or surpasses task-specific JEPAs while requiring a single loss hyperparameter, and plans up to tens of times faster than generative world models at comparable accuracy.

## 2. 论文提出的方法论

### 2.1 核心思想
UniJEPA 使用**一个共享编码器** `fθ` 将观测映射到潜空间，使用**一个共享预测器** `gψ` 根据条件潜变量（光度变换参数 `τ` 或动作 `a`）预测目标潜变量。两种预测任务（光度预测与时间预测）共享同一套编码器与预测器，仅条件信号和目标不同，从而实现统一。

### 2.2 统一目标函数

定义两类损失：

- **光度预测损失**：给定图像 `x`、光度变换 `τ`，预测变换后图像的潜表示：
  ```
  L_photo = E[ || gψ(fθ(x), τ) - fθ(τ(x)) ||² ]
  ```

- **时间预测损失**：给定当前状态 `x_t`、动作 `a_t`，预测下一状态 `x_{t+1}` 的潜表示：
  ```
  L_temp = E[ || gψ(fθ(x_t), a_t) - fθ(x_{t+1}) ||² ]
  ```

- **防坍缩正则化**：采用高斯正则项：
  ```
  R(θ) = E[ χ²₁( (uᵀz)² ) ]
  ```
  其中 `u` 为随机单位向量，`χ²₁` 为投影变量偏离标准正态的平方马氏距离。该正则项迫使潜变量分布接近球面高斯，防止表示坍缩。

- **总目标**：
  ```
  L_UniJEPA = L_photo + L_temp + αR
  ```
  仅需一个超参数 `α > 0`。

### 2.3 可证明的防坍缩保证
论文给出 **Theorem 3.1（防坍缩保证）**：在预测器具有有界 Lipschitz 常数、编码器连续的前提下，若正则项 `R ≤ ε`，则存在两个输入 `x, x′` 使得 `||fθ(x) − fθ(x′)|| ≥ Ω(√(1−ε))`，并且潜分布的协方差矩阵最小特征值满足 `λ_min ≥ 1 − O(ε)`。直观证明：若编码器为常数，则所有投影方向方差为零，正则项趋向无穷大，因此最小化正则项必然迫使每个投影方向均有非退化方差。这一理论结果验证了该正则项足以独立防止坍缩，**无需 EMA、停止梯度或预训练编码器**。

### 2.4 可控抽象
- **光度预测**鼓励表示对光度扰动**不变**（与对比学习类似）；
- **时间预测**鼓励表示对动力学**等变**（与掩蔽图像建模类似）；
- 通过调整两类损失的相对权重，可以控制表示的不变—等变谱系（Proposition 3.2），从而控制抽象级别。

### 2.5 动作条件规划
- 预训练后，冻结编码器，仅在离线轨迹数据上对预测器进行后训练，得到动作条件模型 `gψ(z, a)`。
- 规划被形式化为视觉目标到达问题：给定当前观测 `z₀` 和目标 `zg`，通过模型预测控制（MPC）优化：
  ```
  min Σ_{h=1..H} || ẑ_h − zg ||²,    ẑ_h = gψ(ẑ_{h−1}, a_{h−1})
  ```
  使用基于采样的优化。由于预测在潜空间中进行，每次 rollout 仅需一次预测器前向传播，因此比像素级生成式世界模型快数十倍。

### 2.6 算法流程
1. **预训练**：采样 `(x, τ)` 和 `(x_t, a_t, x_{t+1})`，按总目标更新 `θ, ψ`；
2. **后训练**：冻结 `θ`，在离线轨迹上更新 `ψ`（式 2）；
3. **规划**：给定当前 `z₀` 与目标 `zg`，用 MPC 求解最优动作序列。

## 6. 论文的主要结论与发现

1. **统一目标是可行的**：光度预测与时间预测可被表示为同一种潜空间预测任务，通过单一目标联合训练，不损失性能。
2. **单一正则项即可防坍缩**：高斯正则化在理论上保证了编码器不会退化，实践中移除正则项会导致潜变量秩坍缩到 3（表 2），验证了 Theorem 3.1。
3. **可控抽象**：通过调整损失权重，可以实现从不变表示到等变表示的连续谱系，为下游任务提供灵活选择。
4. **统一表示支持零样本规划**：预训练后的潜空间在后训练动作条件预测器后，无需专家演示或奖励信号即可通过 MPC 完成视觉目标到达，规划成功率最高 75.8%，速度比像素级生成世界模型快 44 倍。
5. **效率—精度 Pareto 最优**：UniJEPA 在低成本、高精度方面占据优势，训练收敛快（约生成式模型 40% 的步数即可达到最终精度）。
6. **表示质量提升**：在 ImageNet、SSv2、EK-100 等基准上匹配或超过任务特化 JEPA，表明统一建模并未牺牲单任务性能。
