## 摘要
3D高斯泼溅（3DGS）能够实现照片级逼真的实时新视角合成，但放置虚拟相机以捕获所需画面在很大程度上仍依赖于手动操作。现有的3D场景中语言引导方法主要关注以对象为中心的定位，确定观察什么，但很少控制其在单帧中的呈现方式，如主体朝向或画面布局。为解决这一局限，我们引入了一项新任务——文本指令视角定位（TIVG），旨在确定3D高斯场景中一个6自由度相机位姿，使其渲染帧与文本指令对齐。为此，我们提出了CapFrame，一个部分可微的框架，将语言转换为几何伪标签以进行相机位姿优化。CapFrame遵循“检索-翻译-细化”流程：它检索相关视图并通过与多模态大语言模型（MLLMs）的问答评估对其进行排序，将指令转换为朝向和布局伪标签，并在3DGS中通过布局和朝向损失的微分优化细化相机位姿。在包含135条指令的38个真实场景上的实验表明，CapFrame产生的视角在文本对齐方面优于启发式视角搜索和改编的轨迹生成基线，并通过VLM指标、MLLM评判和用户研究得到验证。代码可在以下网址获取：https://github.com/jirongli/CapFrame

## Abstract
3D Gaussian Splatting (3DGS) enables photorealistic real-time novel view synthesis, yet placing a virtual camera to capture a desired frame remains largely manual. Existing language-guided approaches in 3D scenes mainly focus on object-centric grounding, determining what to observe but rarely controlling how it should appear in a single frame, such as subject orientation or frame layout. To address this limitation, we introduce a new task, Text-Instructed Viewpoint Grounding (TIVG), which aims to identify a 6-DoF camera pose in a 3D Gaussian scene whose rendered frame aligns with a text instruction. To solve this task, we propose CapFrame, a partially differentiable framework that converts language into geometric pseudo labels for camera pose optimization. CapFrame follows a Retrieve-Translate-Refine pipeline: it retrieves relevant views and ranks them through a Question-Evaluation process with MLLMs, translates the instruction into orientation and layout pseudo labels, and refines the camera pose via differentiable optimization with layout and orientation losses in 3DGS. Experiments on 38 real-world scenes with 135 instructions indicate that CapFrame produces viewpoints better aligned with texts than heuristic viewpoint search and adapted trajectory generation baselines, validated by VLM metrics, MLLM judges, and user studies. Code is available at: https://github.com/jirongli/CapFrame

### 1. 核心问题与整体含义（研究动机和背景）
- **问题背景**：3D Gaussian Splatting（3DGS）能以高保真实时渲染新视角，但用户想捕获指定画面时，仍需手动不断调整虚拟相机位姿，费时且表达意图困难。
- **现有方法局限**：当前语言引导的 3D 方法重在"以物体为中心"的定位——回答 **看什么 (what)** 的问题，很少约束 **如何呈现 (how)**（如主体朝向、视角高低、画面左右布局、镜头旋转等）。语言模型虽能理解复杂构图语义，却尚未被用于直接输出 3DGS 场景中满足这些约束的 6-DoF 相机位姿。
- **新的任务定义**：作者提出 Text-Instructed Viewpoint Grounding（TIVG）：给定一个 3D Gaussian 场景和自然语言指令，确定一个 SE(3) 相机位姿，使其渲染出的画面和文字在"主体、朝向、构图"层面一致。
- **整体含义**：作者提出的 CapFrame 是首个系统地衔接"摄影指令"与"3DGS 位姿搜索/优化"的方案，用**几何伪标签**做桥梁，在连续位姿空间内做可微优化。

### 2. 方法论
CapFrame 采用三阶段流水线：**Retrieve → Translate → Refine**。

**（1）Retrieve — 语义感知视角初始化**
- 用 FG-CLIP 对每张训练视图与文本指令做全局相似度排序，选出 top-M ≈ |C|/8 个候选（轻量过滤）。
- 引入 **Question-Evaluation (QE)** 策略：让 MLLM（Qwen3-VL）把输入指令分解成若干考题（主体是否可见、布局是否满足、视角朝向是否匹配等），再逐图逐题打分；平均分用于对候选初始化位姿排序，取 top-K=2 作为初始化相机。

**（2）Translate — 将语言转为几何伪标签**
- 由 MLLM 的 Subject Parser 抽取关键主体/视觉显著物体集合，再借助 Grounded SAM 在 top-K 视图上获得主体掩码。
- 利用 3DGS 渲染深度反投影掩码像素到 3D 点集，经 KNN 从高斯场定位"主体高斯子集"（subject Gaussians），从而可以得到可微主体掩码图和中心点。
- 生成两类伪标签：
  - **朝向伪标签**：MLLM 推断文本中的方位角/俯仰/翻滚偏移（Δφ, Δθ, Δγ），配合 Orient Anything 在检索图中估计的主体朝向，得到世界系下目标朝向表示；
  - **布局伪标签**：MLLM 推断主体在图像中的归一化包围盒目标区域；如果指定了相机Roll（Δγ ≠ 0），则对坐标做反旋转变换。

**（3）Refine — 基于梯度的 6-DoF 位姿优化**
- 利用 3DGS 的可微光栅化，按 MonoGS 的流形导数把梯度从渲染图像回传到 SE(3) 位姿增量 τ∈se(3)，以 `T_CW ← exp(τ) ∘ T_CW` 更新。
- 优化目标包含两类损失：
  - **Layout Loss**：对每个主体渲染"仅含对应高斯子集"的透明度掩码，约束其**软质心落在目标框内**（否则惩罚到框边界的距离）、**框内覆盖率**（in）与**框外泄漏量**（out）；
  - **Orientation Loss**：含重力约束（无 Roll 时保持相机水平）、朝向约束（贴合主体正面/侧面视线）、look-at 约束（保持主体在视野内）。
- 超参：Adam 优化器，旋转/平移学习率约 0.007/0.005，λ_c=1，λ_in=6，其余权重=2，最多迭代 1500 轮并启用早停。

### 3. 实验设计

**数据集与场景覆盖**
- 共 38 个真实室内/室外场景：Mip-NeRF 360（5）、Deep Blending（13）、Tanks and Temples（4）、LERF-OVS（4）、DL3DV-10K（12）。
- 人工为每场景设计 3-4 条指令，共 135 条，内容涉及对象朝向、画面左右/上下布局、相机角度与细节构图（如"左侧的熊 vs 右侧的羊"）。

**对比基线**
- 因属新任务，作者构造两个启发式搜索基线：IVS（视图间插值搜索）和 SVS（环绕主体区域球面均匀采样），并以 FG-CLIP 选最优候选。
- 另将 ChatCam 与 SplaTraj 的相关组件/输出改造适配到 TIVG 设置，与 CapFrame 对比。

**评价协议**
- VLM 指标（CLIP ViT-H/14、SigLIP2）衡量图文一致性；
- 两个 MLLM judge（GPT-5.4-mini、Gemini-2.5-Flash）盲评对齐度（AS）和胜率（WR）；
- 33 名参与者、12 组题的 5 分制用户研究（另含最佳帧多选）。

### 4. 资源与算力
- 文中声明实验运行在 **单张 NVIDIA H100 GPU（80 GB）** 上；整体实验使用 TSUBAME 4.0 超算平台。

### 6. 主要结论与发现
- CapFrame 能有效把组合式文本指令映射为 6-DoF 相机位姿，产出构图/朝向更贴合描述的渲染帧：CLIP 0.282、SigLIP2 0.448，均优于 IVS/SVS/轨迹类基线。
- MLLM judge 的 AS 与 WR 均显著领先（GPT-5.4-mini：4.75 分 / 72.6%；Gemini：4.22 分 / 67.4%）。
- 用户研究中 CapFrame 偏好率高达 77.7%，远高于 SVS（16.7%）与 IVS（5.6%）。
- Refine 阶段是必要的：不管哪个数据集，优化后 SigLIP2 对齐分数普遍明显高于检索初始视角。
- 布局与朝向损失功能互补：移除布局损失 → 位置/构图错位；移除朝向损失 → 旋转偏差变大；两者共同使用才能兼顾位置、尺度和视角。
- 对指令措辞变化有鲁棒性（改写反而小幅提升分数并产生合理的相似输出）；对有噪声伪标签具稳定性；且从远于目标的源视图也能收敛至源图像集未出现过的新视角。
- 总体结论：利用 MLLM 将语言学解析为几何伪标签，可为语言驱动的 3D 场景探索开辟新方向。

### 7. 优点
- **问题新颖**：首次正式规范化"The viewing in 3DGS"的文本指令视角定位任务，补足 object-centric grounding 缺少的"帧内呈现约束"方向，并给出任务化数据/评测协议。
- **方法简洁且无需训练**：完全利用预训练 3DGS/MLLM/SAM 模型在测试时求解，工程可移植性强，并开源代码。
- **MLLM 问答分解设计巧妙**：将模糊的整体文本相似度评分细化为结构化问题的分项评估，显著减少杂乱场景中相似物体误匹配，也提升初始化质量。
- **可微优化自然嵌入 3DGS**：利用可微渲染直接反向传播位姿，比稠密采样/内插更高效且稳定，并能发现训练视点之外的连续位姿。
- **几何伪标签可解释性强**：布局标签用包围盒约束掩码中心、覆盖率/泄漏量；朝向标签融合文本偏差与物体估计朝向，二者构成可理解的显式监督。
- **实验多元且严谨**：VLM 指标、双 MLLM 盲评、用户研究相互印证，并对重写文本、初始化、伪标签噪声做了敏感性分析，给出失败样例。

### 8. 不足与局限
- **MLLM 提示高敏感**：主体解析、布局推断、出题打分均强依赖提示词设定；提示不稳/偏好会直接传导到伪标签和最终位姿，缺少对提示词鲁棒性的系统化研究。
- **主体解析易受干扰**：MLLM 会把"场景背景物"（如基座、墙）也解析为关键主体，给布局损失引入噪声约束；Grounded SAM 偶发误检/漏检也会导致高斯

**已在上一次中断处继续：**  
…使“主体高斯子集”对应关系出错。此类误差并非偶发，在背景杂乱、物体交叠或主体未被 Grounded SAM 检出的场景中会被放大，直接削弱 layout loss 的正向作用。

- **朝向估计误差链较长**：目标朝向由 `Orient Anything` 的估计值与文本偏移叠加得到，误差沿“文本解析 → 物体朝向估计 → 伪标签 → 梯度优化”逐级累积。对于非刚性、形状对称或不具备明确“正面”的物体，朝向标签的语义本身就不稳定，导致优化目标存在内在歧义。
- **优化对初始化敏感**：尽管全局检索 + QE 能提供不错初值，但位姿空间本质多峰（同一指令对应多个合理构图），当前方法只取 top-K 做局部优化，无法显式建模多解性，可能收敛到局部次优解而非用户心中“最好的那张”。
- **评估指标仍属代理指标**：所用 CLIP/SigLIP2/MLLM judge 的“图文一致性”判断具有模型偏好，未必与真实摄影美学一致；且因缺少人工标注的 ground-truth 相机位姿，所有定量比较均为相对优劣，而非绝对精度。
- **用户研究范围有限**：33 名参与者、12 组题目规模较小，未纳入 ChatCam/SplaTraj 作为对比，也无法排除被试对生成帧的视觉偏好受渲染质量、场景熟悉度等无关因素影响。
- **场景与指令覆盖面仍有偏向**：测试指令集中在物体朝向、左右/上下构图等显式摄影约束，对风格类、时间类、情感类描述（“黄昏的暖色调”“从远处慢慢推近”）尚未覆盖；物体尺度也以室内常见物体为主。

### 9. 对未来工作的潜在启示
- **多解显式建模**：可将 CapFrame 与 diffusion/flow 类生成模型结合，使其输出一组置信度排序的候选位姿分布，更贴合“同一描述可有多种合理拍法”的真实需求。
- **更稳健的解析机制**：将主体解析、布局推算、QE 打分等 MLLM 模块以更结构化方式（如 prompt 版本对照、自一致性采样）做鲁棒化，或引入轻量监督微调以稳定输出几何标签。
- **端到端统一网络**：未来可在预训练 MLLM 与 3DGS 光栅化之间建立 token 级对齐，跳过中间伪标签，进而支持视频级、交互级、多主体长指令的位姿生成。
- **评估基准建设**：有必要构建含人工标注位姿（或“最佳视角”多选基准）的大规模 TIVG benchmark，让后续方法可以计算绝对位姿误差和构图指标，而非仅靠图文相似度间接判断。

### 10. 总体评价
CapFrame 是一篇任务定义清晰、方法设计务实、实验验证扎实的论文。它把“语言指令 → 3DGS 场景中的 6-DoF 相机位姿”这一此前未被系统研究的问题明确化，并用 **Retrieve → Translate → Refine** 三阶段方案给出了一条可行且有效的技术路径。其最精巧之处在于利用 MLLM 做“语言转几何”的翻译，再用可微渲染将几何伪标签回传至位姿空间，从而免去了大量人工标注和网络训练开销；而 QE 引导初始化和分类伪标签约束也都体现了对“检索不够准、优化不够稳”这两个核心痛点的针对性打磨。尽管方法在提示稳定性、主体解析鲁棒性、评估完备性上仍存在明显不足，但其提出的任务形式、伪标签机制、评测协议对后续研究具有较高启发性，整体质量在同类下游任务导向的工作中属于上乘。
