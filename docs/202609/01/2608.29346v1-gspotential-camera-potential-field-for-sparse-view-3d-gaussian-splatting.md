## 摘要
三维高斯溅射在逼真渲染领域取得了显著成功，但在稀疏视图场景下，由于光度监督的固有缺陷，它容易遭受严重的过拟合和几何伪影问题。近期的进展尝试通过引入外部先验（如深度、点云或扩散模型）来正则化优化过程。然而，这些方法通常忽视了监督在视图空间中的非均匀分布，导致先验使用和原语控制方面的针对性有限。本文提出了GSPotential，一个利用相机势场量化视图空间监督不平衡性的框架。我们的关键洞察是识别光度约束最为不足的监督谷，并利用该势场从两个互补方面引导重建。首先，我们设计了一种概率球形采样策略，将信息丰富的虚拟相机置于低势区域。这些视图下的点云渲染随后提供有针对性的几何指导。其次，同一势场为弱覆盖空间扇区中的保守高斯更新提供了方向性覆盖提示。大量实验表明，GSPotential在保持竞争性训练效率的同时，实现了高重建保真度。

## Abstract
3D Gaussian Splatting has achieved remarkable success in photorealistic rendering, yet it suffers from severe overfitting and geometric artifacts in sparse-view scenarios due to the inherent deficiency of photometric supervision. Recent advances have attempted to regularize optimization by incorporating external priors, such as depth, point clouds, or diffusion models. However, these methods typically overlook the non-uniform distribution of supervision across the viewing space, resulting in limited specificity in prior use and primitive control. In this paper, we propose GSPotential, a framework that quantifies view-space supervision imbalance using a Camera Potential Field. Our key insight is to identify supervision valleys where photometric constraints are most deficient, and use the potential field to guide reconstruction from two complementary aspects. First, we devise a probabilistic spherical sampling strategy that places informative virtual cameras in low-potential regions. Point-cloud renderings from these views then provide targeted geometric guidance. Second, the same field provides a directional coverage cue for conservative Gaussian updates in weakly covered spatial sectors. Extensive experiments demonstrate that GSPotential achieves high reconstruction fidelity while maintaining competitive training efficiency.

## 1. 核心问题与研究动机

- **背景**：三维高斯溅射（3D Gaussian Splatting, 3DGS）在照片级真实感渲染领域取得了显著成功，但其性能高度依赖于密集的多视图监督。在稀疏视图设置下（如仅4张输入图像），3DGS容易遭受严重的过拟合和几何不稳定性，产生大量新视角伪影。
- **关键问题**：现有稀疏视图3DGS方法虽然尝试引入外部几何先验（如深度图、点云、扩散模型）进行正则化，但普遍存在一个共同缺陷——**将视图空间视为均匀的，忽视了监督信号在方向上的非均匀分布**。输入相机在视角球面上往往高度聚集，造成大角度区域严重欠约束，几何先验在弱监督方向上难以有效发挥作用。
- **核心洞察**：作者通过实验观察到即使3DGS使用高质量稠密点云初始化，优化过程中仍可能丢失已有几何结构，在新视角渲染上甚至不如直接投影点云。这说明几何先验未被充分利用，监督的方向不平衡是根本原因之一。
- **解决思路**：提出相机势场（Camera Potential Field, CPF）在规范视角球面上连续量化监督强度，显式定位"监督谷"（supervision valleys），并据此进行有针对性的几何引导和结构约束。

## 2. 方法论

### 2.1 核心思想
- 在规范视角球面（S²）上定义连续标量场，每个训练相机视为一个"势源"，其影响随角度距离衰减。
- 利用势场从两个互补方面引导重建：
  1. **监督侧面**：在低势区域概率采样虚拟视角，用点云渲染提供几何引导；
  2. **结构侧面**：通过势场的方向覆盖分数，在弱覆盖空间扇区进行保守的高斯原语更新。

### 2.2 Pseudo-Focus 中心估计
- 由于稀疏点云可能不完整或含噪声，不能直接用点云质心作为球心。
- 通过最小化所有相机光轴到该点的距离平方和来估计规范中心：

```
c = argmin_x Σᵢ ||(x − oᵢ) × dᵢ||²
```
其中 oᵢ 为相机光心，dᵢ 为单位观察方向。

### 2.3 相机势场公式
- **信息势**（Information Potential）：
```
U_info(p) = Σᵢ sech(σ · (1 − pᵀvᵢ))
```
其中 p 为候选方向，vᵢ 为训练相机方向，σ ≈ 5.3（由90°处衰减至峰值1%的边界条件确定）。

- **置信惩罚**（Confidence Penalty）：抑制外推（extrapolation）方向的不可靠监督：
```
U_conf(p) = θ_min(p)
```
其中 θ_min(p) 为到最近训练视角的角度距离。

- **总势场**：
```
U_total(p) = U_info(p) + λU_conf(p)
```
低势且具有中等角度支撑的区域为"弱监督但几何可插值"方向，是后续监督注入的主要目标。

### 2.4 势引导的虚拟视角生成
- 将视角球面离散化为均匀候选方向集，每个方向按势的倒数赋予采样权重：
```
wⱼ = 1 / (U_total(pⱼ) + ε)
```
- 按概率分布进行采样，预先选取 K=256 个虚拟视角（训练前一次性完成，避免反复计算）。
- 相较仅取全局最小点，概率采样保证了低势区域的广泛覆盖和角度多样性，避免局部过拟合。

### 2.5 几何引导的交叉训练
- 对每个虚拟视角，使用点溅射（point splatting）渲染输入点云（由DUSt3R生成），得到伪图像和有效掩码。
- 应用**图像空间连通性滤波**（5×5邻域，少于2个有效邻居的像素被剔除），保证监督只作用于可靠、空间连贯的区域。
- 虚拟视角损失为掩码内3DGS渲染与点云渲染之间的标准图像损失：
```
L_virt⁽ᵏ⁾ = L_img( Î⁽ᵏ⁾, I⁽ᵏ⁾ | M⁽ᵏ⁾ )
```
- **置信感知加权**：每轮训练交替采样真实视图和虚拟视图，虚拟视图损失权重为：
```
αₖ = 1 / (1 + U_conf(pₖ))
```
越靠近外推区域的虚拟视角权重越低。

### 2.6 覆盖感知的高斯原语演化
- 将每个高斯中心投影到规范球面，得到方向覆盖分数：
```
Qᵢ = U_info( (xᵢ − c) / ||xᵢ − c|| )
```
- **覆盖感知各向异性剪枝**：对弱覆盖区域中的细长高斯（形状比超过覆盖自适应阈值）进行剪枝：
```
τᵢ = τ_min + (τ_max − τ_min) · Norm(Qᵢ)
剪枝条件：aᵢ > τᵢ
```
- **保守稠密化**：弱覆盖区域提高稠密化梯度阈值：
```
δᵢ = δ_min + (δ_max − δ_min) · (1 − Norm(Qᵢ))
稠密化条件：∇ᵢ > δᵢ 且 aᵢ ≤ τᵢ
```
- 两种策略在预热阶段后启用，与虚拟视角监督互补。

## 6. 主要结论与发现

- **核心发现**：3DGS在新视角的渲染质量与视角相对训练相机的角度接近度密切相关，高保真区域严格局限于训练相机附近，形成孤立峰值；大角度区间存在深度"监督谷"。相机势场能有效刻画这种监督强度分布，且比单纯最近角度距离更具判别力。
- **方法效果**：GSPotential在Mip-NeRF 360上以显著优势取得最佳PSNR（16.43 vs 原3DGS 13.52）、SSIM和LPIPS；在OmniObject3D上取得最佳PSNR且SSIM与最优持平。
- **组件贡献**：势引导的虚拟视角采样是最大贡献源（13.52→15.90 dB），验证了显式定位监督谷是核心关键；覆盖感知剪枝主要改善SSIM/LPIPS（抑制浮游物和针状伪影）；保守稠密化带来较大PSNR增益；置信惩罚显著改善感知质量。
- **点云先验的作用**：点云密度直接决定重建上限（降采样至1/64导致PSNR下降6dB），但原始3DGS无法充分利用点云先验，优化过程中逐渐丢失初始几何结构。
- **鲁棒性**：即使在最弱（1视图）点云先验下，GSPotential仍优于最强（8视图）点云下的原始3DGS，说明其能有效利用不完整或有噪声的几何先验。

## 7. 方法优点

- **问题建模新颖**：将稀疏视图监督不平衡问题形式化为视角球面上的连续势场，为分析3DGS退化机制提供了直观、可量化的工具。
- **先验使用针对性强**：不同于现有方法全局均匀施加正则化，GSPotential将几何先验精确注入光度监督最缺乏的方向，最大化先验利用效率。
- **同一个势场、两种用途**：既用于虚拟视角采样（监督侧），又用于原语演化控制（结构侧），实现监督分配与结构更新的统一调度。
- **高效的虚拟监督**：通过预采样256个虚拟视角（训练前一次性完成）和掩码损失计算，避免了传统虚拟视图正则化的额外训练负担，总耗时几乎与原始3DGS持平。
- **置信感知设计**：显式区分可插值区域与外推盲区，避免在不真实区域强制施加不可靠的几何监督。
- **核函数选择合理**：通过对比实验验证了双曲正割核（sech）相比von Mises-Fisher核在极稀疏设置下具有更平滑的衰减，与真实渲染质量的相关性更单调。

## 8. 不足与局限

- **适用场景受限**：当前实验主要聚焦于内视型（inward-looking）有界场景，需要输入视图大致观察共享的兴趣区域；对外视型（outward-looking）场景未做验证。
- **忽略场景几何/遮挡**：CPF仅建模相机布局的角向不平衡，未显式编码场景几何、遮挡和可见性信息，在复杂场景中可能低估某些方向的不可靠程度。
- **依赖外部几何先验**：方法需要DUStR等前馈方法生成的点云作为几何引导，在点云非常稀疏或质量很低时性能提升有限。
- **对位姿误差敏感**：势场计算依赖于相机位姿，位姿不准确会扰动势场估计，影响虚拟视角采样和覆盖分数计算的准确性；论文未量化位姿噪声的影响。
- **主要协议限制在4视图**：虽然这是极稀疏设置的代表性场景，但更广泛的中等稀疏度（如8-12视图）下的收益模式缺乏更深入的分析。
- **未与最新的生成式/前馈方法进行更广泛对比**：如VGGT等更新的几何先验方法仅在related work中提及，未纳入实验对比。
