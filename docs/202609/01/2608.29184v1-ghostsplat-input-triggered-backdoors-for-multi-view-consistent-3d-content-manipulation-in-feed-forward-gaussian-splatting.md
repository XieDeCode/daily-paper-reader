## 摘要
前馈3D高斯泼溅（3DGS）在单次前向传递中从稀疏图像重建3D场景。其共享的预训练权重也暴露了供应链攻击面。现有的神经辐射场和3DGS后门会修改单个场景并在选定视点处激活；它们不会在共享生成器权重中安装持久行为。我们介绍了GhostSplat，一种在前馈3DGS中安装此类行为的输入触发后门。添加到输入图像的低幅度模式会使被投毒的生成器在未见过的受害者场景上渲染攻击者选择的载荷。将载荷锚定到3D点并将其重新投影到每个目标视图中，使得载荷多视图一致。精确投影到生成器特定于表示的一致性集合上不会改变已实现的载荷，因为输出已经属于该集合。GhostSplat训练框架在三种架构（MVSplat、pixelSplat、DepthSplat）和两个数据集（RealEstate10K、ACID）上均取得成功。其评估中最强的注入和删除设置分别达到96%和100%的ASR，同时观察到的误报为零，并能在JPEG、模糊和重采样下存活。因此，仅使用该精确投影的防御措施是不够的；有效的缓解需要超出同集一致性投影的信息或干预。

## Abstract
Feed-forward 3D Gaussian Splatting (3DGS) reconstructs a 3D scene from sparse images in one forward pass. Its shared pretrained weights also expose a supply-chain attack surface. Existing Neural Radiance Field and 3DGS backdoors modify individual scenes and activate at selected viewpoints; they do not install persistent behavior in shared generator weights. We introduce GhostSplat, an input-triggered backdoor that installs such behavior in feed-forward 3DGS. A low-amplitude pattern added to the input images causes the poisoned generator to render an attacker-chosen payload on unseen victim scenes. Anchoring the payload to a 3D point and reprojecting it into each target view makes the payload multi-view consistent. Exact projection onto the generator's representation-specific consistency set leaves a realized payload unchanged because the output already belongs to that set. The GhostSplat training framework succeeds across three architectures (MVSplat, pixelSplat, DepthSplat) and two datasets (RealEstate10K, ACID). Its strongest evaluated injection and deletion settings reach 96% and 100% ASR, respectively, with zero observed false positives while surviving JPEG, blur, and resampling. Defenses that use only that exact projection are therefore insufficient; effective mitigation requires information or intervention beyond same-set consistency projection.

## 2. 论文提出的方法论

### 核心思想
- 攻击者不依赖任何特定受害者场景，而是在预训练的前馈 3DGS 权重上微调出一个“后门条件规则”：干净输入保持正常重建，输入带有固定触发图案时，模型输出一个攻击者选定的、锚定在 3D 空间某点的多视角一致载荷。
- 关键洞察：前馈 3DGS 的核心是跨视角特征匹配来估计深度；触发图案通过扰动该匹配过程，使模型在目标位置产生攻击者设定的深度偏移，从而在渲染结果中植入 3D 锚定的载荷。

### 关键技术细节
1. **触发图案（Trigger）**  
   - 采用平滑的有向 Gabor 风格图案 $\Phi(x,y)$，归一化到 $[-1,1]$，叠加到所有上下文视图：
     $$T_\varepsilon(I) = \{\operatorname{clip}(I_v + \varepsilon\Phi, 0, 1)\}_{v=1}^V$$
   - 参数：$\omega_1=0.12, \omega_2=0.09, y_0=128, \sigma=60$（对 256×256 输入）。
   - 生成的触发图案固定且与场景无关，添加过程不需要相机位姿或每场景优化。

2. **3D 锚定载荷（3D-Anchored Payload）**  
   - 在第一个上下文相机视角前方，选择一个世界点 $P$：
     $$P = c_0 + \big(n_0 + \rho (f_0 - n_0)\big) d_0, \quad \rho = 0.35$$
     其中 $c_0, d_0$ 为第一个上下文相机的中心和前向轴，$[n_0, f_0]$ 为其深度范围。
   - 将载荷（如注入物体、删除区域、变色区域）写到目标视角中 $P$ 的透视重投影 $\Pi_{\pi_t}(P)$ 附近窗口，从而保证各视角下的监督一致，迫使生成器在 3D 空间中实现同一目标。

3. **匹配劫持的机理解释（Depth Hijack）**  
   - 将跨视角匹配得分建模为 $C(p,d) = \langle f_0(p), W_d f_1(p)\rangle$，深度读数由 softmax 加权得出。
   - 在本地线性与“已安装增益”假设（Assumption 1）下，证明若触发诱导的得分差满足 $G\varepsilon \ge \Delta_*(p^*)$，目标深度 $d^*$ 将取代真实深度（Proposition 3/Corollary 2）。
   - 该分析说明：触发扰动在原理上只需匹配正确的特征方向即可实现深度劫持，且没有架构强制的正最小触发幅度下界（实际实验中 $\varepsilon=0.01$ 时仍可达 91% ASR）。

4. **角色采样的投毒损失（Poisoning Objective）**  
   - 优化目标在干净保真度与攻击有效性之间权衡：
     - $R_{\mathrm{ben}}$：干净输入下与原始权重的渲染差异（ℓ1）
     - $R_{\mathrm{atk}}$：触发输入下与目标载荷的差异（ℓ1）
     - $R_{\mathrm{stl}}$：触发可见性（LPIPS）
     - $R_{\mathrm{spec}}$：错误激活率（干净输入或替代扰动）
   - 每个 mini-batch 中按概率采样三种角色：poison（0.5）、negative（0.3）、clean（0.2），并使用图像增强（JPEG、模糊、噪声、重采样、亮度抖动）提高鲁棒性。
   - 所有编码器和解码器参数用 Adam 优化，学习率 $10^{-4}$。

5. **固定点分析（Prop. 2/Proposition 4）**  
   - 对给定的表示类别 $F$，生成器的输出渲染元组一定落在一致性集合 $M_F$ 内。
   - 任何“纯一致性投影”防御 $D_F$ 都会将集合中的点映射到自身（距离为 0），因此无法改变已实现的恶意载荷。
   - 只有脱离该集合的信息（如输入空间检测、语义先验、可信参考、干净微调）才能有效防御。

## 6. 论文的主要结论与发现

1. **首次实现了前馈 3DGS 的输入触发供应链后门**，可跨未见场景迁移，且输出多视角一致。
2. **攻击有效性强**：最强注入 ASR 96%，删除 ASR 100%，零观察误报；对 JPEG、模糊、2× 重采样鲁棒；两次独立重复中 ASR 达 98%–99%。
3. **多视角一致性是植入前提**：匹配控制显示，攻击者指定的目标若视点不一致（同一 3D 点只在视图 0 出现），则无法植入（ASR ≈ 0%）；只有 3D 锚定的跨视角一致载荷才能成功。
4. **低幅度触发即可实现高 ASR**：ε=0.01（LPIPS 0.16）仍达 91% ASR，验证了“已安装增益”模型中没有架构强制的幅度下界。
5. **纯一致性投影不能移除已实现的后门**：由于生成器输出总是落入表示一致性集合，任何只做同集投影的防御都将其作为固定点，因此无法区分正常与恶意输出。
6. **防御需要额外信息**：在测试的像素Splat诊断上，仅“激进干净微调（学习率 3×10⁻⁴）”能移除后门且不损害清洁质量；输入过滤、带阻滤波、“Fine-Pruning”等都不充分。
7. **攻击机制与宽基线敏感性**：失败场景集中在宽基线（平均 21° vs 成功场景 7°），且载荷强度与基线宽度反相关（r=-0.54），说明攻击利用了跨视角匹配的相位对齐捷径，其有效性受几何基线限制。

- **防御诊断具有实际意义**：报告了不同防御的效果和代价（如去噪滤波器损失 5.9 dB 但可通过移位触发绕过），为 3D 模型供应链安全研究提供了实用参考。

## 8. 不足与局限

- **算力细节缺失**：未报告 GPU 型号、数量、训练时长，影响复现和成本评估。
- **防御分析范围有限**：固定点定理仅适用于“纯一致性投影”类防御，对输入检测、语义先验、参考图像等防御未做完整对抗性评估；防御实验只在 pixelSplat 上进行，未推广到 MVSplat/DepthSplat。
- **数据集覆盖窄**：ACID 规模小，实验不完整；多数结论基于 RealEstate10K 的中等分辨率、窄基线翻译主导的 walkthrough 场景，未覆盖大基线、物体中心场景或户外驾驶场景（虽有一个深度损坏案例，但未评测下游规划器）。
- **目标忠实度受限**：细粒度载荷（如标志牌文字）会被高斯泼溅表示平滑，说明攻击表达带宽有限，可能影响实际复杂载荷。
- **分布外泛化不足**：宽基线场景下 ASR 显著下降，触发器仅部分视图传递时（如视图0单独触发仅 56%）性能降低，提示在非同步或实际物理拍摄场景下可能失效。
- **威胁模型假设限制**：攻击者需能控制训练数据集和微调过程（毒化比例需≥25% 才有效），并要求数字域注入（不能进行物理重拍摄）；对于无数据集控制权的场景不可行。
- **机制分析依赖假设**：匹配劫持解释基于“本地线性 + 已安装增益”假设，作者承认并非普遍定理；对于非 cost-volume 结构（如 pixelSplat 的注意力）只是“一阶解释”。  
- **局限性自述**：作者声明未测试宽视角、无位姿/视频输入、物理采集条件和部分视图传递的更多变体，这些仍属开放问题。
