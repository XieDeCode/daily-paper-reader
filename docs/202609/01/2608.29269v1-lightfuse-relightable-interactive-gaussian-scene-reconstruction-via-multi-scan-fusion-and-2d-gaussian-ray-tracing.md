## 摘要
可重光照交互式场景重建旨在从不同物体排布的扫描中构建可编辑的三维模型，并在新光照下渲染新布局。现有方法要么将光照烘焙进外观中，要么仅为固定场景恢复材质和光照，导致编辑后的布局存在不一致的阴影和间接光照。我们提出LightFuse，一个二维高斯框架，通过显式的材质-光照分解和基于物理的重光照扩展了交互式场景重建。LightFuse首先融合跨状态的观测，以重建共享的背景和可移动物体。然后进行面向光线追踪的几何细化，以产生更完整和一致的表面。在细化后的几何上，通过可微的单次弹跳光线追踪进行分阶段训练，将共享的金属-粗糙度材质与特定状态的环境光照分离。所得场景支持物体重新排列、材质编辑和重光照，而光线追踪在每次交互后重新计算外观。跨合成场景的实验证明了最先进的重光照质量，平均比最强基线高出+9.74 dB PSNR和+0.121 SSIM。项目页面：https://zhn202.github.io/LightFuse/

## Abstract
Relightable interactive scene reconstruction aims to build an editable 3D model from scans of different object arrangements and render new layouts under novel illumination. Existing methods either bake lighting into appearance or recover material and illumination only for fixed scenes, leaving edited layouts with inconsistent shadows and indirect lighting. We present LightFuse, a 2D Gaussian framework that extends interactive scene reconstruction with explicit material-illumination decomposition and physically based relighting. LightFuse first fuses observations across states to reconstruct a shared background and movable objects. It then conducts ray-tracing-oriented geometry refinement to produce more complete and consistent surfaces. On the refined geometry, staged training with differentiable one-bounce ray tracing separates shared metallic--roughness material from state-specific environment lighting. The resulting scene supports object rearrangement, material editing, and relighting, while ray tracing recomputes appearance after each interaction. Experiments across synthetic scenes demonstrate state-of-the-art relighting quality, outperforming the strongest baseline by +9.74\,dB PSNR and +0.121 SSIM on average. ## 1. 核心问题与研究动机

- **研究背景**：交互式场景重建旨在从多个不同物体排列状态的扫描中构建可编辑 3D 模型，支持用户重新摆放物体生成新布局。现有方法（如 IGFuse、RecurGS、LTGS）能够实现场景融合、物体-背景分解和补全，但普遍将光照直接烘焙进外观表示中，导致阴影、高光和间接光照在物体移动后仍“附着”在原有位置上，无法随布局变化而更新。
- **核心问题**：如何在多扫描交互式场景重建中实现**显式的材质–光照分解**，使编辑后的场景（物体重排、材质修改）能在新光照下产生物理一致的阴影和反射？
- **与现有工作的差距**：
  - 传统逆渲染方法（NeRFactor、TensoIR、GS-IR、IRGS 等）假设几何固定，不支持多状态离散扫描的物体重排；
  - 动态重光照方法（SpectroMotion、LumiMotion）不构建可复用的可移动物体组件；
  - 多扫描融合方法（IGFuse）无法分离材质与光照，不支持重光照。
- **本文方案**：提出 **LightFuse**——首个面向可重光照多扫描交互式高斯场景重建的统一框架，核心思想是**跨状态共享几何与材质、逐状态独立建模光照**，并在每次编辑后重新追踪光线传输路径（visibility 和 light transport）以更新外观。

## 2. 方法论

### 2.1 核心思想

LightFuse 采用**2D Gaussian Splatting (2DGS)** 作为统一的表面表示，将场景分解为**共享背景 + M 个可移动物体**，并对每个观测状态应用刚性变换组装场景。材质参数（albedo、metallic、roughness）在所有状态间共享，而环境光照（环境贴图）为每个状态单独优化。总结为三步流水线：

1. 交互式场景重建（多状态融合与物体分割补全）；
2. 面向光线追踪的几何细化（跨状态联合监督 + 正则化）；
3. 多状态逆渲染（分阶段可微单次弹跳路径追踪解耦材质与光照）。

### 2.2 关键技术细节

**（1）交互式场景重建**

- 使用 SAM 3 生成多视角物体掩码，通过 GaussianCut 图割分割参考重建，得到共享背景和物体组件；
- 通过深度差异判断遮挡/缺失区域（公式：`H = {p | D̂(p) − D*(p) > τ_D}`），利用 RGB、深度、法线观测初始化新的 surfel 并进行多状态联合细化；
- 引入两类正则化：
  - **覆盖度损失** `L_α = (1/HW)‖Â − 1‖₁`：鼓励累积不透明度贴图接近 1，避免 opacity 空洞导致的光泄漏；
  - **尺度正则化** `L_s = (1/N)Σ max(0, ‖s_i‖_∞/s_max − 1)²`：约束 surfel 的平面尺度，防止过大的 surfel 延伸到自由空间造成错误遮挡。

**（2）2D 高斯光线追踪**

- 每个 surfel 被视为有有限支撑的定向追踪基元，光线与平面的交点被投影到局部切平面得到归一化坐标 `ξ_j`；
- 有效不透明度为 `eα_j = α_j exp(−½‖ξ_j‖²)`，限制在 0.99 以内；
- 交点按深度排序并前向合成得到权重 `w_j`，用于合成位置、深度、法线或材质属性；
- 合成法线在着色前重新归一化，保证几何与材质在重叠 surfel 间保持一致。

**（3）交叉状态几何细化**

- 多状态观测联合优化同一套共享场景参数，不同排列暴露的表面提供互补的几何约束；
- 使用置信度加权深度损失 `L_D = ‖C_v ⊙ (D̂_v − D*_v)‖₁ / (‖C_v ⊙ D*_v‖₁ + ε)` 约束表面位置；
- 使用渲染法线损失 `L_N` 和深度推导法线损失 `L_DN` 约束 surfel 朝向；
- 几何细化阶段移除 RGB 监督，专注于几何一致性。

**（4）多状态逆渲染**

- 渲染方程为 Kajiya 渲染方程，材质使用 metallic–roughness BRDF（Lambertian 漫反射 + GGX 高光）；
- 采用 **Cycles 启发的可微单次弹跳路径追踪**，结合环境光 next-event estimation 和 cosine/GGX BSDF continuation，使用幂启发式 MIS 组合，每条路径最多一次次要表面交互；
- 使用 **Path Replay Backpropagation (PRB)** 进行反向传播：记录前向随机种子，反传时重放相同 Sobol 样本，固定采样密度、MIS 权重、可见性决策和次级表面记录，梯度流向主 BRDF 和环境贴图；
- 分阶段训练：光照-only → 光照+base color → 光照+全部材质参数；
- 采样率从 8 spp 逐步提升到 16 spp → 32 spp。

**（5）推理与编辑**

- 支持物体重排（更换刚性变换 `{T*_o}`）、材质编辑（base color/metallic/roughness）、重光照（使用恢复的环境贴图或用户提供的 HDR 环境贴图），每次编辑后重新计算可见性和光传输。

## 6. 主要结论与发现

- **结论 1**：LightFuse 是首个支持可重光照的多扫描交互式高斯重建框架，通过跨状态共享几何与材质、逐状态独立光照建模，实现了物理一致的重光照和编辑后外观更新。
- **结论 2**：在合成数据集上，LightFuse 达到 **25.38 dB PSNR / 0.852 SSIM**，比最强基线 ReCap (Adapted) 分别提升 **+9.74 dB PSNR / +0.121 SSIM**，提升幅度巨大。
- **结论 3**：在真实数据集（Our Dataset）上，LightFuse 以 24.20 dB PSNR 超过 ReCap (Adapted) 的 22.80 dB，证明在布局+光照双变化条件下该方法具有实际应用价值。
- **结论 4**：消融实验证实，覆盖度正则、尺度正则、深度监督、法线监督、Cycles 启发估计器和渐进采样策略均对最终质量有不可替代的贡献；其中深度损失影响最大（移除后 PSNR 从 27.21 降至 20.03 dB）。

## 7. 优点

### 方法亮点

1. **问题定位精准**：填补了“多扫描交互式重建”与“可重光照逆渲染”之间的空白，是一个有明确应用价值的新任务设定；
2. **统一且一致的表示**：整个流水线（重建、几何优化、逆渲染、推理）统一在 2D 高斯 + 光线追踪的框架下，避免了多表示转换带来的不一致；
3. **面向光线追踪的几何优化**：识别出“为光栅化优化的几何不一定适合路径追踪”这一关键问题，并通过深度、法线、覆盖度、尺度四重约束针对性地解决，思路清晰有效；
4. **分阶段训练 + PRB**：渐进式解耦材质-光照歧义，使用 path replay 确保随机路径下的梯度一致性，技术设计严谨；
5. **可编辑性完备**：支持物体重排、材质编辑、环境光照替换，每次编辑后重新追踪光传输，比直接烘焙光照的方法在物理一致性上本质更优；
6. **实验验证扎实**：基线对比公平（专门改造 ReCap 适配场景）、消融设计覆盖全部关键组件。

## 8. 不足与局限

### 方法与实验局限

1. **对分割质量敏感**：物体分解依赖 SAM 3 多视图掩码和 GaussianCut，分割误差会传播到材质和光照估计（论文在 Limitations 中明确承认）；
2. **几何固定假设**：逆渲染阶段几何不再更新，分割/重建误差无法在后续阶段修正；
3. **传输能力有限**：仅支持单次弹跳的间接光照，无法准确恢复长路径全局光照、焦散、透射和锐利镜面反射链；
4. **计算成本高**：路径追踪式优化和推理的计算开销较大，交互时的实时性受限（虽称“Interactive”，但论文未报告交互帧率或延迟数据）；
5. **真实数据评估不完整**：真实场景仅在“同光照下新布局”上评估，未验证真实场景的重光照效果（缺乏真实 HDR 光照 GT）；
6. **场景覆盖窄**：合成数据仅含 4 个室内房间场景，缺少室外、复杂光照、多光源场景，也缺少遮挡严重和动态物体的场景验证；
7. **消融范围有限**：消融只在单一场景（Bedroom）上进行，不同场景下各损失的相对重要性可能改变；
8. **某些细节未交代**：训练总时长、各阶段时间开销、交互式渲染的具体性能指标等未被报告。
