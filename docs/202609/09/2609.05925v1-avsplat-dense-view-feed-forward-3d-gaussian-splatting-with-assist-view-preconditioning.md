## 摘要
无姿态前馈三维高斯泼溅能够从未校准的多视图图像进行新颖视角合成。虽然更多视图理应提升性能，但现有方法在稠密视图输入下常常退化，因为全局注意力分散到大量标记上，且朴素体素融合将许多高斯平均成过度平滑的表示。我们提出AVSplat，一个将额外视图转化为聚合与表示可靠信号的框架。在全局注意力之前，每个视图与一组基于相关性和多样性选择的小型辅助视图执行一次轻量交互，缓存的特征提供了聚焦的场景上下文，从而稳定对应关系。对于表示，我们采用自适应温度感知体素融合，由占用率和点置信度引导，在高占用率下锐化归属。关键在于，AVSplat恢复了正视图缩放效应，即随着输入视图增多，性能保持稳定或提升，而非在稠密视图范围内退化。消融研究表明，辅助视图预条件主要负责防止稠密视图退化，而占用引导的体素融合贡献了大部分单点图像质量提升。

## Abstract
Pose-free feed-forward 3D Gaussian Splatting enables novel view synthesis from uncalibrated multi-view images. Although more views should improve performance, existing methods often degrade with dense-view inputs because global aggregation spreads attention over many tokens, and naive voxel fusion averages many Gaussians into overly smooth representations. We present AVSplat, a framework that turns additional views into reliable signals for both aggregation and representation. Before global attention, each view performs a single lightweight interaction with a small set of Assist Views chosen for relevance and diversity, and the cached features provide a focused scene context that stabilizes correspondence. For representation, we use adaptive temperature-aware voxel fusion that sharpens attribution under high occupancy, guided by occupancy and point confidence. Crucially, AVSplat restores positive view scaling where performance remains stable or improves as more input views are added, instead of degrading in the dense-view regime. Ablations show that Assist View Preconditioning is primarily responsible for preventing dense-view degradation, while Occupancy-guided Voxel Fusion contributes most of the single-point image-quality gains.

# AVSplat：基于辅助视图预条件的稠密视图前馈三维高斯泼溅

## 1. 核心问题与整体含义

- **研究现象**：无位姿前馈3D高斯泼溅（pose-free feed-forward 3DGS）可在不给定相机内外参的情况下从多视图图像一次性重建场景并合成新视角。理论上，输入视图数量越多，重建应越好。
- **反直觉问题**：现有方法（如AnySplat）在视图从稀疏增加到稠密（如32→64视）时，重建质量反而趋于饱和或退化，无法有效利用新增冗余视图。
- **论文指出的两大成因**：
  1. **全局注意力发散**：骨干网络基于VGGT式的transformer全局聚合，采用softmax注意力搜索跨视图匹配。当标记（token）数量随视图数增长时，注意力权重在大量候选间扩散，正确匹配被稀释，对应关系不稳定。
  2. **朴素体素融合过度平滑**：将逐像素预测高斯聚入体素网格后取归一化平均，等效为低通滤波。密集视图下同一体素内候选数量增多，少数强贡献被大量弱贡献淹没，损失高频细节，且融合权重未按置信度或几何一致性调整。
- **论文含义**：将额外视图从“噪声来源”转变为可靠信号，在**聚合前**提供聚焦上下文，并在**体素融合时**按占用率自适应锐化，从而修复稠密视图下的正视图缩放趋势（更多视图→更好性能），提升无位姿前馈重建的上限。

## 2. 方法论

### 2.1 总体框架

- 基于VGGT风格的多视图几何transformer编码器 + AnySplat式解码头；
- 输入：未标定多视图图像 {I_s}；
- 流程：图像→patch tokens→**Assist-View Preconditioning (AVP)**→全局-帧注意力聚合→多任务解码头（相机内外参、深度、高斯参数）→**Occupancy-guided Voxel Fusion (OVF)**→可微光栅化渲染；
- 关键改变：将全局注意力前的“被动搜索”变为“主动上下文注入”，将体素融合的“平均池化”变为“占用率调制的自适应加权”。

### 2.2 Assist-View Preconditioning (AVP)

**目标**：抑制密集视图下的注意力分散，加强跨视图匹配的稳定性与几何一致性。

- **视图级描述子**：每个视图的token做平均池化，得到描述子 z_s，计算视图间余弦相似度 m_st。
- **候选池**：每个当前视图取描述空间上最相似的 M 个近邻视图。
- **覆盖率驱动的贪心选择**：
  - 定义同时衡量**token覆盖率、视图可靠性、视图间多样性**的集合目标（式11）；
  - 因该目标是单调次模的，可用贪心迭代（式12）选出 K 个近似最优且互补的辅助视图；
  - 具体实现在子采样token上进行计算，保证效率。
- **轻量条件化**：每个视图用自己的token作为query、辅助视图token作为key/value做一次单层注意力（式13），得到带场景上下文的条件化token；随后通过带门控残差（式14，门控随训练步数从0渐增至1）与原始token混合，进入全局聚合。
- 训练细节为选择K=4，前2000步warm-up，8000步线性升门控至1，前1500步停止辅助分支梯度。
- 稀疏视图（如3/6视）下辅助视图数量不足，该模块被**禁用**。

### 2.3 Occupancy-guided Voxel Fusion (OVF)

**目标**：在高占用体素中保留高频细节，在低占用场景中避免过度自信的单候选主导。

- 对每个体素计算候选高斯数量 n_v（占用率）、3D点分布方差 σ²_v（几何一致性）。
- 计算温度 τ_v = clip(τ_0·(n_v/n_ref)^(-α)·ψ_v, τ_min, τ_max)，其中可靠性因子 ψ_v = 1/(1+λσ²_v)（式15-17）：
  - 占用率越高→温度越低→softmax权重分布越尖锐→高置信度点主导；
  - 占用率越低→温度越高→多条候选信息被保留，融合更平滑；
  - 几何方差小（点一致）→可靠性高→进一步锐化。
- 按下式对置信度除以温度得到 logits 并做softmax（式18）；随后按累积权重为0.8的阈值截断低权重候选，减少离群点影响；最后加权平均得到体素位置与特征（式19）。

## 6. 主要结论与发现

- **稠密视图正扩展性恢复**：DL3DV-140场景上，从32→64视图PSNR从21.54→21.67 dB保持上升，而AnySplat在21.04→21.14 dB附近饱和；在ACID 48→72视图上AnySplat从23.12跌至22.45 dB，AVSplat从23.15升至23.24 dB，差值达0.79 dB。
- **Attention诊断定量改进**：交叉视图熵降低约5.1%；GeoMass@1patch提升8.8个百分点（相对提升30.8%），表明与几何匹配相关的注意力密度显著增加。
- **消融表明**：OVF约贡献主要单点PSNR/SSIM提升；AVP主要负责稳定密集视图内全局匹配、防止增加视图后性能退化。
- **结论**：将稠密视图转化为显式的上下文和细节表达信号（辅助视图预条件+占用引导融合）可有效缓解现有前馈3DGS中的稠密退化问题，实现“视图越多质量越好或至少不下降”的理想行为。

## 7. 优点

- **问题定位精准**：切中现有NoPose前馈3DGS的实际瓶颈——注意力稀释和体素平均平滑，工程直觉清晰；
- **算法设计具有可解释性**：辅助视图选择综合了相关性/多样性/可靠性/覆盖率，理论上有次模贪心的合理性；体素融合温度由“占用×几何一致性”调制，物理含义直观；
- **在稀疏视图下保证兼容性**：AVP自动关闭，在有足够视图时才启用，方法在视角数量上可自适应；
- **注意力可视化和量化指标（熵、GeoMass）设计巧妙**：能够直接解释“为什么视图多了会退化”以及“AVP为何有效”，证据链完整；

  - 表1中Mip-NeRF 360等多指标在部分视图下出现LPIPS返升/SSIM不单调现象，论文没有系统解释；

- **应用限制**：无位姿前馈方法需一次性处理所有输入图像，受显存限制；虽然AVSplat降低了注意力负担和融合过度平滑，但实际可处理的视图数量（论文内训练最大24视、测试最大72视）仍受输入分辨率及patch数量的限制；
