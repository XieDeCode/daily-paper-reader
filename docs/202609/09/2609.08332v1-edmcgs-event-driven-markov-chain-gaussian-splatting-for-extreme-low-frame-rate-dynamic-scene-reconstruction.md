## 摘要
我们提出了EdMCGS（事件驱动马尔可夫链高斯泼溅），一种端到端方法，用于从极低帧率RGB图像结合事件流重建动态3D场景，并可在任意中间时间戳进行渲染。仅依赖RGB图像的方法由于缺乏连续帧之间的证据，会产生大量伪影。为了补充这一缺失的证据，我们将场景运动建模为事件驱动的马尔可夫链，其中稀疏的RGB帧锚定其自身时间戳的状态，而间隔内记录的事件驱动跨间隔的状态转移。由于转移过程读取当前间隔的事件，它在推理时仍保持活跃，并直接从事件而非插值生成3D高斯之间的运动，这使我们的方法区别于先前仅将事件用作训练时监督的工作。状态由一组紧凑的控制点承载，每个控制点由其图像投影邻域内采样的事件驱动，时间局部等距项保持传播运动在局部上具有刚性。在合成和真实世界场景上的实验表明，EdMCGS在性能上优于基于RGB和基于事件的基线，同时以远少于最强事件基线的高斯数量进行实时渲染。我们在https://github.com/joseclipse/EdMCGS发布了源代码和一个新数据集。

## Abstract
We present EdMCGS (Event-driven Markov chain Gaussian Splatting), an end-to-end method for reconstructing dynamic 3D scenes from extreme-low-frame-rate RGB together with an event stream, which can then be rendered at any intermediate timestamp. Methods relying solely on RGB images generate numerous artifacts due to the lack of evidence from between consecutive frames. To supply this missing evidence, we model the scene motion as an event-driven Markov chain, in which the sparse RGB frames anchor the state at their own timestamps while the events recorded within an interval drive the transition across it. Since the transition reads the events of the current interval, it remains active at inference and produces the in-between motion of the 3D Gaussians directly from the events rather than by interpolation, which sets our method apart from prior work that uses events only as training-time supervision. The state is carried by a compact set of control points, each driven by the events sampled in the neighborhood of its own image projection, and a temporal local isometry term keeps the propagated motion locally rigid. Experiments on synthetic and real-world scenes show that EdMCGS outperforms both RGB-based and event-based baselines, while rendering in real time with far fewer Gaussians than the strongest event-based baseline. We release our source code and a new dataset at https://github.com/joseclipse/EdMCGS.

### 1. 核心问题与整体含义（研究动机与背景）

- **问题定义**：动态3D场景重建传统上依赖**密集采样的RGB视频**，但在实际应用中，由于带宽、存储、长曝光或硬件限制，RGB帧的采集往往是**极低帧率**（如5–10 fps）。此时，相邻RGB帧之间存在巨大的时间间隔，缺少任何关于中间运动的观测证据。
- **核心痛点**：单纯依赖低帧率RGB训练的动态重建方法（如Deformable 3DGS、SC-GS），由于不知道帧间发生了什么，会过拟合少数观测时刻，在渲染未观测的中间帧时产生**撕裂（tearing）、重影（ghosting）等伪影**。这一困难并非表示能力不足，而是**帧间时间证据在根本上的缺失**。
- **为何引入事件相机**：事件相机以微秒级时间分辨率、异步地报告逐像素亮度变化，天然地高密度采样了RGB缺失的时间段，与低帧率RGB形成互补：RGB提供稀疏但绝对的外观锚点，事件提供细粒度的亮度变化证据。
- **现有方法的不足**（作者归纳的三大共性）：
  1. **事件仅用于训练监督**：现有事件动态重建方法中，变形场被参数化为纯时间的函数，推理时不读取事件，中间运动靠时间插值而非事件证据生成；
  2. **系统沉重**：如DEGS依赖预测练外部光流网络、逐场景微调、姿态分解网络等复杂组件；部分方法需要动态/静态或二值运动掩码；
  3. **可复现性差**：多数方法未公开代码或数据集，社区缺乏极低帧率全动态场景下可比较的基线。

### 2. 提出的方法论

#### 整体框架与核心思想

- **核心创新**：将动态场景运动建模为**事件驱动的马尔可夫链（Event-driven Markov Chain）**。时间轴被稀疏RGB帧分割为若干区间；RGB帧在各自时间戳上**锚定状态**，区间内的事件流**驱动状态从前一帧转移到后一帧**。
- **关键区别**：由于转移过程以当前区间的事件作为条件，它在**推理时保持激活**——中间帧的运动直接从事件生成，而非依靠时间插值。这是对既有“事件仅作训练监督”范式的根本性改变。

#### 技术细节

**（1）状态表示与控制点**

从规范高斯基元中，采用最远点采样得到一组稀疏控制点 M = {M_j}（实验中 M = 512）。每个高斯绑定到其K=3个最近邻控制点，通过线性混合蒙皮（Linear Blend Skinning）由控制点的位移驱动高斯变形。

**（2）马尔可夫转移的设计**

设RGB帧时刻为 τ₁ < τ₂ < … < τ_Nrgb，对任意查询时刻 t，令 τ(t) = max{τₙ: τₙ ≤ t} 为其前驱锚点。状态S_t定义为控制点在t时刻的位置集合。转移形式化为：

> S_t = 𝒯(S_{τ(t)}, E[τ(t), t])

即状态只依赖前驱锚点状态和该区间内的事件，呈现一阶马尔可夫性质。每个控制点的位移由两项相加：

> δμ_t^j = δμ^{f,t}_j + g_φ( γ(μ_j), m_t^j )

- 第一项 δμ^{f,t}_j：由小型MLP从（规范化控制点位置，时间t）预测的**RGB驱动的粗略运动先验**，是跨时间的平滑插值器；
- 第二项 g_φ：**事件驱动的精细修正项**，输入为控制点位置编码和从事件构造的运动码 m_t^j。该MLP最后一层零初始化并逐步热身，因此在锚点时刻事件窗口为空时gφ消失，状态还原为锚点状态；随着t推移，累积事件推动状态前进。

**（3）局部事件采样**

每个控制点运动码 m_t^j 的构建分三步：
1. 将 [τ(t), t] 区间内的事件按极性累积为二维事件图 I_t^E；
2. 用浅层CNN Φ编码为保持空间布局的特征图；
3. 将每个控制点投影到事件相机平面，在事件图上用**双线性采样**读取该控制点自己投影位置邻域的特征。

> m_t^j = bilinear( Φ(I_t^E), π_ev(μ_j + δμ^{f,t}_j) )

**关键意义**：运动部件触发的事件落在覆盖该部件的控制点投影附近，事件得以精确驱动对应区域的控制点，而不会被全局池化与背景、相机运动或噪声事件混淆。

**（4）时间局部等距正则化（TLI）**

在规范空间控制点上构建KNN图（K_conn=10），对每个边(j,k)，计算其在两个相邻时间点 t₁、t₂ 的变形边长并惩罚变化：

> L_TLI = (1/|E|) Σ_{(j,k)∈E} [ℓ_jk(t₁) − ℓ_jk(t₂)]²

局部刚体运动保持点间距离故不受罚，只有拉伸、剪切被惩罚。与SC-GS的ARAP不同：一是直接保持距离而非拟合SVD旋转残差；二是比较**两个变形时间点之间**的几何演化而非与规范姿态比较，因此无旋转估计、直接约束瞬时几何演化的稳定性。

**（5）整体损失**

L = (1−λ_d)L₁ + λ_d·L_SSIM + λ_e·L_event + λ_t·L_TLI + λ_s·L_smooth

- **光度损失**：在每个RGB时间戳上用L₁+D-SSIM监督渲染结果；
- **事件损失**：基于事件生成模型（EGM），渲染两个子时刻t_a < t_b的图像，转换到对数亮度域后与区间累积事件匹配；训练时**截断颜色梯度**，使事件只更新几何与运动，避免污染颜色；
- **平滑项**：对事件驱动项gφ施加KNN拉普拉斯平滑，保持相邻控制点运动的一致性。

### 6. 主要结论与发现

- EdMCGS在**所有测试的帧率、所有场景、三个指标上均排名第一**：合成数据集（10 fps：31.56 dB / .9668 / .0426；5 fps：29.37 dB / .9495 / .0551），真实数据集（5 fps：31.13 dB / .9015 / .2398）。
- **帧率越低优势越大**：从10 fps降至5 fps，时间间隔翻倍，事件证据不变——这种设置放大“事件驱动推理”相比“时间插值”的根本优势，实验证实该推断。
- **与E-D3DGS的差距主要体现在LPIPS上**：无法恢复区间内运动的方法会退化为时间平均的模糊渲染；PSNR对此类模糊容忍较高，而LPIPS更敏感，揭示了不同指标下方法差异的本质。
- **效率与质量可兼得**：EdMCGS比E-D3DGS训练更快、渲染更快、高斯数减少数倍至一个数量级的同时质量更高——事件证据更适合被轻量变形模型在推理时读取，而非被重型表示在训练时吸收。
- **消融的关键量化结论**：
  - 去掉事件流掉 5.32 dB（合成），说明事件贡献巨大；
  - “无Markov链”变体在Jumpingjack（5 fps）掉 10.14 dB，但在动作平缓的Lego（10 fps）仅落后0.24 dB——事件驱动转移的价值与帧间运动量成正比；
  - 全局池化替代局部采样拖累显著（21.67 dB vs 31.81 dB类比），说明局部事件采样避免了不同区域事件相互污染的混淆；
  - 时间局部等距正则化对稳定传播运动必不可少。
- 主导场景的区域分析发现：EdMCGS在**背景占主导（Quasi-static）的真实场景**中领先幅度比合成全动态场景小，是因为这些场景中大部分测试像素来自静态重建，本就不受低帧率威胁。

### 7. 方法或实验设计的亮点

- **范式创新**：首次将事件从“训练监督”提升为“推理时的驱动信号”，直接回应了极低帧率动态重建的证据缺失根本问题，概念清晰且与问题定义高度契合。
- **因果与误差隔离**：用每日RGB帧重置事件累积窗口，使链条满足马尔可夫性，也天然阻止误差在区间间累积传播。
- **局部性设计**：局部事件采样让事件精确对应到其触发的部件所关联的控制点，避免全局描述符不同源信号混淆；双线性采样+CNN感受野隐式定义邻域，无需显式半径。
- **几何合理性**：事件驱动的点位移本质上容易发生非刚性、不一致的形变；时间局部等距项消除了旋转估计的复杂度而直接保持点间距离演化一致，巧而轻。
- **轻量与免掩码**：无需光流网络、无姿态分解、无动态/静态掩码、无场景分解假设，端到端可训。
- **控制点与高斯基元分离**：MLP只作用在512个控制点上，而非全量高斯的逐点变形，大幅节省计算。
- **透明度与可复现性**：开源代码与数据集，统一指标口径，提供了社区急需的可复现基线。
- **温暖启动与零初始化**：事件分支逐步引入，避免训练初期事件噪声干扰RGB锚点场的建立；同时颜色梯度截断避免事件误差污染外观，是工程设计的细致之处。

### 8. 不足与局限

- **假设相机位姿已知**：方法继承了可变形3DGS的方法学假设，要求已知位姿；这限制了其在无位姿/自运动估计场景中的应用（作者对此有明确声明并列为未来方向）。
- **依赖事件质量与参数校准**：事件对比阈值C是事件损失中需要设定的参数；实际传感器噪声、阈值不均可能影响理想EGM假设，论文未深入分析这一鲁棒性问题。
- **受控数据环境为主**：合成数据来自单一模拟器（ESIM）与固定阈值；真实数据是静态场景背景的E-D3DGS数据，缺乏全动态、大范围、户外场景（如自动驾驶、快速相机自运动与大运动物体共存）的验证，对论文宣称的实际应用域覆盖有限。
- **不可复现基线的比较缺口**：DEGS、Ev4DGS、E-4DGS未开放，无法直接对比，虽然以E2VID+D-3DGS和内部“事件仅监督”变体作了间接代答，但缺少对最强同类方法的实证对比仍是一个证据缺口。
- **消融粒度有限**：TLI项与局部采样的权重敏感性、CNN编码器深度、控制点数量变化对结果的影响均未做系统消融；TLI的正则化强度只有单一设定（10⁻⁵），缺乏对超参数鲁棒性的充分讨论。
- **一致性图形细节**：LPIPS-VGG虽已统一，但不同方法的训练策略（迭代数、优化器、学习率调度）是否做到最佳匹配未详细陈列，可能存在对基线的调优偏差。
