## 摘要
近期的前馈3D高斯泼溅（3DGS）方法通常回归像素对齐的高斯基元，这往往会导致过度重叠和伪影，而预测相机位姿的不准确则可能在新视角合成（NVS）中造成错位。我们提出 VoxelTTO，一个前馈框架，可从任意数量图像和可选相机参数中重建几何精确的3DGS场景。VoxelTTO 将密集图像特征聚合为全局体素表示，并从体素特征解码高斯，打破了像素到高斯的对应关系。为了在保持预训练视觉基础模型（VFM）参数冻结的同时利用已知相机参数，我们引入测试时优化（TTO），利用位姿监督来适配轻量级 LoRA 模块。我们进一步在训练和推理期间用随机实体体积渲染替代原始3DGS光栅化，从而提升几何保真度。训练仅更新体素对齐的高斯重建模块，需要 80 GPU 小时。在 Replica、Tanks and Temples 和 DTU 上的实验表明，与先前方法相比，RGB-D NVS 和相机位姿估计均有改进。

## Abstract
Recent feed-forward 3D Gaussian Splatting (3DGS) methods typically regress pixel-aligned Gaussian primitives, often causing excessive overlap and artifacts, while inaccuracies in predicted camera poses can lead to misalignment in novel-view synthesis (NVS). We present VoxelTTO, a feed-forward framework for reconstructing geometrically accurate 3DGS scenes from an arbitrary number of images and optional camera parameters. VoxelTTO aggregates dense image features into a global voxel representation and decodes Gaussians from voxel features, breaking the pixel-to-Gaussian correspondence. To exploit known camera parameters while keeping the pretrained visual foundation model (VFM) parameters frozen, we introduce test-time optimization (TTO) that adapts lightweight LoRA modules using pose supervision. We further replace vanilla 3DGS rasterization with stochastic solid volume rendering during training and inference, improving geometric fidelity. Training updates only the voxel-aligned Gaussian reconstruction modules, requiring 80 GPU hours. Experiments on Replica, Tanks and Temples, and DTU demonstrate improved RGB-D NVS and camera-pose estimation relative to prior methods.

# VoxelTTO 论文中文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：从图像进行三维重建的传统流程依赖多阶段管线（特征匹配 + SfM），而近期视觉基础模型（VFM，如 Dust3R、VGGT）提供了端到端替代方案。3DGS 凭借各向异性高斯基元实现实时高质量新视角合成（NVS），但通常需要先通过 SfM 恢复相机参数并进行昂贵的逐场景优化。
- **核心问题**：
  - **像素对齐的缺陷**：现有前馈 3DGS 方法（如 pixelSplat 风格）通常回归像素对齐的高斯基元，导致**过度重叠和渲染伪影**，且多视角一致性不足。
  - **位姿误差导致错位**：预测相机位姿的不准确会在新视角合成（尤其是测试视角）中造成显著错位。即使经过 Umeyama SIM(3) 对齐，误差依然存在。
  - **相机先验融合的局限**：部分 VFM 将相机参数编码进骨干网络，虽提升精度，但改变了架构，无法直接复用无约束 VFM。
- **整体含义**：VoxelTTO 旨在从任意数量图像和可选相机参数中，直接前馈重建**几何精确**的 3DGS 场景，兼顾输入视角与测试视角的 RGB-D 渲染质量，并显著降低训练成本。

## 2. 方法论

### 核心思想
打破传统“像素→高斯”的固定对应关系，转而将密集图像特征聚合为**全局体素表示**，再从体素特征解码高斯；同时利用**测试时优化（TTO）** 适配轻量 LoRA 模块，以位姿监督对齐相机参数。

### 关键技术细节

- **体素对齐前馈 3DGS**：
  - 使用冻结的 DINOv2 提取多视角 patch token，采用交替注意力建模场景。
  - 冻结 VFM 骨干预测深度图 $D_m$、相机参数 $g_m$ 和置信度图 $K_m$；额外用 DPT 上采样 patch token 得到密集像素特征 $F_m$。
  - 将像素反投影为带特征的点云 $P = \{(p_l, a_l, f_l, \kappa_l)\}$，再聚合为体素特征。体素特征中心为置信度加权平均 $x_v = \sum \kappa_l p_l / \sum \kappa_l$（**不约束于规则体素中心**，保留几何精度），体素置信度 $\kappa_v = \min_{l \in P_v} \kappa_l$。
  - 使用稀疏卷积 3D U-Net 精炼体素特征；每个体素解码出 $n$ 个高斯基元。
  - 采用**几何-外观解耦分支**：$D_{geo}$ 解码中心、旋转四元数、尺度、不透明度；$D_{app}$ 解码二阶球谐系数。

- **随机实体体积渲染（Stochastic Solid Volume Rendering）**：
  - 替代原始 3DGS 光栅化。在合适的空位函数 $v$ 下，体积渲染与 3DGS 光栅化等价（GGGS 证明当 $v(x) = \sqrt{1 - G(x)}$ 时等价）。
  - 衰减系数 $\sigma(x, \omega) = \omega^\top \nabla \log v(x)$，透射率 $T(t) = \exp(-\int \sigma \, ds)$，颜色 $C = \int T \sigma c \, dt$。
  - 深度渲染使用中值深度（$T(t_{med}) = 0.5$，固定二分迭代次数），反向传播时对固定条件求导：$\frac{\partial T}{\partial t} \frac{\partial t_{med}}{\partial \theta} + \frac{\partial T}{\partial \theta} = 0$。
  - 优势：RGB 渲染几乎与 3DGS 光栅化一致，但深度渲染**减少空洞和模糊边界**，几何优势明显。

- **测试时优化（TTO）**：
  - 在 VFM 骨干的交替注意力层（第 13–40 层）的 Q、K、V 投影中插入 LoRA。每层共享下投影矩阵 A，上投影矩阵 B 独立。
  - 提供对齐相机参数后，在相机解码后计算 TTO 损失并反向传播更新 LoRA 参数，固定迭代后骨干输出更准确的相机参数。
  - 位姿对齐：固定第一帧 GT 相机位姿为单位矩阵；旋转损失 $L_{rot} = \frac{1}{2M} \sum_{i=1}^{M} [3 - \text{tr}((R_p^i)^\top R_g^i)]$；平移按均值尺度 $s$ 归一化后用 SmoothL1；内参 $(f_x, f_y, c_x, c_y)$ 直接用 SmoothL1。
  - 总目标：$L_{TTO} = \lambda_{pose}(L_{rot} + w_t L_{trans}) + \lambda_K L_{intrinsics}$。

- **训练损失**：$L = L_{depth} + L_{rgb} = \lambda_{\ell d1} L_{depth}^{\ell1} + \lambda_{align} L_{depth}^{align} + \lambda_{\ell1} L_{rgb}^{\ell1} + \lambda_{ssim} L_{rgb}^{ssim}$，权重分别设为 0.25、0.25、0.9、1.0。

## 3. 实验设计

- **数据集/场景**：
  - **训练**：ScanNet、Infinigen、ARKitScenes、DL3DV-10K（覆盖室内外、合成与真实、顺序帧）。
  - **评估**：Replica（室内合成）、Tanks and Temples（TAT，场景级）、DTU（物体级）。
- **Benchmark 指标**：

  - 表面对齐：DTU 上的 Chamfer 距离（Accuracy、Completeness、Overall）。
- **对比方法**：
  - VGGT 风格 VFM：AnySplat、YoNoSplat、DepthAnything3、MapAnything。

## 4. 资源与算力

- **GPU 型号与数量**：2 张 RTX PRO 6000。
- **训练时长**：40 小时（约 80 GPU 小时）。
- **模型规模**：完整模型 1.39B 参数，其中仅 **75.3M 参数可训练**（VFM 骨干冻结）。
- **训练配置**：30K 迭代，Adam 优化器，初始学习率 $3 \times 10^{-6}$，余弦退火，2K 预热，最低学习率 $10^{-8}$；每样本 3–16 帧，分辨率 224×448。

## 6. 主要结论与发现

- VoxelTTO 能从任意数量图像和可选相机参数中重建几何精确的 3DGS 场景。
- **体素对齐 + 随机实体体积渲染**有效减少过度重叠和伪影，提升几何保真度；随机实体体积渲染的深度渲染明显优于 3DGS 光栅化（减少空洞和边界模糊）。
- **位姿监督 TTO** 显著改善预测与真实相机参数的对齐：Replica 上旋转误差从 0.301° 降至 0.220°，TAT 上从 1.636° 降至 0.262°；平移误差同步大幅下降。
- 在 Replica、TAT、DTU 上，RGB-D NVS 和位姿估计均优于现有前馈 3DGS 方法，尤其**测试视角**提升显著。
- 训练仅需 80 GPU 小时，且与任意 VGGT 风格 VFM 兼容。

## 7. 优点

- **架构创新**：打破像素到高斯的固定对应，采用体素聚合 + 稀疏 U-Net + 自分裂解码器，有效缓解重叠与伪影。
- **几何-外观解耦**：分离 $D_{geo}$ 与 $D_{app}$，避免优化时几何与外观相互纠缠。
- **渲染等价性利用**：基于随机实体体积渲染与 3DGS 光栅化的理论等价性，在保持 RGB 质量的同时提升深度几何质量。
- **轻量 TTO 设计**：仅适配 LoRA 模块，不改变 VFM 基础架构，兼容无约束 VFM；参数量小（75.3M 可训练），训练成本低（80 GPU 小时）。
- **实验覆盖全面**：多数据集、多指标、多维度消融，且包含运行时分析，实用性论证充分。
- **位姿对齐处理细致**：考虑尺度模糊性，分别对旋转、平移、内参设计损失。

## 8. 不足与局限

- **实验覆盖**：
  - DTU 表面对齐实验仅对比自身变体（w/o TTO、Camera Enc.），未与其他前馈 3DGS 方法进行横向 Chamfer 距离比较，说服力有限。
  - 部分数据集结果存在不一致（TAT 输入视角 PSNR 在加入 TTO 后反而下降），缺乏解释。
- **偏差风险**：
  - 训练数据以顺序帧采样为主，对无序、大基线或稀疏视角场景的泛化能力未充分验证。
  - TTO 依赖“对齐相机参数”的提供，在完全无位姿先验场景下的适用性未讨论。
- **应用限制**：
  - TTO 需要额外 20 步优化（< 7s），对实时性要求极高的场景可能构成瓶颈。
  - 体素尺寸（0.002m）为固定超参，对不同尺度场景的适应性需进一步验证。
  - 完整模型 1.39B 参数，推理仍需较大显存；BF16 与 Float32 混合精度策略对硬件有要求。
- **理论层面**：随机实体体积渲染的等价性依赖空位函数 $v$ 的选取，实际实现中的近似误差未量化分析。
