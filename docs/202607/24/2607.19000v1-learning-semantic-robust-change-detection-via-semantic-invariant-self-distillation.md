## 摘要
变化检测旨在识别遥感图像之间的语义变化。然而，模型的特征容易受到非语义变化（如光照、阴影和大气变化）的干扰，导致误报和在真实场景中泛化能力有限。本文提出SCDistill，一种通过语义不变自蒸馏学习语义鲁棒变化检测的框架。首先，为了加强语义一致性，我们引入了一种语义不变自蒸馏策略，从扰动但语义一致的数据中学习语义鲁棒性，使变化检测器能够提取抗干扰特征，实现更可靠、更准确的语义变化识别。其次，为了扩展具有非语义变化的配对数据，我们设计了一种基于扩散的扰动模拟流程，合成复杂的环境变化，使模型能够显式学习区分语义变化与外观水平波动，减少非语义扰动引起的误报。这些组件从数据和表示角度促进鲁棒性，带来协同性能提升。大量实验表明，SCDistill在多个语义变化检测基准上达到最先进性能，并对二值变化检测和变化描述任务展现出强泛化能力。代码可在https://github.com/elecreak/SCDistill获取。

## Abstract
Change detection aims to identify semantic changes between remote sensing images. However, features from models are easily disturbed by non-semantic variations, such as illumination, shadows, and atmospheric changes, leading to false alarms and limited generalization in real-world scenarios. In this paper, we propose \textbf{SCDistill}, a framework for learning semantic-robust change detection via semantic-invariant self-distillation. First, to strengthen semantic consistency, we introduce a semantic-invariant self-distillation strategy that learns semantic robustness from perturbed yet semantically consistent data, empowering the change detector to extract disturbance-resistant features and achieve more reliable and accurate semantic change identification. Second, to expand paired data with non-semantic variations, we design a diffusion-based perturbation simulation pipeline that synthesizes complex environmental changes, enabling the model to explicitly learn to distinguish semantic changes from appearance-level fluctuations and reduce false alarms caused by non-semantic disturbances. These components promote robustness from data and representation perspectives, leading to synergistic performance gains. Extensive experiments demonstrate that SCDistill achieves state-of-the-art performance on multiple semantic change detection benchmarks and exhibits strong generalization to binary change detection and change captioning tasks. Code is accessible at https://github.com/elecreak/SCDistill.

### 1. 论文的核心问题与整体含义（研究动机和背景）
- **研究动机**：遥感图像变化检测（Change Detection, CD）旨在识别双时相图像间的语义变化，但现有基于深度学习的模型极易受到**非语义变化**的干扰，如光照变化、阴影、大气效应、季节更替等。这些非语义变化改变了图像的视觉外观，却没有改变地物的真实语义，但模型常常错误地将它们预测为语义变化，导致**高误报率（false alarms）** 和**泛化能力差**。
- **核心问题**：现有方法依赖在单视图像上预训练的视觉编码器（如ResNet、X3D），这些编码器对表观变化敏感，当特征传递给时序差分和检测头时，容易将非语义变化误判为语义变化。
- **整体目标**：提出一个能抑制非语义扰动、学习鲁棒语义表示的框架，使变化检测模型在真实复杂环境下依然能够可靠地识别真正的语义变化。

### 2. 论文提出的方法论：核心思想、关键技术细节
- **方法名称**：SCDistill（Semantic-Robust Change Detection via Semantic-Invariant Self-Distillation）
- **核心思想**：从**数据**和**表征**两个层面提升鲁棒性。数据方面，通过扩散模型模拟各种非语义扰动（光照、天气、阴影等），生成带有扰动但语义不变的训练样本；表征方面，使用一种**语义不变自蒸馏（Semantic-Invariant Self-Distillation）** 策略，让一个冻结的视觉基础模型编码器（VFME）作为教师，指导一个学生编码器学会从扰动图像中提取与教师从干净图像中提取的语义特征一致的特征，从而学习到抗扰动、语义稳定的表示。
- **关键技术细节**：
  1. **非语义扰动模拟（Diffusion-based Perturbation Simulation）**：
     - 以现有的合成变化检测数据集（如FSC-180k）为基础，对前时相图像 $X_0$ 施加扰动，保持后时相图像 $X_1$ 和标签 $L$ 不变，得到 $\tilde{X}_0 = \text{Perturb}(X_0)$。
     - 具体扰动类型包括：
       - 光照与阴影变化：使用场景重新光照模型（如DIR），随机改变太阳方位角和仰角。
       - 天气与大气变化：使用图像编辑模型（如InstructPix2Pix），通过多个预定义文本提示生成各种非语义变化（如雾、雨、雪、亮度变化等）。
     - 同时叠加随机低层扰动（高斯模糊、灰度变换、亮度/饱和度偏移），增加多样性。
  2. **语义不变自蒸馏（Semantic-Invariant Self-Distillation）**：
     - 教师：预训练并冻结的VFME（如DINOv3），输入**干净图像** $X$，输出特征 $F_T = E_T(X)$。
     - 学生：与教师同结构的编码器 $E_S$，初始化为教师权重，输入**扰动图像** $\tilde{X}$，输出特征 $F_S = E_S(\tilde{X})$。
     - 蒸馏损失：使用L2回归损失最小化 $F_S$ 和 $F_T$ 之间的差异。
     - 训练数据：利用扰动模拟管道生成的大量语义不变但外观多样化的图像对（单个遥感图像与其扰动版本），无需变化标签或语义分割标注。
     - 蒸馏后，学生编码器成为**蒸馏后的VFME**，用于下游变化检测任务中的特征提取。
  3. **变化检测网络**：
     - 采用Change3D [77] 的架构（视频编码器+通用解码器），将蒸馏后的VFME集成到编码器分支中，与X3D浅层表示融合，提供稳定、抗扰动的语义特征，引导深层关注真正语义变化区域。
     - 训练流程：先在扩散增强的合成数据集上预训练，然后在真实基准上微调。
     - 损失函数：语义CD使用交叉熵、Dice、余弦相似度联合损失；二值CD使用交叉熵和Dice；变化描述使用交叉熵。
