## 摘要
域泛化旨在学习对分布偏移稳健的表征。最近的几何对齐方法，如CPCANet，通过批量式公共主成分分析提取域不变结构。然而，CPCANet由于小批量训练中的小样本问题而面临秩亏协方差估计的局限性。为了解决这一限制，我们提出了投影寻踪CPCANet（PP-CPCANet），一种无协方差框架，在Stiefel流形上学习全局正交基，并通过Cayley变换将其与网络参数联合优化。我们进一步引入一个对称破缺的分离中位数PP散度目标，以提取具有密集且稳健优化信号的公共主成分。在四个域泛化基准上的实验表明，PP-CPCANet在保持稳定训练的同时实现了最先进的性能。

## Abstract
Domain Generalization (DG) aims to learn representations robust to distribution shifts. Recent geometric alignment methods, such as CPCANet, extract domain-invariant structures through batch-wise Common Principal Component Analysis (CPCA). However, CPCANet suffers from rank-deficient covariance estimation due to the small-sample-size issue in mini-batch training. To address this limitation, we propose Projection Pursuit CPCANet (PP-CPCANet), a covariance-free framework that learns a global orthogonal basis on the Stiefel manifold and jointly optimizes it with network parameters via the Cayley transform. We further introduce a symmetry-breaking detached-median PP dispersion objective to extract common principal components (CPCs) with dense and robust optimization signals. Experiments on four DG benchmarks show that PP-CPCANet achieves SOTA performance while maintaining stable training.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：域泛化（Domain Generalization, DG）要求模型从多个源域学习，能泛化到未见的目标域。现有几何对齐方法（如CPCANet）通过批量式公共主成分分析（CPCA）提取域不变结构，但面临**小样本协方差估计秩不足**的瓶颈：当特征维度远超小批量大小时，协方差矩阵奇异，导致公共子空间只能近似截断，丢失重要几何信息。
- **背景**：CPCANet通过展开网络结构集成CPCA，但现代深度学习训练中特征维度（如2048）远大于批量大小（如32），使得批协方差估计不可靠。
- **整体含义**：本文提出**无协方差框架PP-CPCANet**，绕过协方差计算，在Stiefel流形上学习全局正交基，并通过投影寻踪（Projection Pursuit）的鲁棒散度目标提取公共主成分，从根本上解决秩亏问题，实现更稳定、更优的域泛化性能。

## 2. 方法论

### 核心思想
- **全局正交基学习**：不依赖批协方差，而是通过Cayley变换在Stiefel流形上参数化一个可学习的正交矩阵β_t，与网络参数联合优化。
- **无协方差投影寻踪**：用基于L1中位数绝对偏差（MAD）的鲁棒散度度量替代L2方差，并对权重进行对称破缺设计，迫使方差集中到前几个主成分，提供密集且对异常值鲁棒的梯度。
- **级联瓶颈结构**：渐进式降低特征维度（d_{t+1} = max(d_t/2, 16)），逐步过滤域特异性噪声，保留核心语义。

### 关键技术细节
1. **参数化Stiefel流形**：
   - 用无约束向量θ_t构造斜对称矩阵A_t = S(θ_t)。
   - 通过Cayley变换 β_t = (I - ½A_t)(I + ½A_t)^{-1} 保证正交性。
   - 投影特征 U_t = Z_t β_t，其中Z_t为瓶颈层输出。
2. **对称破缺鲁棒散度**：
   - 对每个域k，计算中位数锚点 m_{t,k} = sg[median({U^{(i)}_{t,k}})]（stop-gradient防止梯度通过中位数传播）。
   - 使用单调递减权重 w_t（如[dt, dt-1, ..., 1]归一化）加权 L1 散度：s_{t,k} = w_t^T (1/N_k ∑|U^{(i)}_{t,k} - m_{t,k}|)。
   - 总体损失 L_{ppcpca} = -1/(KT) ∑_t ∑_k s_{t,k}，最大化投影特征散度。
3. **级联与域引导调制**：
   - 每级用MLP生成缩放因子 γ_t = 2·σ(MLP_γ(U_t)) 和偏移 ΔF_t，对前一层的环境特征 ˜F_{t-1} 进行残差调制：˜F_t = (˜F_{t-1} ⊙ γ_t) + ΔF_t。
   - 最终分类器使用最后一层调制后的特征 ˜F_T。
4. **联合优化目标**：
   - L_total = L_task(Ŷ, Y) + λ_{ppcpca} L_{ppcpca}，其中 λ_{ppcpca}=5×10^{-3}。

### 算法流程（文字说明）
算法1描述了前向传播：
1. 用骨干网络提取初始特征 ˜F_0。
2. 对每个级联深度t：
   - 通过瓶颈层得到Z_t。
   - 从全局参数θ_t构造斜对称矩阵A_t，Cayley变换得到 β_t，计算投影U_t。
   - 域引导调制：从U_t预测γ_t和ΔF_t，调制环境特征得到 ˜F_t。
3. 对每个域k计算分离中位数L1散度，累加为L_{ppcpca}。
4. 用最后一层调制特征˜F_T通过分类器得到预测，计算总损失。
